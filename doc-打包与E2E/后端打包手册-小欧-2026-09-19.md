## 一、概述

OmniAgentAst 后端是 Python + FastAPI 应用，通过 PyInstaller 打包为 Windows 可执行文件（exe），使用户无需安装 Python 环境即可运行。

**打包方式：** PyInstaller onedir 模式（生成一个目录，包含 exe 和所有依赖，拷走即用）。

**产物位置：** `backend/dist/OmniAgentBackend/OmniAgentBackend.exe`

**产物大小：** 约 42MB（精简后）至 915MB（含全部间接依赖，可优化）。

**运行方式：** 双击 exe 或命令行启动，带控制台窗口方便查看日志。

## 三、配套文件清单

打包涉及 10 个文件，分为三类：构建配置、路径分流、资源文件。

### 3.1 构建配置文件（直接参与打包）

| 文件 | 说明 | 是否改动 |
|------|------|---------|
| `backend/run_server.py` | exe 启动入口（新建） | **新建** |
| `backend/OmniAgentBackend.spec` | PyInstaller 打包配置（新建） | **新建** |
| `backend/requirements.txt` | 依赖清单（未改） | 未改 |

**`run_server.py`** 是 exe 的启动入口。PyInstaller 以它为 Analysis 起点，它负责：
1. 检测是否 frozen（exe 运行），是则把 `sys._MEIPASS` 加入 `sys.path`
2. 检查 `config/config.yaml` 是否存在，不存在则从 `config.yaml.example` 复制
3. 编程式启动 uvicorn（不走命令行 `python -m uvicorn`，因为 frozen 环境没有 python 命令）
4. 支持 `--host` 和 `--port` 命令行参数

**`OmniAgentBackend.spec`** 是 PyInstaller 打包配置，定义了：
- **Analysis 入口：** `run_server.py`
- **datas：** `version.txt` 和 `config.yaml.example` 拷到 exe 旁
- **hiddenimports：** 手动声明 PyInstaller 静态分析找不到的依赖（aiosqlite、uvicorn 各协议、jinja2、platformdirs）
- **Tree：** 业务源码 `app/` 整树以源码形式拷入 `_internal/app/`（因为 `app/` 无 `__init__.py`，PyInstaller 的 `collect_all` 收不全）
- **COLLECT：** onedir 模式，所有文件收集到 `dist/OmniAgentBackend/` 目录

### 3.2 路径分流文件（4 处小改，零功能退化）

exe 运行时，程序资源（version.txt、config.yaml、logs/）的定位方式与源码运行不同。以下 4 个文件各增加了一个 frozen 分支，通过唯一的 `get_frozen_dir()` 函数判断：

| 文件 | 改动内容 | 行为差异 |
|------|---------|---------|
| `app/config.py` | 新增 `get_frozen_dir()` 唯一源 + `_get_code_root()` 增加 frozen 分支 | exe：返回 exe 所在目录；源码：返回 `__file__` 推算的 backend 目录 |
| `app/logger/config.py` | `LOG_DIR` 增加 frozen 判断 | exe：`exe旁/logs/`；源码：`backend/logs/` |
| `app/logger/prompt_logger.py` | `PromptLogger.__init__` 的 `log_dir` 增加 frozen 判断 | exe：`exe旁/logs/prompt-logs/`；源码：`backend/logs/prompt-logs/` |
| `app/file_persist.py` | `_files_root()` 增加 frozen 判断 | exe（debug）：`exe旁/files/`；源码（debug）：`backend/files/` |

**设计原则：** 路径分流只在 `get_frozen_dir()` 一处判断 `sys.frozen`，其他 3 个文件调用此函数，不重复判断（DRY）。

### 3.3 资源文件（打包时拷入 exe 旁）

| 文件 | 位置 | 打包方式 | 说明 |
|------|------|---------|------|
| `version.txt` | 项目根目录 | spec datas → exe 旁 | 版本号来源，第一行如 `v1.0.1` |
| `config.yaml.example` | `backend/` 目录 | spec datas → exe 旁 | 配置模板，首次启动自动复制为 `config/config.yaml` |
| `backend/app/services/visualization/templates/` | 后端源码 | Tree() → `_internal/app/` | 动画模板文件（animation.html/css/js） |

## 四、打包配置详解

### 4.1 run_server.py 逐段说明

```python
# 第一段：frozen检测 + sys.path注入
def _exe_dir() -> Path:
    if getattr(sys, "frozen", False):
        sys.path.insert(0, sys._MEIPASS)   # _internal/app/ 的绝对路径
        return Path(sys.executable).resolve().parent  # exe 所在目录
    return Path(__file__).resolve().parent  # 源码运行：backend/
```

frozen 时，业务源码以源码树拷入 `_internal/app/`，但 `run_server.py` 自身在 exe 根目录，所以需要把 `_MEIPASS`（即 `_internal/`）加入 `sys.path`，`import app.main` 才能找到。

```python
# 第二段：首次启动自动补 config
def _ensure_config(base: Path) -> None:
    target = base / "config" / "config.yaml"
    if target.exists():
        return
    example = base / "config.yaml.example"
    if example.exists():
        target.parent.mkdir(parents=True, exist_ok=True)
        shutil.copy(example, target)
```

用户拿到 exe 后第一次双击，若没有 `config/config.yaml`，程序自动从 `config.yaml.example` 复制一份，用户编辑后重启即可。

```python
# 第三段：编程式启动 uvicorn
def main() -> None:
    freeze_support()
    # ... argparse 解析 --host/--port ...
    base = _exe_dir()
    _ensure_config(base)
    import app.main  # 静态导入，供 PyInstaller 收集依赖
    import uvicorn
    uvicorn.run("app.main:app", host=args.host, port=args.port, log_level="info")
```

`import app.main` 除了实际导入，还让 PyInstaller 的静态分析器看到 app 包的所有第三方依赖（fastapi、sqlalchemy 等），确保这些包被打入 exe。

### 4.2 OmniAgentBackend.spec 逐段说明

```python
# 入口：run_server.py
a = Analysis(
    [str(BACKEND / "run_server.py")],
    pathex=[str(BACKEND)],
    ...
)

# datas：拷贝到 exe 旁的资源文件
datas=[
    (str(REPO / "version.txt"), "."),          # → exe旁/version.txt
    (str(BACKEND / "config.yaml.example"), "."), # → exe旁/config.yaml.example
]

# hiddenimports：静态分析找不到的依赖（uvicorn协议、aiosqlite、platformdirs等）
hiddenimports=[ ... ]

# Tree：业务源码整树拷入 _internal/app/（app/无__init__.py，collect_all收不全）
app_tree = Tree(
    str(BACKEND / "app"),
    prefix="app",
    excludes=["__pycache__", "*.pyc"],
)

# COLLECT：onedir模式，所有文件收集到 dist/OmniAgentBackend/
coll = COLLECT(
    exe,
    a.binaries,
    a.datas,
    app_tree,
    name="OmniAgentBackend",
)
```

**为什么用 Tree 而不是 collect_all：** `app/` 目录没有 `__init__.py`（Python 命名空间包），PyInstaller 的 `collect_all("app")` 会跳过（报 `skipping data collection for module 'app' as it is not a package`）。用 `Tree()` 强制拷入整棵源码树，再由 `run_server.py` 的 `sys.path.insert(0, sys._MEIPASS)` 使运行时能正常 import。

## 五、构建步骤

### 5.1 一条命令构建

```powershell
cd F:\OmniAgentAs-repair\backend
E:\Appsw\python31311\Scripts\pyinstaller.exe OmniAgentBackend.spec --noconfirm
```

`--noconfirm` 表示自动覆盖上次构建产物，不弹确认框。

构建耗时约 30-120 秒（取决于机器性能）。

### 5.2 构建后收尾（必需）

PyInstaller 的 onedir 模式禁止 datas 目标指向 `..`（exe 上级目录），所以 `version.txt` 和 `config.yaml.example` 需要手动拷贝到产物目录：

```powershell
copy ..\version.txt dist\OmniAgentBackend\
copy config.yaml.example dist\OmniAgentBackend\
```

检查产物目录结构：

## 六、已知问题与优化方向

### 6.1 已知问题

| 问题 | 原因 | 影响 | 解决方式 |
|------|------|------|---------|
| document 工具注册失败 | `reportlab` 未安装到构建机 | PDF 生成工具不可用 | 构建前 `pip install reportlab` |
| win10toast 安装失败 | frozen 环境不能执行 `pip install` | 桌面通知不可用 | 非核心功能，可忽略 |
| torch/scipy 被间接拉入 | pycorrector 依赖链 | 产物体积膨胀至 915MB | 见 6.2 优化方向 |
| 启动时 warning：pysqlite2/MySQLdb/psycopg2 not found | 数据库方言的可选驱动 | 不影响 SQLite 核心功能 | 可忽略 |

### 6.2 优化方向

| 优化项 | 预估效果 | 做法 |
|--------|---------|------|
| 剔除 torch/scipy | -800MB | spec 中加 `excludes=["torch","scipy","torchvision","transformers","datasets","pyarrow"]` |
| UPX 压缩 | -20-30% | spec 中 `upx=True`（需安装 UPX） |
| strip 二进制 | -5-10% | spec 中 `strip=True` |
| 精简 pycorrector | 需评估 | 若不需要中文纠错，移除 requirements.txt 中的 pycorrector |

**当前产物未做任何精简**，完整包含了所有间接依赖。生产打包建议做上述优化后再构建。

## 七、附录：文件改动 diff 摘要

### 7.1 app/config.py（新增 get_frozen_dir）

```python
# 新增导入
import sys

# 新增函数
def get_frozen_dir() -> Optional[Path]:
    if getattr(sys, "frozen", False):
        return Path(sys.executable).resolve().parent
    return None

# _get_code_root 增加 frozen 分支
def _get_code_root() -> Path:
    global _CODE_ROOT
    if _CODE_ROOT is None:
        _frozen = get_frozen_dir()
        if _frozen is not None:
            _CODE_ROOT = _frozen
        else:
            _CODE_ROOT = Path(__file__).parent.parent.parent
    return _CODE_ROOT
```

### 7.2 app/logger/config.py（LOG_DIR 分流）

```python
from app.config import get_config, get_frozen_dir

_frozen = get_frozen_dir()
LOG_DIR = (_frozen / "logs") if _frozen is not None else Path(__file__).parent.parent.parent / "logs"
LOG_DIR.mkdir(exist_ok=True)
```

### 7.3 app/logger/prompt_logger.py（log_dir 分流）

from app.config import get_frozen_dir

# __init__ 中：
_frozen = get_frozen_dir()
if _frozen is not None:

self.log_dir.mkdir(parents=True, exist_ok=True)

### 7.4 app/file_persist.py（_files_root 分流）

```python
from app.config import get_config, get_frozen_dir

def _files_root() -> Path:
    try:
        if get_config().get("app.debug", False):
            _frozen = get_frozen_dir()
            if _frozen is not None:
                return _frozen / "files"
            return Path(__file__).resolve().parent.parent / "files"
    except Exception:
        pass
    return Path.home() / ".omniagent" / "files"
```
