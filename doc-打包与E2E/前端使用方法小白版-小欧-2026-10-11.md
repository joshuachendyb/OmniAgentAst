## 一、先确认后端在跑

前端只是页面，所有数据都问后端要。**先把后端跑起来**（详见《后端exe使用方法》），再弄前端。

确认方法：浏览器打开下面这个地址，看到 `healthy` 字样就是好的：

```
http://127.0.0.1:8500/api/v1/health
```

看不到 → 先去把后端弄好，前端不用试。

> 后端 exe **双击即可启动**，不用敲命令。它会自己监听 8500 并在控制台持续打印日志——
> **那个黑窗口不能关**，关了就等于把后端关了。

### 端口速记（最容易搞混的地方）

| 端口 | 谁用 | 记法 |
|---|---|---|
| **8500** | 后端（API） | 打包版 exe 无参启动就是它 |
| **2000** | 前端（页面） | 本文所有启动命令都用它 |
| 8000 | ❌ **别用** | 源码开发版后端才用，打包版不用 |
| 5173 | ❌ **别用** | 开发模式专用，见方式三 |

### 2000 这个端口是怎么定的

前端跑在哪个端口是自由的（1024~65535 都能用），但**必须和后端 CORS 白名单里写的一致**，否则浏览器会拦下跨域请求。当前约定用 **2000**，写在：

```
G:\Omni-AI\config\config.yaml
```

```yaml
network:
  cors_origins: "http://localhost:2000,http://127.0.0.1:2000"
```

两个地址都要在（`localhost` 和 `127.0.0.1` 算两个不同的源），少一个就有一边打不开。

## 二、启动前端（选一种）

### 方式一：Python 静态服务（最快，一条命令）

1. PowerShell 里敲：

```powershell
python -m http.server 2000 --directory G:\Omni-AI\frontend
```

2. 看到 `Serving HTTP on ... port 2000` 就是起来了。

3. 浏览器打开 **`http://127.0.0.1:2000`**

> ⚠️ **端口必须写**。不写默认占 8000，会和后端撞车起不来。
>
> 窗口保持开着，关窗口等于关前端。

### 方式二：Node 静态服务（推荐，支持刷新）

```powershell
npx --yes serve -s G:\Omni-AI\frontend -l 2000
```

`-s` 是 SPA 回退开关，**刷新任意子路由都正常**。同样打开 `http://127.0.0.1:2000`。

> 第一次用要现下载 `serve` 包，等一会儿是正常的。
>
> 方式一没有回退：首页能用、页面内点链接跳转也正常，
> **但地址栏停在 `/settings2` 这类子路径时按刷新会 404**。这是 `python -m http.server` 的固有限制，不是 bug。

## 三、第一次打开看到什么

| 看到 | 说明 |
|---|---|
| 聊天框 + 发送按钮 | ✅ 正常，前后端都通了 |
| 页面空白 / 转圈不停 | 后端没起，回去看第一章 |
| `设置加载失败` | 前端调不通后端：检查后端地址对不对 |
| `Network Error` 小黄条 | 同上；按 F12 看 Console 红字定位 |

**如果换过端口**：后端 CORS 白名单必须同步改成新端口，且**重启后端 exe**，否则浏览器会拦跨域请求。改的时候 `localhost` 和 `127.0.0.1` 是两个不同的源，两个都要加。

## 四、日常使用

| 动作 | 做法 |
|---|---|
| 发消息 | 输入框打字 → 回车（或点发送） |
| 停掉服务 | 关掉对应的黑窗口（前端一个、后端一个，各关各的） |
| 换前端端口 | 启动命令里改端口 + 后端 `config.yaml` 的 `cors_origins` 同步改 + **重启后端** |
| 改配置 | 前端设置页直接改（推荐）；手改 `config.yaml` 后刷新页面即可，后端配置热加载 |

> 「重启后端」= 关掉 exe 的黑窗口再双击一次。不重启，CORS 改动读不到，前端会报跨域错。

## 五、坏了找谁

| 症状 | 先看 |
|---|---|
| 页面打不开 | 服务窗口还在不在？端口是不是 **2000**（不是 8000）？ |
| 能打开但数据出不来 | `http://127.0.0.1:8500/api/v1/health` 通不通？F12 Console 红字是什么？ |
| 改了配置没生效 | CORS 改了要**重启后端**；前端包换了后端地址要**重打**（地址烘进 JS，改不了） |
| 子路径刷新 404 | 换方式二（Node 带 `-s`），或回根路径 |

## 六、目录说明

打包部署时前后端放同一个文件夹，**整个文件夹拷走即整套**：

```
G:\Omni-AI\
├── OmniAgentBackend.exe      后端程序（双击启动）
├── _internal\                后端依赖，别删
├── frontend\                 ← 前端静态包（本文启动的就是它）
│   ├── index.html
│   └── assets\
├── config\config.yaml        配置（含 CORS 白名单）
├── logs\                     日志
├── version.txt
├── config.yaml.example
└── OmniAgent.md              项目规则文件
```

**这个文件夹就是整个系统**——拷到别的电脑上照样跑，不需要装 Python。

---

## 七、想换台机器用

把 `G:\Omni-AI` 整个文件夹拷过去，双击 `OmniAgentBackend.exe`，
再开一个窗口起前端（第二章方式一或方式二），浏览器打开对应地址即可。

目标机器**不需要**装 Python，也不需要装 Node（方式二要用 Node，不方便就改用方式一）。
