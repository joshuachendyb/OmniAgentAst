## 一、背景与目标

右侧 step 查看区（RightViewer）在任务结束后，底部出现"任务统计条"：一条紧凑的统计标题条（TitleBlock）+ 一个可展开的静态统计块（StaticStatsBlock）。该区块是任务终态信息的唯一收口，直接对用户呈现"状态/耗时/模型/Token/工具/产出物"全部终态数据。

**目标**：摸清统计条当前结构，从数据、样式规范、信息层级、交互四类维度做一次全面视觉体检，找出问题并给出可落地的优化方向（本报告纯分析，不产生代码改动）。

### 2.2 TitleBlock 结构明细（TitleBlock.tsx）

**上行**（L78-103）：

| 元素 | 实现 | 样式 |
|------|------|------|
| 标题 | `任务统计`（Typography.Text strong） | FontSize.PRIMARY（14px） |
| 状态 | `PillBadge`（胶囊彩底白字，minWidth 80，shine 扫光） | 底色引 Colors 常量：SUCCESS / ERROR / BORDER.STRONG |
| 间距 | 空 `span` width 12px | 硬编码魔数 L83 |
| 运行耗时 | `运行耗时 Xs` | FontSize.SECONDARY（12px），去 secondary 恢复 AntD 默认黑色 |
| 间距 | 空 `span` width 15px | 硬编码魔数 L90 |
| 模型 | `provider / model` | FontSize.SECONDARY（12px），去 secondary 恢复 AntD 默认黑色；**仅 failed/cancelled 显示，completed 隐藏**（§四 4.2⑤定案） |
| 折叠 | `CircleArrow`（24px 圆形，折叠蓝 #4096ff → 展开粉 #ff4d94） | 引 Colors 令牌 FOLD_COLLAPSED/FOLD_EXPANDED + 发光 glow |

容器：`marginTop Spacing.LG / padding Spacing.MD Spacing.LG 0 / borderTop Colors.BORDER.LIGHT`，整行可点击折叠（含 title 悬停提示）。

**下行**（L105-125）：4 组 token `累计 P/C/T · 任务 P/C/T · 会话 P/C/T · 链 P/C/T`，11px secondary、`gap 8 + flexWrap wrap`，数据源 `formatTokenCompact`（stepStyles.ts:256）。

### 2.3 StaticStatsBlock 结构明细（StaticStatsBlock.tsx）

五个 section 复用 `sectionStyle`/`sectionTitleStyle`（L44-55，每节 = `marginTop10 + borderTop#f0f0f0 + paddingTop8`，标题 = `12px/500 + 左侧 2px PRIMARY 色条`）：

| 节 | 内容 | 关键实现 |
|------|------|---------|
| 基本信息 | grid 4 列（72px 标签位 ×2） | 开始 / 结束 / 事件 / LLM / 步数 / 模型（L112-162） |
| Token | 全量 `P/C/T` + 任务级/会话级/链级 | `formatTokenFull` + 三行 secondary L164-196 |
| 工具汇总 | 工具×次数 + 可折叠调用链(链式 A→B→C) | 文本 **▲/▼** 折叠三角 + params 截断 80 字符切片 L198-288 |
| 产出物 | 序号/工具/名称/类型/路径 | monospace 路径 ellipsis，11px 类型标签 L290-350 |
| 错误 | ⚠ `[type] message` 警示条 | 底色 #fff1f0 / 边框 #ffa39e hardcode（仅 error_message 存在时） |

### 3.5 后端根因 · X2 短信号裁剪回归（Token/模型显示异常的病根）
