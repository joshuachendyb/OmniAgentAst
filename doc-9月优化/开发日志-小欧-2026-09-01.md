## 一、左列任务列表滚动问题

### 1.1 问题现象
- 任务完成后，左侧任务列表**跳回第一个任务**（顶部），而非停留在最新任务。
- 用户期望：最新任务=实时任务=列表最后一个可见任务；任务完成后当前任务应停留在最新任务上，不跳走。

### 1.2 根因
- 任务完成 → `onSettledRefresh` → `refreshTasks()` → **`loading` 变 true**。
- `TaskListPanel` 旧代码 `if (loading) return <Skeleton/>` **把整个任务列表卸载换成骨架屏**。
- 左列滚动容器内容高度骤降 → 浏览器自动把 `scrollTop` **clamp 归零**（跳回顶部第一个）。
- 刷新结束列表回归，但 `scrollTop` 已停在顶部。

### 1.3 修复
- `TaskListPanel.tsx`：`if (loading)` → **`if (loading && tasks.length === 0)`**。
- 仅"首次加载无数据"时显骨架屏；刷新时保留旧列表，滚动位置不丢失。

### 1.4 验证
- tsc / lint / format 全部通过；`tasklistpanel-audit.test.tsx` 5 用例通过。

## 三、token 折行修复 + 三轮严格三堂会审

### 3.1 问题现象
- 任务统计块（StaticStatsBlock）"token终值"行 `P79201 / C2011 / T81212` 有时**折行**，与同行"最终状态/总耗时"不齐。

### 3.2 根因
- antd `<Descriptions column={3}>` 三列均分布局，"token终值"在第 3 列。
- token 文本 `/` 两侧**有空格**，浏览器视为**可断行点**；右侧查看区宽度收窄时第 3 列放不下 → 在空格处折行。

### 3.3 修复方案（nowrap + 紧凑格式，满足"不折行 + 不剪切"）
1. token 值加 `contentStyle={{ whiteSpace: 'nowrap' }}` —— **强制单行不折行**。
2. 格式紧凑化 `P79201/C2011/T81212`（去 `/` 两侧空格）—— 缩短文本、省宽度，降低溢出概率。

改动文件：`frontend/src/features/chat/components/right/StaticStatsBlock.tsx`
