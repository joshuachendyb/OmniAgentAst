### BUG-01：userScrolledUpRef 被 liveSteps 变化误重置（RV-01 + 场景1-a）

| 项目 | 内容 |
|------|------|
| **测试用例** | `audit-chat-page-30bugs.test.tsx:27` RV-01 |
| **场景复验** | `audit-scenario-verification.test.tsx:17` 隐藏期间 liveSteps 增长 |
| **病根** | `RightViewer.tsx:126` `if (isCurrentLive) userScrolledUpRef.current = false;` 每次 liveSteps 变化都触发 |
| **病因** | 路由切回实时任务时 isCurrentLive 从 false→true，userScrolledUpRef 被重置为 false，但用户在历史任务中上翻的状态不应被清除 |
| **影响** | 用户在历史任务中上翻→切回实时任务→ref 保持 true→不滚，属非预期行为 |

**代码 diff**：

```diff
// RightViewer.tsx:124-152
  useEffect(() => {
-   if (isCurrentLive) userScrolledUpRef.current = false;
    if (!isCurrentLive || liveSteps.length === 0) return;
    const container = findScrollContainer();
    const pipeline = pipelineEndRef.current;
    if (!container || !pipeline) return;
    const threshold = 120;
    const handleScroll = () => {
      userScrolledUpRef.current =
        container.scrollHeight - container.scrollTop - container.clientHeight >
        threshold;
    };
    container.addEventListener('scroll', handleScroll, { passive: true });
    const stickToBottom = () => {
      if (!userScrolledUpRef.current) {
        container.scrollTop = container.scrollHeight;
      }
    };
    const ro = new ResizeObserver(stickToBottom);
    ro.observe(pipeline);
    stickToBottom();
    return () => {
      ro.disconnect();
      container.removeEventListener('scroll', handleScroll);
    };
- }, [isCurrentLive, liveSteps.length, findScrollContainer]);
+ }, [isCurrentLive, findScrollContainer]);
```

**说明**：移除 `liveSteps.length` 依赖，避免 liveSteps 增长时重新挂载监听器并重置 userScrolledUpRef。
