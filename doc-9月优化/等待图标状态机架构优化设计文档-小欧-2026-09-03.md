## 二、状态机（直接看末段类型）

**编写人**: 小欧 - 2026-09-03 23:20:00

**核心思路**：buildSegments 里 observation 统一存为 `kind: 'obs'`，不挂 tool 上。waiting 一句搞定。

```ts
const lastSeg = segs[segs.length - 1];
const waiting = taskActive && (!lastSeg || lastSeg.kind === 'obs');
```

**互斥规则**：扳手由 ToolCallLine 在 `!hasResult && tools.length > 0` 时自己显示，obs 到达后 `hasResult=true` 扳手自动消失。绿圈和扳手天然互斥。

**状态表**：

| 末段类型 | waiting | 显示 |
|---------|:-------:|------|
| 无（start_info） | true | 绿圈 |
| obs | true | 绿圈 |
| tool（无 obs） | false | 扳手（ToolCallLine 自己管） |
| thinking | false | 都不显示 |
| text | false | 都不显示 |
| final | false | 都不显示 |
| error | false | 都不显示 |
