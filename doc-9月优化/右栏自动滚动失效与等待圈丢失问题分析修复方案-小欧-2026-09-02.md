## 一、背景与现状问题

### 1.1 北京老陈反馈（2026-09-02）

右侧查看区出现两类 UI 缺陷：

1. **右栏不自动上滚**：最新执行步骤/内容被盖住，尤其第一屏、HIT 弹框后、执行进行中都可能中招；
2. **等待圈丢失**：等待 thought 到来的转圈指示（SVG 缺口圆弧）在三种场景下必丢：首屏、HIT 挂起、HIT confirm 后。

### 1.2 前置修复为何无效（诚实复盘）

`c579d7b4e` 的 A/B/C 三处修复：

- **A**（RightViewer）：首帧 `requestAnimationFrame` 补发，消 ResizeObserver 断档漏触发——只补了时序，没治活页开关误判的死锁；
- **B**（RightViewer）：HIT confirm `highlightToolName` 值→null 时无条件滚底防阈值误拦——只治 confirm 一个点，且"无条件滚"本身会打断用户主动上翻；
- **C**（PipelineRenderer）：`waiting` 判定加 `highlightToolName` 保活，HIT 高亮时保持圈可见——只覆盖弹窗期间，confirm 后空窗仍丢圈。

三处都是**治标补点**，均未命中最底层判定逻辑，逐项被老陈验证落空。

## 二、根因分析（读全链路实码钉死，非猜测）

### 2.1 问题1：右栏不自动上滚 —— 滚动开关用"距底瞬态判定"

- 实码：`RightViewer.tsx` 旧逻辑 `isNearBottom = container.scrollHeight - container.scrollTop - container.clientHeight < 120`，作为「是否自动滚」开关。
- 缺陷：`isNearBottom` 是**瞬态快照**。首屏 `scrollTop=0`，只要首帧内容超过一屏+120px，判定恒 `false` → **永不触发自动滚**；流式逐帧增长过程中该值继续为 false，形成死锁；HIT/弹框造成 `clientHeight` 抖动时同样误判误拦。
- 参照对：消息区 `useChatScroll.ts:57-61` 的正确模式——**`scroll` 事件驱动维护「用户是否主动上翻」标志**，而非每次渲染时的距底阈值。右栏旧实现没有用这个已验证的模式。
- 附带问题：双 `requestAnimationFrame` 延迟滚底（07f38c3cd 已把驱动改为 ResizeObserver，但首帧丢失靠 RAF 补发）本质是拖延，新方案直接首帧直滚，弃 RAF。

### 2.2 问题2：等待圈丢失 —— `waiting` 绑死 `streaming` 单源

- 实码：`PipelineRenderer.tsx` 旧逻辑 `waiting = streaming && 末段非 thinking/text`；`streaming = activeTaskId === serverTaskId && receiving`。
- 三处必丢窗口（`streaming` 为 false 但任务事实上仍在进行）：

| # | 窗口 | 机制 | streaming 状态 |
|---|------|------|----------------|
| ① | 首屏 startinfo 已到、receiving=true | `serverTaskId→activeTaskId` 存在同步几拍延迟，singleton 内任务 ID 尚未对上 | false |
| ② | HIT 挂起 >60s | `useSSE.ts:582` 空闲超时触发重连 → `disconnect` 内 `setIsReceiving(false)` | false |
| ③ | HIT confirm 后、resumed/下一条前 | `highlightToolName` 已清 null，末段仍卡在 tool | false（此处 C 修复也失效） |

结论：`streaming` 是**瞬时连接态**，不能充当「任务仍在推进」的业务语义；等待圈必须由**任务级活跃态**撑起。

## 三、实施修改方法（三文件，均已落码工作区）

### 3.1 `frontend/src/features/chat/components/right/RightViewer.tsx`

**改动 A（badge 权威派生，接 PipelineRenderer 撑圈）**：

- Props 新增 `frames: TaskMetaFrames`（`RightViewer.tsx:67`），解构拿到（`:78`）；
- 内部调用 `const { badge: liveBadge } = useTaskInfo(liveSteps, frames ?? emptyMetaFrames(), receiving)`（`:89-93`）——**复用** `useTaskInfo` 的权威业务判定（`paused→running` 回推已在 `useTaskInfo.ts:109-170` 实现），渲染器**不重造**任何业务判断（DRY）；
- `PipelineRenderer` 调用处传 `badge={isCurrentLive ? liveBadge : undefined}`——非 live 历史回放不显示圈（边界语义保留）。

**改动 B（滚动开关改事件驱动，根治不自动上滚）**：

- 新增 `userScrolledUpRef`（`:102`）：语义 = 「用户是否主动上翻距底 >120px」；
- `container` 挂 `scroll` 监听维护标志（`:128-133`）：仅用户真实滚动触发；程序 `scrollTop=scrollHeight` 滚到底时距远<120 → 返回 false，不误判；
- 内容高度驱动改 `ResizeObserver` + **首帧立即直滚**（`:140-142`）：`stickToBottom = !userScrolledUpRef.current && (container.scrollTop = container.scrollHeight)`，挂 `ro.observe(pipeline)` 后立即调一次；
- **删除**：`isNearBottom` 距底瞬态判定、双 `requestAnimationFrame`、`prevHighlightRef`、`force` 无条件滚底分支。

**效果**：首屏从未滚动→标志 false→内容增长即滚底；HIT confirm 新内容到达即滚；用户真上翻读历史绝不打断；滚回底部自动恢复。

### 3.2 `frontend/src/features/chat/components/pipeline/PipelineRenderer.tsx`

**改动（waiting 由 streaming 单源改 taskActive 三源）**：

- Props 新增 `badge?: TaskBadge`（`:133`），默认未传（`:141` 注释：非 live 历史回放不传）；
- 判定改写（`:160-167`）：

```ts
const taskActive =
  streaming ||
  !!highlightToolName ||
  badge === 'running' ||
  badge === 'paused';
const waiting =
  taskActive &&
  (!lastSeg || (lastSeg.kind !== 'thinking' && lastSeg.kind !== 'text'));
```

- 三源对照三窗口：`streaming`（正常连接态）+ `highlightToolName`（HIT 弹窗中）+ `badge=running/paused`（任务级活跃，`useTaskInfo` 权威派生）：
  - 窗口①：startinfo 已到且 `receiving` → `badge=running` 撑圈；
  - 窗口②：HIT 挂起 >60s 空闲超时重连 `isReceiving` 瞬 false → `badge=paused` 撑圈；
  - 窗口③：confirm 后 resumed 前 `highlight` 已清 null → `badge` 仍 `paused` 撑圈。
- `waiting` 末段判定保持原样（末段非 thinking/text 才算等待，首 chunk 到达即消失，由内容覆盖接管）。

### 3.3 `frontend/src/features/chat/hooks/useChatPanels.tsx`

- `RightViewer` 增传 `frames={metaFrames}`（`:228`）——`useTaskInfo` 的 `badge` 派生需要 `startInfo` 帧判定 `running`（`useTaskInfo.ts:178-179`），`metaFrames` 即该输入源（同一 `metaFrames` 已传 `TaskInfoBar` 等，`useMemo` 依赖既有保留，零新依赖）。

## 四、三堂会审合规结论

| 审查 | 结论 |
|------|------|
| 合规（10 大规范） | SRP：滚动归属 RightViewer、等待圈判定归属 PipelineRenderer，互不越界；DRY：badge 复用 `useTaskInfo` 权威派生，渲染器零重造；KISS-DIRECT：滚动一条直线「标志+直滚」，判定一条直线「三源 OR」，无注册表/无中间层/无透传链 |
| 合理（逻辑最优雅） | 弃瞬态距底阈值 → 事件驱动标志（与消息区 `useChatScroll.ts:57-61` 已验证模式同语义）；弃 RAF 双帧 → ResizeObserver+首帧直滚；弃无条件滚底 → 尊重用户主动上翻 |
| 关联逻辑（无退化） | ①`streaming`/`highlight` 原语义全保留（三源是扩展非替换）；②非 live 历史回放 `badge=undefined`，圈不显示（边界不变）；③`paused→running` 回推机制（useTaskInfo.ts）继续生效，仅新增消费方；④滚动对用户上翻恢复行为与旧 120px 内滚动一致 |
| 禁止 backward | 无新旧双轨：旧 `isNearBottom`/RAF/force 判定一律移除，不保留旁路 |

## 六、边界场景穷举分析（十遍核查后穷举，无阻塞性遗漏确认）

### 6.1 等待圈边界（5 类）

| 场景 | 现象 | badge 来源 | taskActive | waiting | 结论 |
|------|------|-----------|-----------|---------|------|
| A. startinfo 还没到的窗口（发消息后几毫秒~几十毫秒） | hasStartInfo=false → badge=idle；streaming=false（同步窗口） | idle | false | false | ⚠ 严格来说漏圈，但 startinfo 极快到达，用户肉眼不可见，不需改 |
| B. 任务失败/取消瞬间 | final 步骤到达 → badge='failed'/'cancelled' | failed/cancelled | false | false | ✅ 圈正确消失 |
| C. HIT 弹窗关闭但任务仍挂起 | highlight 清 null；步骤中仍有 paused → badge='paused' | paused | true | true | ✅ 圈显示，告知"任务在等确认" |
| D. 多轮对话：第一轮完成，第二轮开始 | 第一轮 final → badge='completed'；第二轮 startinfo → badge='running' | completed→running | false→true | false→true | ✅ 正确切换 |
| E. badge=paused 后收到 resumed | resumed 步骤 → badge='running'；pausedIdx 重置为 -1（useTaskInfo:131-133） | running | true | 依末段 | ✅ 正确推回 |

### 6.2 滚动边界（6 类）

| 场景 | 现象 | userScrolledUpRef | 结论 |
|------|------|-------------------|------|
| F. 用户在任务A中上翻，切到任务B | useRef 在组件级别，不随任务切换重置 | true（保持） | ✅ 合理——用户主动上翻后切任务，不应被打断 |
| G. 用户在历史任务中上翻，切回实时任务 | 同上 | true（保持） | ✅ 合理——用户在浏览历史，不应被打断 |
| H. 流式输出中，用户快速滚到底部再滚回顶部 | scroll 事件多次触发，最终距底>120px | true | ✅ 正确——用户明确上翻，不滚 |
| I. 流式输出中，用户滚到底部附近（距底<120px） | scroll 事件：距底<120px | false | ✅ 正确——恢复自动滚 |
| J. 打字机逐字增长但内容高度不变（单行不换行） | ResizeObserver 不触发（高度不变），但用户已在底部 | false | ✅ 正确——不需要滚 |
| K. ResizeObserver vs scroll 事件首帧竞态 | 首帧 stickToBottom 同步执行一次，可能在 scroll 事件前 | 时序不确定 | ⚠ 竞态存在但影响极小：只在首帧可能发生一次，后续 ResizeObserver 异步触发时 scroll 事件已先设置标志，可接受 |

### 6.3 结论

**无阻塞性遗漏。** 三处丢失窗口被覆盖，所有边界场景被正确处理。

唯一可优化但不阻塞的边界：场景 A（startinfo 到达前几毫秒的漏圈窗口），用户肉眼不可见，不需改。

## 七、三场景深度分析（北京老陈 2026-09-02 驱动）

### 7.1 页面隐藏和恢复（浏览器 tab 切换、窗口最小化）

**机制**：`document.hidden=true` 时浏览器暂停部分渲染，ResizeObserver 停止触发。

| 区域 | 处理方式 | 行为 | 结论 |
|------|---------|------|------|
| 消息区（左栏） | `useChatScroll.ts:67-77` 监听 `visibilitychange`，页面恢复时 `scrollToBottomDelayed()` | 自动滚到底 | ✅ |
| 右栏（流水线） | RightViewer 无 `visibilitychange` 监听，靠 `ResizeObserver` 兜底 | 页面恢复 → 浏览器重新布局 → ResizeObserver 触发 → `stickToBottom()` | ✅ |
| 等待圈 | 后端持续发数据 → `liveSteps` 增长 → `useMemo` 重算 → badge 持续派生 | 圈不消失 | ✅ |

**边界**：页面隐藏期间用户无法操作滚动（焦点不在页面），`userScrolledUpRef` 不会被 scroll 事件改变 → 恢复后 `stickToBottom` 正常执行。

### 7.2 页面切换（React Router 路由跳转）

**机制**：`/` → `/history` → `/settings`，ChatPage 组件卸载/重挂载。

**卸载时**：RightViewer useEffect cleanup → `ro.disconnect()` + `removeEventListener` ✅

**重挂载时**：useEffect 重新执行 → 重新找容器、挂 ResizeObserver、挂 scroll 监听、首帧 `stickToBottom()` ✅

**发现问题与修复**：

`userScrolledUpRef` 是 `useRef(false)`，组件级别，不随卸载重置。如果用户在历史任务中上翻了（`userScrolledUpRef=true`），切回实时任务时 ref 仍为 `true` → 实时任务不自动滚 → **用户可能期望切回实时任务时看到最新内容**。

**修复**：RightViewer useEffect 开头加 `if (isCurrentLive) userScrolledUpRef.current = false;`——切回实时任务时重置上翻标志，确保恢复自动滚。

### 7.3 弹框弹起和关闭后（HIT AuthorizationModal）

**弹窗弹起**：
- `authorizationPending` 有值 → `highlightToolName` 有值 → `taskActive=true` → **圈显示** ✅
- Ant Design Modal overlay 覆盖在内容上方，**不改变底层容器高度** → 滚动位置不变 ✅

**弹窗关闭后**：
- `handleAuthorizationConfirm` → `setAuthorizationPending(null)` → `highlightToolName=null`
- badge 状态取决于后端是否已发 `resumed` 事件：
  - `resumed` 已到 → badge='running' → taskActive=true → **圈仍显示**，等到内容段到达后消失 ✅
  - `resumed` 未到 → badge='paused' → taskActive=true → **圈仍显示** ✅
  - `resumed` 到达 → badge='running' → 末段变 thinking/text → **圈消失** ✅

**弹窗关闭后自动滚**：
- overlay 消失 → 容器高度恢复 → ResizeObserver 触发 → `stickToBottom()` 执行（若 `userScrolledUpRef=false`）→ **自动滚到底** ✅
- 若用户在弹窗打开期间滚动了页面 → scroll 事件设置 `userScrolledUpRef=true` → 弹窗关闭后 `stickToBottom` 跳过 → **不自动滚**（正确——用户主动上翻不应打断）

**60 秒超时自动拒绝**：
- 超时 → `taskControlApi.confirm(false)` → `setAuthorizationPending(null)` → 弹窗关闭
- badge 仍为 paused（后端可能还没发 resumed）→ **圈仍显示** → 后端处理后发 resumed/final → badge 变化 → **圈消失** ✅

### 7.4 汇总

| 场景 | 自动上滚 | 等待圈 | 结论 |
|------|---------|--------|------|
| 页面隐藏恢复 | ✅ ResizeObserver 兜底 | ✅ badge 持续派生 | 正确 |
| 页面切换（路由） | ✅ 已修复：isCurrentLive 重置 ref | ✅ badge 重新派生 | 已修复 |
| 弹窗弹起 | ✅ 容器高度不变 | ✅ highlight+badge=paused 撑圈 | 正确 |
| 弹窗关闭 | ✅ ResizeObserver 兜底 | ✅ badge 保持直到 resumed | 正确 |
