## 一、设计目标（v4.0 收敛为七条）

1. **单一设置入口**：用户视角只有一个"设置"。旧页文件零改动、旧路由保留可访，导航只留一个入口指向新页。
2. **显示即生效**：页面显示的值 = 后端实际生效的值；被环境变量接管的项明确标注来源并只读。
3. **单存储**：所有数据存一个 `config.yaml`，无第二存储。
4. **前门后门**：设置页面服务与后端业务服务读取逻辑完全独立；写按 key 分区——旧键走 `config_service.update_config`（语义不变），新键走通用 region 合并（同套备份+原子写+回滚机制）。时序和信息量完全不同。
5. **易用性**：搜索框快速定位、全局保存条一次保存所有改动、跨Tab脏态可见、初始化全量加载零延迟切Tab。
6. **诚实标注**：没接消费方的配置项不标"生效"；密钥永不明文下发；未接入项明确说明；深色二期标注工作量前提。
7. **健壮**：原子重命名防半写 + 最近 5 个编号备份链（backup.1 最新~backup.5 最旧）+ FIFO 清理 + 启动校验失败自动用备份恢复。

## 三、新架构总览（编排器模式 + 有效值透明）

### 3.1 一页看懂的数据流

```
【房间：config.yaml —— 同一个配置底文件】

【前门：设置页面服务（settings_service + model_service，完全独立）】
settings_service（读+写独立实现，不依赖 config_service 的读取逻辑）
  读：自己解析 config.yaml → 组装 {groups:{data,sources,mtime}} + env标注 + 脏态
  写：自己校验 patch → 调 config_service.update_config（原子重命名+备份链）→ config.yaml
  API：GET/PUT /api/v1/settings（6组参数）
model_service（读+写独立实现，属于设置页面服务的一部分）
  读：自己解析 config.yaml 的 models/provider_config 区域
  写：自己校验 → 调 config_service.update_config → config.yaml
  API：GET/POST/PUT/DELETE /api/v1/models /api/v1/providers

【后门：后端业务服务（config_service，完全独立）】
config_service（读+写独立实现，不依赖 settings_service）
  读：直接读 config.yaml → get_setting(key, default) 返回有效值（含env覆盖）
  写：直接调 config_service.update_config → config.yaml
  调用：后端任何位置（chat/stream 等）直接调用，无需经过 settings_service

【两者关系】
- 读：完全分开，各自独立实现，互不依赖
- 写：旧键走 config_service.update_config（FIELD_HANDLERS 语义不变），新键走通用 region 合并；两条路径共享同套备份+原子写+回滚机制
- 存储：同一个 config.yaml
- 时序：设置页面（人操作，慢，校验+脏态+确认） vs 后端业务（系统自动，快，实时）
- 信息量：设置页面（groups/sources/mtime/env标注/脏态） vs 后端业务（key/value 直接取）
- mtime 感知：设置页面首次加载时记录 config.yaml mtime；切 Tab/刷新时检查 mtime，若后门修改了文件（mtime 变）则自动重新 GET /settings 刷新

### 3.2 七大铁律

1. **后端唯一真相源**：key、类型、默认值、值域、存储、生效、来源规则，只在 registry 定一次；key 全局唯一，启动自检发现重复直接拒启。**存储位置统一为 YAML（`config/config.yaml`），无第二存储。**
2. **读写前门后门**：设置页面（settings_service+model_service）与后端业务（config_service）完全独立。读：各自实现，互不依赖。写：旧键走 `config_service.update_config`，新键走通用 region 合并，两条路径共享同套备份+原子写+回滚机制。时序和信息量完全不同。
3. **显示即生效**：GET 返回有效值 + 每项来源；env 项只读并标注。
4. **密钥与生效诚实**：secret 永不返明文；无消费方的项不标生效；未接入项明确说明。
5. **一次全量 + 零延迟切Tab**：初始化全量拉取所有组值，切 Tab 不重新请求。
6. **全局状态 + 全局保存**：单 hook 管理全部组数据与脏态，底部"保存全部"一次提交所有改动。
7. **模型管理 CRUD 完整**：模型/Provider 支持查看、增加、删除、修改全生命周期操作；属于设置页面服务的一部分，前端四个区域完整覆盖。

### 5.2 接口契约

```
【参数配置接口】
GET  /api/v1/settings
  → {groups:{key:{data,sources,mtime}}, version:"", mtime:""}  # 一次全量返回全部 6 组 + config.yaml mtime
GET  /api/v1/settings?group=X  # 按需刷新单组
  → {data:{...}, sources:{...}, mtime:""}
PUT  /api/v1/settings  body={patch:{...}}
  → {ok:true, updated:[{key, source}], need_restart:[], warnings:[]}

前端 mtime 感知逻辑：
- 首次 GET /settings → 记录返回的 config.yaml mtime
- 切 Tab / 手动刷新 → 检查 config.yaml mtime 是否变化
  → mtime 变了（后门修改了）→ 重新 GET /settings 刷新全部数据
  → mtime 没变（自己修改的）→ 缓存命中，零延迟

【模型管理接口】
GET  /api/v1/models
  → {providers:[{name,label,api_base,models:[{name,label,default_params,range,capabilities}]}], current_model_ref:{provider,model}}
POST /api/v1/models  body={provider,model,label,default_params,range,capabilities}
  → {ok:true, providers:[...], current_model_ref:...}
PUT  /api/v1/models/{provider}/{model}  body={default_params,range,capabilities}
  → {ok:true, model:...}
DELETE /api/v1/models/{provider}/{model}
  → {ok:true, switched_to:"default_model"|null}  # 如果删除的是当前模型，返回切换目标

GET  /api/v1/providers
  → [{name,label,api_base,models:[...]}]
POST /api/v1/providers  body={name,label,api_base}
  → {ok:true, provider:...}
PUT  /api/v1/providers/{name}  body={api_key,base_url,timeout,retry_times}
  → {ok:true, provider:...}  # Provider配置更新，立即生效
DELETE /api/v1/providers/{name}
  → {ok:true, switched_to:"default_provider"|null}  # 级联删除所有子模型
```

要点：
- 单 YAML 存储。设置页面服务（settings_service+model_service）与后端业务服务（config_service）读取逻辑完全独立；写按 key 分区：旧键走 `config_service.update_config`，新键走通用 region 合并，两条路径共享同套备份+原子写+回滚机制。文本文件天然完整：写时原子重命名 + 最近 5 个备份链（FIFO 清理）。
- 旧 `/config/*` 路由保留兼容；新页只调 `/settings/*`，旧页照旧调 `/config/*`（同库同源）。
- 读：设置页面服务（settings_service+model_service）与后端业务服务（config_service）完全独立，各自实现读取逻辑，互不依赖。写：旧键走 `config_service.update_config`，新键走通用 region 合并，两条路径共享同套备份+原子写+回滚机制。时序和信息量完全不同。

env 契约：
- GET 对被环境变量接管的项返回有效值 + `sources[key]="env"`；页面整行只读并标注"来自环境变量"。
- PUT 含 env 接管项 → 该项拒绝写入，`warnings` 提示，不影响 patch 内其他项。

模型管理契约：
- 添加模型：校验 provider 存在 + model 名在 Provider 内唯一 → 写入 config.yaml 的 `models.{provider}.models.{model}` → 写入后需重启生效（registry 重建）
- 删除模型：若删除当前模型 → 自动切换回 Provider 的默认模型 → 返回 `switched_to`
- 删除 Provider：级联删除所有子模型 → 若当前 Provider 被删除 → 切换回默认 Provider → 返回 `switched_to`
- Provider 配置（api_key, base_url, timeout）：立即生效（下次 LLM 调用使用新配置），无需重启

secret 契约：
- GET 对 secret 项永不返回明文，只返回 `{configured:true, suffix:"末4位"}`。
- PUT secret 项：带 `value` 非空 = 更新；缺省/空 = 保持原值；`{clear:true}` = 显式清空。

更新返回值 `updated` 结构：
- 返回每项的来源 `{key, source:"yaml"|"env"}`，方便前端标注 env 接管项。

### 6.2 状态设计（全局单层 state）

- **全局 state**：`useSettings()`（唯一 state 层，管理全部 6 组数据 + 脏态 + sources + 模型管理状态）。首次加载 `getAll()` 一次全量拉取（schema + 全部组值）+ `getModels()` 模型列表 → 内存缓存；切 Tab 零延迟。
- **模型管理状态**：
  ```typescript
  interface ModelState {
    providers: Array<{name, label, api_base, models:[{name,label,default_params,range,capabilities}]}>;
    selectedProvider: string;
    selectedModel: string;
    params: Record<string, any>;          // 当前模型的参数值
    defaults: Record<string, any>;        // 当前模型的默认参数
    ranges: Record<string, {min, max}>;   // 当前模型的参数范围
    envOverride: Record<string, boolean>; // env 接管标记
    providerConfig: Record<string, {api_key, base_url, timeout}>;
    isDirty: boolean;                     // 是否有参数被修改
    editingProviderConfig: boolean;       // Provider配置是否在编辑模式
    addModelModalOpen: boolean;           // 添加模型弹窗
    addProviderModalOpen: boolean;        // 添加Provider弹窗
    deleteConfirmOpen: boolean;           // 删除确认弹窗
    deleteTarget: string | null;          // 待删除目标
  }
  ```
- **局部状态**：每 Tab 内 `SettingsGroup` 只管表单渲染 + 局部脏态（该组哪些项改了），汇总到全局 state。
- 仅外观 fontSize/density 做本地预应用：改控件即写 `localStorage["omni.prefs.v1"]` + 预览；保存成功后对齐；后端不可达时外观 Tab 仍可本地试玩（纯本地，不承诺落盘）。
- 其余分组无本地缓存：以后端为准；后端不可达 → 整 Tab 错误态（`Result` + 重试），不展示过期值。
- **模型 Tab 脏态计算**：`isDirty = params[key] !== defaults[key] && !envOverride[key]`；切换模型时未修改的参数恢复为新模型默认值，已修改的参数保留。

### 6.3 页面读写流程

**读（首次加载）**：`getAll()` 一次全量 + `getModels()` 模型列表 → schema + 全部组值 + sources + providers/models 进全局 state；记录 config.yaml mtime；所有 Tab 渲染完毕，切零延迟。

**读（切 Tab / 刷新）**：检查 config.yaml mtime
- mtime 没变（自己修改的，已知状态）→ 缓存命中，零延迟
- mtime 变了（后门修改了）→ 重新 `getAll()` 刷新全部数据

**写（参数配置）**：改控件 → 全局 state 记录脏态 → [保存本组] 或底部 [保存全部] → schema 校验 → `PUT /settings {patch}` → 成功（含重启 Modal）/ 失败 `handleApiError` + 回滚。

**写（模型管理 CRUD）**：
- 添加模型：弹窗填表单 → `POST /models` → 后端写入 config.yaml → 刷新模型列表 → 选中新模型
- 删除模型：弹窗确认 → `DELETE /models/{provider}/{model}` → 若当前模型被删除，自动切换回默认模型 → 刷新列表
- 添加Provider：弹窗填表单 → `POST /providers` → 刷新Provider列表 → 选中新Provider
- 删除Provider：弹窗确认（级联警告）→ `DELETE /providers/{name}` → 级联删除所有子模型 → 刷新列表
- 修改Provider配置：编辑表单 → `PUT /providers/{name}` → 立即生效

### 6.4 搜索与全局脏态

- **搜索框**：页面顶部右上角，Input.Search；按 key（如 `app.language`）和显示名（如"日志级别"）过滤，全部 6 分组参与搜索；匹配项高亮并自动切到对应 Tab 定位。
- **全局脏角标**：顶部 Tab 栏旁显示"有 N 项未保存"（从全局 state 聚合）；切 Tab 时若目标 Tab 有未保存项，弹 Modal 提示。
- **底部保存栏**：`[保存本组]`（当前 Tab 脏时可用）+ `[保存全部]`（全局任意脏时可用，N 项一起提交）。
- **模型 Tab 特殊脏态**：参数区有 `[已修改]` 标记时，`[保存本组]` 可用；Provider 配置区有编辑内容时，`[保存本组]` 也可保存 Provider 配置变更。

### 6.5 模型 Tab 四个区域

模型 Tab 分为四个视觉区域：

| 区域 | 内容 | 操作 |
|------|------|------|
| ① 选择器 | Provider 下拉 + Model 下拉（双联动）+ 能力标签 | 切换 Provider/Model |
| ② 参数区 | 当前模型的所有可配参数（跟随模型）+ 范围 + 默认值 + [已修改] 标记 | 修改参数值、重置为默认 |
| ③ 配置区 | 当前 Provider 的配置（api_key、base_url、timeout、retry_times） | 编辑 Provider 配置 |
| ④ 操作区 | [+]添加模型、[+]添加Provider、[删除此模型]、[删除此Provider] | CRUD 操作 |

### 6.6 模型管理弹窗

- **添加模型弹窗**：Provider 下拉 + 模型名输入 + 默认参数（上下文窗口、温度范围、思考力度）+ 能力标签 → `POST /models`
- **添加Provider弹窗**：名称 + 显示名 + API地址 → `POST /providers`
- **删除确认弹窗**：目标名 + 警告（"删除模型将切换为默认模型" / "删除Provider将级联删除所有子模型"）→ `DELETE /models` 或 `DELETE /providers`

### 6.7 备份链命名统一（前端展示）

- 备份文件统一命名 `config.yaml.backup.1`（最新）~ `config.yaml.backup.5`（最旧），前端若展示备份列表按此编号。
- 旧 `/config/*` 路由保留兼容；新页只调 `/settings/*`，旧页照旧调 `/config/*`（同库同源）。

### 7.5 保存 / 还原 / 脏状态 / 重启生效

```
【参数配置流】
Tab 内改动 → 脏态 → [保存本组]可用
  → 点[保存本组] → schema 校验
    → 通过 → PUT /settings {仅改动项}
      → 成功：success toast；含重启项 → Modal 列出；含 env 拒绝 → warnings 提示
      → 失败：handleApiError + 回滚
    → 不通过：首个错误控件红框 + 定位
  → [还原默认] → 确认 Modal → 按当前模型 schema.default 重置 → 脏态清空
切 Tab 有未保存 → Modal[保存并切换/放弃修改/取消]

【模型管理流】
模型参数改动 → 脏态(params≠defaults) → [保存本组]可用
  → 范围外值自动截断 + toast
  → PUT /settings {model_ref + 模型级参数} 或 PUT /providers {config}
    → 成功：defaults 更新 → 脏态清空
    → 失败：handleApiError + 回滚 params 到保存前值
添加模型 → 弹窗 → POST /models → 刷新列表
删除模型 → 确认弹窗 → DELETE /models → 若当前模型被删 → 自动切默认模型
删除Provider → 级联确认 → DELETE /providers → 级联删除所有子模型
```

### 7.7 密钥与危险项

- **api_key**：GET 只返 `{configured:true, suffix:"末4位"}`；常态显示"已配置 ····末4位"+[修改]；PUT 带 `value`=更新、缺省/空=保持、`clear:true`=清空。
- **危险操作/黑白名单**：保存二次确认 Modal（UX 层）。注意：后端安全门禁独立于 UI 开关——无论 `confirmDangerousOps` 开关状态如何，后端对危险命令的执行判断都独立生效；UI 开关只影响"是否在提交前弹窗确认"，不影响后端拦截。
- **只读项**：禁用态 + 复制按钮。

### 7.8 加载 / 空 / 错误 / mtime 刷新

| 状态 | UI 表现 |
|------|---------|
| 首次加载 | Tab 内容区 `Skeleton` |
| schema 失败 | 整 Tab `Result` + [重试]；toast 走 `handleApiError(SETTINGS_SCHEMA_FAILED)` |
| 组内无项 | 占位"暂无设置项" |
| 保存失败/后端不可达 | `handleApiError` 统一提示；非外观 Tab 整页错误态（不展过期值），外观 Tab 本地模式 |
| mtime 变化（后门修改） | 自动重新 `GET /settings` 刷新全部数据，toast 提示"配置已更新，已刷新" |

"""
settings_service — 设置页 6 组服务（3.1 前门：读+写完全独立，不依赖 config_service 读取逻辑）
读：自己解析 config.yaml → {groups:{data,sources,mtime}} + env 标注 + secret 掩码

编辑历史:

  2026-09-20 - 小沈 - 核查 B1/B2/B5：掩码改调 config_helpers.mask_secret_value（消与 model_service 重复）；

def _raw_config() -> Dict[str, Any]:
    """读 YAML 原始值（不经 env 覆盖）。"""
    return read_yaml_config(Path(get_config_path()))


def _get_dotted(data: Dict[str, Any], key: str, default: Any = None) -> Any:
    """点号键取值（config_path/version 等虚拟只读键返回 default）。"""
    node: Any = data
    for part in key.split("."):
        if isinstance(node, dict) and part in node:
            node = node[part]
        else:
            return default
    return node


def _resolved(key: str, default: Any = None) -> Any:
    """读后端实际生效值（含 env 覆盖）。"""
    return get_config().get(key, default)


def app_version() -> str:
    """读 version.txt 首个非空行（公开函数，供 settings_routes 复用；不 import main，避免层倒挂）。"""
    try:
        vf = Path(get_code_root()) / "version.txt"
        if vf.exists():
            with open(vf, "r", encoding="utf-8") as f:
                for line in f:
                    v = line.strip().lstrip("﻿")
                    if v:
                        return v
    except Exception as e:
        logger.warning(f"读取 version 失败: {e}")
    return "0.0.0"


def _item_data(key: str, item: Dict[str, Any], raw: Dict[str, Any]) -> Tuple[Any, str]:
    """单项有效值 + 来源：只读虚拟键特殊组装；其余比较 YAML 原始 vs 生效值判 env。"""
    if key == "config_path":
        return str(get_config_path()), "ro"
    if key == "version":
        return app_version(), "ro"
    raw_val = _get_dotted(raw, key, item["default"])
    eff_val = _resolved(key, item["default"])
    if item.get("secret"):
        return mask_secret_value(eff_val), ("env" if eff_val != raw_val else "yaml")
    if eff_val != raw_val:
        return eff_val, "env"
    return raw_val if raw_val is not None else item["default"], "yaml"

# 写：校验 + 分区（旧键走 update_config，新键走通用合并）
# ------------------------------------------------------------------

def _validate_value(item: Dict[str, Any], value: Any) -> Optional[str]:
    """单值按 schema 校验，返回错误文案或 None。"""
    if item.get("readonly"):
        return f"{item['key']} 为只读项"
    t = item["type"]
    if value is None:
        return None
    if t == "bool" and not isinstance(value, bool):
        return f"{item['key']} 应为 bool"
    if t == "int" and not isinstance(value, int):
        return f"{item['key']} 应为整数"
    if t in ("float", "range") and not isinstance(value, (int, float)):
        return f"{item['key']} 应为数字"
    if item.get("range"):
        lo, hi = item["range"]
        if not (lo <= float(value) <= hi):
            return f"{item['key']} 超出范围 [{lo}, {hi}]"
    if item.get("options") and value not in item["options"]:
        return f"{item['key']} 非法选项"
    if t == "model_ref" and not (isinstance(value, dict) and value.get("provider") and value.get("model")):
        return "ai.model_ref 应为 {provider, model} 结构"
    return None


def update_settings(patch: Dict[str, Any]) -> Dict[str, Any]:
    """PUT /settings {patch}：只处理改动项；env 接管项拒绝写入进 warnings（5.2）。"""
    raw = _raw_config()
    updated: List[Dict[str, str]] = []
    need_restart: List[str] = []
    warnings: List[str] = []
    errors: List[str] = []
    old_fields: Dict[str, Any] = {}
    security_fields: Dict[str, Any] = {}
    new_region: Dict[str, Any] = {}

    for key, value in patch.items():
        item = get_item(key)
        if item is None:
            errors.append(f"未知 key: {key}")
            continue
        err = _validate_value(item, value)
        if err:
            errors.append(err)
            continue
        # env 接管项：拒绝写入（5.2 env 契约）
        _, src = _item_data(key, item, raw)
        if src == "env":
            warnings.append(f"{key} 被环境变量接管，已跳过")
            continue
        if item.get("restart") and _get_dotted(raw, key, item["default"]) != value:
            need_restart.append(key)
        mapped = OLD_KEY_MAP.get(key)
        if mapped == "ai_model_ref":
            old_fields["ai_model_ref"] = ModelRef(**value)
            updated.append({"key": key, "source": "yaml"})
        elif mapped:
            old_fields[mapped] = value
            updated.append({"key": key, "source": "yaml"})
        elif key.startswith("security.") and key.split(".", 1)[1] in SECURITY_KNOWN:
            security_fields[key.split(".", 1)[1]] = value
            updated.append({"key": key, "source": "yaml"})
        else:
            new_region[key] = value
            updated.append({"key": key, "source": "yaml"})

    if errors:
        return {"ok": False, "updated": [], "need_restart": [], "warnings": warnings, "errors": errors}
    if security_fields:
        old_fields["security"] = security_fields
    if old_fields:
        update_config_service(ConfigUpdate(**old_fields))  # 旧键语义不变（FIELD_HANDLERS）
    if new_region:
        merge_region_patch(new_region, scope="settings")

"""
model_service — 模型编排器（位于 model 域，与 config_service/config_helpers/resolver 同域聚合）
读：解析 config.yaml 的 models/provider_config 区域（动态遍历 provider，禁止硬编码 provider 名，
与旧页铁律一致）；写：校验 → config_helpers.merge_region_patch → config.yaml。
current_model_ref 与旧扁平 ai.provider/ai.model 双写保持同步（纯加法，不改旧逻辑）。

编辑历史:
  2026-09-20 - 小沈 - 新建：5.2 模型管理契约（合并返回/级联/switched_to/立即生效）
  2026-09-20 - 小沈 - 核查 B1/B2/A2：掩码改调 config_helpers.mask_secret_value；合并写改调
    config_helpers.merge_region_patch（消私有跨域）；delete_model 删光当前 provider 模型时跨
    provider 回退，不写空 model_ref
"""
from pathlib import Path
from typing import Any, Dict, List, Optional

from app.logger import logger
from app.services.model.config_helpers import (
    get_config_path,
    mask_secret_value,
    merge_region_patch,
    read_yaml_config,

RESERVED_AI_KEYS = {"provider", "model", "model_ref"}


def _raw_ai() -> Dict[str, Any]:
    """读 config.yaml 的 ai 整块。"""
    raw = read_yaml_config(Path(get_config_path())) or {}
    ai = raw.get("ai", {})
    return ai if isinstance(ai, dict) else {}


def _provider_names(ai: Dict[str, Any]) -> List[str]:
    """动态遍历 provider 名（禁止硬编码）。"""
    return [k for k, v in ai.items() if isinstance(v, dict) and k not in RESERVED_AI_KEYS]


def get_current_ref(ai: Dict[str, Any], providers: List[str]) -> Dict[str, str]:
    """当前模型：优先 ai.model_ref 结构，回退旧扁平 ai.provider/ai.model。"""
    ref = ai.get("model_ref")
    if isinstance(ref, dict) and ref.get("provider") and ref.get("model"):
        return {"provider": str(ref["provider"]), "model": str(ref["model"])}
    provider = str(ai.get("provider") or (providers[0] if providers else ""))
    models = _models_of(ai, provider)
    model = str(ai.get("model") or (models[0]["name"] if models else ""))
    return {"provider": provider, "model": model}


def _models_of(ai: Dict[str, Any], provider: str) -> List[Dict[str, Any]]:
    """某 provider 下模型列表（models[] 元素可为 str 或 dict）。"""
    p = ai.get(provider, {})
    raw_models = p.get("models", []) if isinstance(p, dict) else []
    out: List[Dict[str, Any]] = []
    for m in raw_models:
        if isinstance(m, str):
            out.append({"name": m, "label": m, "default_params": {},
                        "range": {}, "capabilities": []})
        elif isinstance(m, dict) and m.get("name"):
            out.append({"name": str(m["name"]), "label": str(m.get("label", m["name"])),
                        "default_params": m.get("default_params", {}) or {},
                        "range": m.get("range", {}) or {},
                        "capabilities": m.get("capabilities", []) or []})
    return out


def get_models() -> Dict[str, Any]:
    """GET /models：providers/models 层级 + current_model_ref（11-17 合并返回）。"""
    ai = _raw_ai()
    providers = []
    for name in _provider_names(ai):
        p = ai[name]
        providers.append({"name": name, "label": str(p.get("label", name)),
                          "api_base": str(p.get("api_base", "")),
                          "api_key": mask_secret_value(p.get("api_key", "")),
                          "timeout": p.get("timeout", 60),
                          "models": _models_of(ai, name)})
    return {"providers": providers,
            "current_model_ref": get_current_ref(ai, [p["name"] for p in providers])}


def get_providers() -> List[Dict[str, Any]]:
    """GET /providers：provider 列表（含掩码 key）。"""
    return get_models()["providers"]


def _sync_current(region: Dict[str, Any], provider: str, model: str) -> None:
    """current 双写同步：新结构 + 旧扁平（加法，不改旧消费方）。"""
    region["ai.model_ref"] = {"provider": provider, "model": model}
    region["ai.provider"] = provider
    region["ai.model"] = model


def add_model(provider: str, model: str, label: str = "",
              default_params: Optional[Dict[str, Any]] = None,
              range_: Optional[Dict[str, Any]] = None,
              capabilities: Optional[List[str]] = None) -> Dict[str, Any]:
    """POST /models：校验 provider 存在 + provider 内 model 名唯一 → 写入。"""
    ai = _raw_ai()
    if provider not in _provider_names(ai):
        raise ValueError(f"Provider 不存在: {provider}")
    if any(m["name"] == model for m in _models_of(ai, provider)):
        raise ValueError("同名模型已存在")
    models = list(ai[provider].get("models", []) or [])
    models.append({"name": model, "label": label or model,
                   "default_params": default_params or {},
                   "range": range_ or {}, "capabilities": capabilities or []})
    merge_region_patch({f"ai.{provider}.models": models}, scope="model")
    return {**get_models(), "ok": True}


def update_model(provider: str, model: str, fields: Dict[str, Any]) -> Dict[str, Any]:
    """PUT /models/{provider}/{model}：改 default_params/range/capabilities/label。"""
    ai = _raw_ai()
    models = list(ai.get(provider, {}).get("models", []) or [])
    hit = False
    for i, m in enumerate(models):
        name = m if isinstance(m, str) else m.get("name")
        if name == model:
            base = {"name": model} if isinstance(m, str) else dict(m)
            for k in ("label", "default_params", "range", "capabilities"):
                if fields.get(k) is not None:
                    base[k] = fields[k]
            models[i] = base
            hit = True
    if not hit:
        raise ValueError(f"模型不存在: {provider}/{model}")
    merge_region_patch({f"ai.{provider}.models": models}, scope="model")
    return {"ok": True, "model": model}


def delete_model(provider: str, model: str) -> Dict[str, Any]:
    """DELETE /models：删当前模型 → 自动切回默认模型（switched_to）；若该 provider 已无模型，
    跨 provider 回退到首个可用模型，不写空 model_ref（A2）。"""
    ai = _raw_ai()
    models = [m for m in (ai.get(provider, {}).get("models", []) or [])
              if (m if isinstance(m, str) else m.get("name")) != model]
    region: Dict[str, Any] = {f"ai.{provider}.models": models}
    switched_to = None
    cur = get_current_ref(ai, _provider_names(ai))
    if cur["provider"] == provider and cur["model"] == model:
        names = [(m if isinstance(m, str) else m.get("name")) for m in models]
        if names:
            _sync_current(region, provider, names[0])
            switched_to = names[0]
        else:
            rest = [n for n in _provider_names(ai) if n != provider]
            target_p, target_m = "", ""
            for n in rest:
                ms = _models_of(ai, n)
                if ms:
                    target_p, target_m = n, ms[0]["name"]
                    break
            _sync_current(region, target_p, target_m)
            switched_to = target_m or None
    merge_region_patch(region, scope="model")
    return {"ok": True, "switched_to": switched_to}


def add_provider(name: str, label: str = "", api_base: str = "",
                 api_key: str = "", model: str = "", timeout: int = 60) -> Dict[str, Any]:
    """POST /providers：name 唯一 → 写入 ai.{name} 块。"""
    ai = _raw_ai()
    if name in _provider_names(ai):
        raise ValueError("同名 Provider 已存在")
    merge_region_patch({f"ai.{name}": {
        "label": label or name, "api_base": api_base, "api_key": api_key,
        "timeout": timeout, "models": ([model] if model else [])}}, scope="model")
    return {"ok": True, "provider": name}


def update_provider_config(name: str, fields: Dict[str, Any]) -> Dict[str, Any]:
    """PUT /providers/{name}：改 api_key/base_url/timeout → 下次 LLM 调用立即生效。"""
    ai = _raw_ai()
    if name not in _provider_names(ai):
        raise ValueError(f"Provider 不存在: {name}")
    region = {}
    key_map = {"api_key": "api_key", "base_url": "api_base", "api_base": "api_base",
               "timeout": "timeout", "retry_times": "max_retries", "max_retries": "max_retries"}
    for k, v in fields.items():
        if k in key_map and v is not None:
            region[f"ai.{name}.{key_map[k]}"] = v
    if fields.get("clear") is True:
        region[f"ai.{name}.api_key"] = ""  # secret 三态之清空（5.2 secret 契约）
    if not region:
        raise ValueError("无有效配置项")
    merge_region_patch(region, scope="model")
    return {"ok": True, "provider": name}


def delete_provider(name: str) -> Dict[str, Any]:
    """DELETE /providers：级联删除所有子模型；删当前 Provider → 切回默认。"""
    ai = _raw_ai()
    names = _provider_names(ai)
    if name not in names:
        raise ValueError(f"Provider 不存在: {name}")
    raw = read_yaml_config(Path(get_config_path())) or {}
    ai_block = raw.get("ai", {})
    if isinstance(ai_block, dict) and name in ai_block:
        del ai_block[name]
    merge_region_patch({"ai": ai_block}, scope="model")
    switched_to = None
    cur = get_current_ref(ai, names)
    if cur["provider"] == name:
        rest = [n for n in names if n != name]
        target_p = rest[0] if rest else ""
        target_m = ""
        if target_p:
            ms = _models_of(ai_block, target_p)
            target_m = ms[0]["name"] if ms else ""
        region: Dict[str, Any] = {}
        _sync_current(region, target_p, target_m)
        merge_region_patch(region, scope="model")
        switched_to = target_p or None
    return {"ok": True, "switched_to": switched_to}

import type { SettingSchemaItem } from '@/services/api/settings.api';

/** 模型 Tab 脏态：值与默认不一致且未被 env 接管（6.2）。 */
export function isDirty(
  params: Record<string, unknown>,
  defaults: Record<string, unknown>,
  env: Record<string, boolean>,
): Record<string, boolean> {
  const out: Record<string, boolean> = {};
  Object.keys(params).forEach((key) => {
    out[key] = !env[key] && params[key] !== defaults[key];
  });
  return out;
}

/** 超出新模型范围自动截断（7.5 范围截断 / 8.2.10 切换边界）。 */
export function clampToRange(value: unknown, range?: { min: number; max: number }): unknown {
  if (typeof value !== 'number' || !range) return value;
  if (value < range.min) return range.min;
  if (value > range.max) return range.max;
  return value;
}

/** 保存前 schema 校验：返回首个错误 {key, message}，通过返回 null（7.5 首个错误控件红框+定位）。 */
export function validate(
  items: SettingSchemaItem[],
  values: Record<string, unknown>,
): { key: string; message: string } | null {
  for (const item of items) {
    if (item.readonly) continue;
    const value = values[item.key];
    if (value === undefined || value === null) continue;
    if ((item.type === 'bool') && typeof value !== 'boolean') {
      return { key: item.key, message: `${item.label}应为开关值` };
    }
    if ((item.type === 'int' || item.type === 'float' || item.type === 'range') && typeof value !== 'number') {
      return { key: item.key, message: `${item.label}应为数字` };
    }
    if (item.range && typeof value === 'number') {
      const [lo, hi] = item.range;
      if (value < lo || value > hi) {
        return { key: item.key, message: `${item.label}超出范围 [${lo}, ${hi}]` };
      }
    }
    if (item.options && !item.options.includes(value as string)) {
      return { key: item.key, message: `${item.label}为非法选项` };
    }
  }
  return null;
}

// 编辑历史: 2026-09-20 小强 - 新建：全局单层 state（6 组+脏态+sources+模型管理+mtime 感知+外观本地预应用，见 6.2/6.3/7.0.5）
import { useCallback, useEffect, useMemo, useState } from 'react';
import { message } from 'antd';
import { settingsApi, type SettingSchemaItem } from '@/services/api/settings.api';
import { modelApi, type ModelEntry } from '@/services/api/model.api';
import { isDirty, clampToRange, validate } from '../utils/modelUtils';
import type { SettingsState, TabKey } from '../types';
import { handleApiError } from '@/services/error/handler';

const PREF_KEY = 'omni.prefs.v1';
const GROUP_ORDER: TabKey[] = ['general', 'model', 'security', 'chat', 'appearance', 'system'];

const initialModel = () => ({
  providers: [], selectedProvider: '', selectedModel: '',
  params: {}, defaults: {}, ranges: {}, envOverride: {},
  providerConfig: {}, isDirty: false, editingProviderConfig: false,
  addModelModalOpen: false, addProviderModalOpen: false,
  deleteConfirmOpen: false, deleteTarget: null as string | null,
});

function readLocalPrefs(): Record<string, unknown> {
  try {
    return JSON.parse(localStorage.getItem(PREF_KEY) || '{}') as Record<string, unknown>;
  } catch {
    return {};
  }
}

export function useSettings() {
  const [state, setState] = useState<SettingsState>({
    schema: {}, values: {}, sources: {}, dirtyKeys: {}, mtime: 0,
    loading: true, loadError: null, activeTab: 'general',
    model: initialModel(), currentRef: null,
  });
  const [saving, setSaving] = useState(false);
  const [restartKeys, setRestartKeys] = useState<string[]>([]);
  const [highlightKey, setHighlightKey] = useState<string | null>(null);

  const patchState = useCallback((p: Partial<SettingsState>) => {
    setState((s) => ({ ...s, ...p }));
  }, []);

  const patchModel = useCallback((p: Partial<SettingsState['model']>) => {
    setState((s) => ({ ...s, model: { ...s.model, ...p } }));
  }, []);

  /** 首次加载：schema + 全量值 + 模型列表一次拉取（6.3/7.0.5）。 */
  const load = useCallback(async () => {
    patchState({ loading: true, loadError: null });
    try {
      const [schema, all, models] = await Promise.all([
        settingsApi.getSchema(), settingsApi.getAll(), modelApi.getModels(),
      ]);
      const values = all.groups ? Object.fromEntries(
        Object.entries(all.groups).map(([g, v]) => [g, { ...v.data }]),
      ) : {};
      const sources = all.groups ? Object.fromEntries(
        Object.entries(all.groups).map(([g, v]) => [g, { ...v.sources }]),
      ) : {};
      // 7.6 外观本地预应用覆盖
      const prefs = readLocalPrefs();
      if (values.appearance) {
        if (typeof prefs.fontSize === 'number') values.appearance['appearance.fontSize'] = prefs.fontSize;
        if (typeof prefs.density === 'string') values.appearance['appearance.density'] = prefs.density;
      }
      const ref = models.current_model_ref ?? null;
      const provider = models.providers.find((p) => p.name === ref?.provider) ?? models.providers[0];
      const current = provider?.models.find((m) => m.name === (ref?.model ?? '')) ?? provider?.models[0];
      const defaults = Object.fromEntries(
        Object.entries((current?.default_params ?? {}) as Record<string, unknown>),
      );
      patchState({
        schema: schema.groups,
        values, sources, dirtyKeys: {}, mtime: all.mtime, loading: false,
        currentRef: ref,
        model: {
          ...initialModel(),
          providers: models.providers,
          selectedProvider: provider?.name ?? '',
          selectedModel: current?.name ?? '',
          params: { ...defaults }, defaults,
          ranges: { ...((current?.range ?? {}) as Record<string, { min: number; max: number }>) },
          providerConfig: Object.fromEntries(models.providers.map((p) => [p.name, {
            api_key: p.api_key, base_url: p.api_base, timeout: p.timeout,
          }])),
        },
      });
    } catch (e) {
      handleApiError(e);
      patchState({ loading: false, loadError: '设置加载失败' });
    }
  }, [patchState]);

  useEffect(() => { void load(); }, [load]);

  /** 切 Tab/刷新 mtime 检查（3.1/9.11）。 */
  const checkMtime = useCallback(async () => {
    try {
      const all = await settingsApi.getAll();
      if (all.mtime !== state.mtime) {
        await load();
        message.info('配置已更新，已刷新');
      }
    } catch (e) {
      handleApiError(e);
    }
  }, [state.mtime, load]);

  /** 改控件：记脏态；外观两项同步 localStorage 预览（7.6）。 */
  const setValue = useCallback((group: string, key: string, value: unknown) => {
    setState((s) => {
      const values = { ...s.values, [group]: { ...(s.values[group] ?? {}), [key]: value } };
      if (group === 'appearance' && (key === 'appearance.fontSize' || key === 'appearance.density')) {
        try {
          localStorage.setItem(PREF_KEY, JSON.stringify({
            ...readLocalPrefs(),
            [key === 'appearance.fontSize' ? 'fontSize' : 'density']: value,
          }));
        } catch { /* 本地预览失败不阻断 */ }
      }
      return { ...s, values, dirtyKeys: { ...s.dirtyKeys, [`${group}.${key}`]: true } };
    });
  }, []);

  const groupOfKey = useCallback((key: string): string | null => {
    for (const [g, items] of Object.entries(state.schema)) {
      if (items.items.some((i) => i.key === key)) return g;
    }
    return null;
  }, [state.schema]);

  const dirtyCount = useMemo(() => Object.keys(state.dirtyKeys).length, [state.dirtyKeys]);

  const isGroupDirty = useCallback((tab: TabKey) => {
    if (tab === 'model') return state.model.isDirty;
    return Object.keys(state.dirtyKeys).some((k) => k.startsWith(`${tab}.`));
  }, [state.dirtyKeys, state.model.isDirty]);

  /** 写（参数配置）：schema 校验 → PUT /settings（6.3/7.5）。 */
  const saveKeys = useCallback(async (keys: string[]) => {
    const items: SettingSchemaItem[] = [];
    const values: Record<string, unknown> = {};
    keys.forEach((ck) => {
      const dot = ck.indexOf('.');
      const g = ck.slice(0, dot);
      const key = ck.slice(dot + 1);
      const item = state.schema[g]?.items.find((i) => i.key === key);
      if (item) {
        items.push(item);
        values[key] = state.values[g]?.[key];
      }
    });
    const bad = validate(items, values);
    if (bad) {
      setHighlightKey(bad.key);
      message.warning(bad.message);
      return { ok: false as const, firstError: bad.key };
    }
    setSaving(true);
    try {
      const patch = Object.fromEntries(keys.map((ck) => {
        const dot = ck.indexOf('.');
        return [ck.slice(dot + 1), state.values[ck.slice(0, dot)]?.[ck.slice(dot + 1)]];
      }));
      const result = await settingsApi.updateSettings(patch);
      if (!result.ok) {
        result.errors.forEach((m) => message.error(m));
        return { ok: false as const };
      }
      result.warnings.forEach((m) => message.warning(m));
      if (result.need_restart.length) setRestartKeys(result.need_restart);
      else message.success('保存成功');
      setState((s) => {
        const dirtyKeys = { ...s.dirtyKeys };
        keys.forEach((k) => { delete dirtyKeys[k]; });
        return { ...s, dirtyKeys };
      });
      return { ok: true as const };
    } catch (e) {
      handleApiError(e);
      return { ok: false as const };
    } finally {
      setSaving(false);
    }
  }, [state.schema, state.values]);

  const saveModelGroup = useCallback(async () => {
    const dirty = isDirty(state.model.params, state.model.defaults, state.model.envOverride);
    const changed = Object.fromEntries(Object.keys(dirty).filter((k) => dirty[k]).map((k) => [k, state.model.params[k]]));
    if (!Object.keys(changed).length) return { ok: true as const };
    setSaving(true);
    try {
      await settingsApi.updateSettings({
        'ai.model_ref': { provider: state.model.selectedProvider, model: state.model.selectedModel },
        ...changed,
      });
      message.success('模型参数已保存');
      patchModel({ defaults: { ...state.model.params }, isDirty: false });
      return { ok: true as const };
    } catch (e) {
      handleApiError(e);
      return { ok: false as const };
    } finally {
      setSaving(false);
    }
  }, [patchModel, state.model]);

  const saveGroup = useCallback((tab: TabKey) => {
    if (tab === 'model') return saveModelGroup();
    const keys = Object.keys(state.dirtyKeys).filter((k) => k.startsWith(`${tab}.`));
    return saveKeys(keys);
  }, [state.dirtyKeys, saveKeys, saveModelGroup]);

  const saveAll = useCallback(() => saveKeys(Object.keys(state.dirtyKeys)), [state.dirtyKeys, saveKeys]);

  // ---- 模型 Tab（8.2.10 脏态合并/截断；6.5 四区域） ----
  const currentModelEntry = useCallback((): ModelEntry | undefined => {
    const p = state.model.providers.find((x) => x.name === state.model.selectedProvider);
    return p?.models.find((m) => m.name === state.model.selectedModel);
  }, [state.model.providers, state.model.selectedProvider, state.model.selectedModel]);

  const selectProvider = useCallback((name: string) => {
    const p = state.model.providers.find((x) => x.name === name);
    const first = p?.models[0];
    const defaults = { ...((first?.default_params ?? {}) as Record<string, unknown>) };
    patchModel({
      selectedProvider: name, selectedModel: first?.name ?? '',
      params: defaults, defaults,
      ranges: { ...((first?.range ?? {}) as Record<string, { min: number; max: number }>) },
      isDirty: false,
    });
  }, [patchModel, state.model.providers]);

  const selectModel = useCallback((name: string) => {
    const entry = state.model.providers
      .find((x) => x.name === state.model.selectedProvider)?.models
      .find((m) => m.name === name);
    if (!entry) return;
    const nextDefaults = { ...entry.default_params } as Record<string, unknown>;
    const nextRanges = { ...(entry.range ?? {}) } as Record<string, { min: number; max: number }>;
    const dirty = isDirty(state.model.params, state.model.defaults, state.model.envOverride);
    const params: Record<string, unknown> = {};
    Object.keys(nextDefaults).forEach((k) => {
      params[k] = dirty[k]
        ? clampToRange(state.model.params[k], nextRanges[k])
        : nextDefaults[k];
    });
    if (dirty && Object.values(dirty).some(Boolean)) message.info('已修改参数已保留并标记');
    patchModel({
      selectedModel: name, params, defaults: nextDefaults, ranges: nextRanges,
      isDirty: Object.values(isDirty(params, nextDefaults, state.model.envOverride)).some(Boolean),
    });
  }, [patchModel, state.model]);

  const setParam = useCallback((key: string, value: unknown) => {
    setState((s) => {
      const params = { ...s.model.params, [key]: clampToRange(value, s.model.ranges[key]) };
      return { ...s, model: { ...s.model, params, isDirty: Object.values(isDirty(params, s.model.defaults, s.model.envOverride)).some(Boolean) } };
    });
  }, []);

  const resetParams = useCallback(() => {
    patchModel({ params: { ...state.model.defaults }, isDirty: false });
  }, [patchModel, state.model.defaults]);

  const refreshModels = useCallback(async (select?: { provider: string; model: string }) => {
    try {
      const models = await modelApi.getModels();
      patchModel({ providers: models.providers });
      if (select) {
        const p = models.providers.find((x) => x.name === select.provider);
        const m = p?.models.find((x) => x.name === select.model);
        if (p && m) {
          const defaults = { ...(m.default_params as Record<string, unknown>) };
          patchModel({
            selectedProvider: p.name, selectedModel: m.name,
            params: { ...defaults }, defaults,
            ranges: { ...(m.range as Record<string, { min: number; max: number }>) },
            isDirty: false,
          });
        }
      }
      return models;
    } catch (e) {
      handleApiError(e);
      return null;
    }
  }, [patchModel]);

  return {
    state, saving, restartKeys, setRestartKeys, highlightKey, setHighlightKey,
    dirtyCount, isGroupDirty, groupOfKey, GROUP_ORDER,
    load, checkMtime, setValue, saveGroup, saveAll,
    selectProvider, selectModel, setParam, resetParams, saveModelGroup, refreshModels,
    patchModel, patchState, setActiveTab: (t: TabKey) => patchState({ activeTab: t }),
  };
}

import tempfile


def atomic_write(file_path: str, content: str, encoding: str = "utf-8") -> None:
    """原子写入文本：写同目录临时文件 → fsync → os.replace 整文件替换，绝不半写。

    同目录临时文件保证 replace 不跨文件系统；异常时清临时文件原样抛出。
    """
    abs_path = os.path.abspath(file_path)
    parent = os.path.dirname(abs_path) or "."
    fd, tmp_path = tempfile.mkstemp(dir=parent, prefix=".tmp_", suffix=".yaml")
    try:
        with os.fdopen(fd, "w", encoding=encoding) as f:
            f.write(content)
            f.flush()
            os.fsync(f.fileno())
        os.replace(tmp_path, abs_path)
    except Exception:
        try:
            if os.path.exists(tmp_path):
                os.remove(tmp_path)
        except OSError:
            pass
        raise


def backup_file(file_path: str, backup_dir: Optional[str] = None, suffix: str = ".backup",
                keep: int = 5) -> Dict[str, Any]:
    """编号备份链：backup.1（最新）~ backup.N（最旧）+ FIFO 清理（9.2/一.7）。

    轮转：删最旧 backup.{keep}，backup.{i}→backup.{i+1} 顺移，新备份=backup.1。
    返回保持原形状 {original_path, backup_path, backup_size}，加 backup_index=1。
    注意：旧调用方 update_config 验证成功后会删本次 backup.1（原有行为不变）；
    设置页路径（merge_region_patch）保留备份，链满 5 个自动 FIFO。
    """
    file_path = os.path.abspath(file_path)
    if not os.path.exists(file_path):
        raise FileNotFoundError(f"文件不存在: {file_path}")
    file_name = os.path.basename(file_path)
    if backup_dir is None:
        backup_dir = os.path.dirname(file_path)
    else:
        backup_dir = os.path.abspath(backup_dir)
        os.makedirs(backup_dir, exist_ok=True)
    for i in range(keep, 1, -1):
        older = os.path.join(backup_dir, f"{file_name}{suffix}.{i}")
        newer_src = os.path.join(backup_dir, f"{file_name}{suffix}.{i - 1}")
        if os.path.exists(older):
            os.remove(older)
        if os.path.exists(newer_src):
            os.rename(newer_src, older)
    backup_path = os.path.join(backup_dir, f"{file_name}{suffix}.1")
    shutil.copy2(file_path, backup_path)
    return {
        "original_path": file_path,
        "backup_path": backup_path,
        "backup_size": os.path.getsize(backup_path),
        "backup_index": 1,
    }
```

from typing import Any, Dict


def mask_secret_value(value: Any) -> Dict[str, Any]:
    """secret 掩码公共函数：永不返明文，只返 {configured, suffix 末4位}。"""
    s = str(value or "")

def _set_dotted(data: Dict[str, Any], key: str, value: Any) -> None:
    """点号键写入嵌套 dict。"""
    parts = key.split(".")
    node = data
    for part in parts[:-1]:
        child = node.get(part)
        if not isinstance(child, dict):
            child = {}
            node[part] = child
        node = child
    node[parts[-1]] = value


def _get_dotted(data: Dict[str, Any], key: str, default: Any = None) -> Any:
    """点号键取值。"""
    node: Any = data
    for part in key.split("."):
        if isinstance(node, dict) and part in node:
            node = node[part]
        else:
            return default
    return node

    config_path = Path(get_config_path())
    backup_path = _backup_config(config_path)
    restored = [False]

        config_data = read_yaml_config(config_path) or {}
        for key, value in region_updates.items():
            _set_dotted(config_data, key, value)
        import yaml
        yaml.safe_load(yaml.safe_dump(config_data))  # 内存结构可序列化校验

        return str(backup_path)
    except Exception:
