## 一、shell 命令安全规整

1. 命令命中只读白名单前缀（`SHELL_READONLY_PREFIXES`，内置 30 条，如 `ls` `cat` `git log` `pip list` `kubectl get`；可在设置页「人工确认」组配置收紧，缺省回退内置）且不含任何禁用载体时，直接执行，不弹确认框。
2. 禁用载体共 12 种，命中任一即不走直通：管道 `|`、语句分隔 `;`、后台 `&`、输出重定向 `>` 与 `>>`、变量 `$`、圆括号 `(` 与 `)`、反引号、输入重定向 `<`、换行符 `\n` 与 `\r`。
3. 只读命令跳过沙箱预检直接执行；需确认的命令先做沙箱预检，免确认的命令直通。
4. 其余命令按命令内容分组确认：同一批相同命令只问一次，不同命令各问一次。
5. 同一 (工具, 拒绝类型) 组合连续被拒 3 次后，该任务直接失败，不再重复询问；safety 与 sandbox 两个门各自独立计数。
6. 终端命令会做路径三线判定（读/写/删，查目录名单，详见 path_decision.md 终端命令六道关）——写目标越界（工作区外）先被危险意图扫描拦下转 HITL，路径判定再拦一道，而非直接执行。
7. 终端命令的删除动作走删线判定：命令内含递归删除（`rm -rf`/`del /s` 等）且目标在工作区外 → 硬拦；命令内路径的读/写/删权限与文件工具同一张权限矩阵。
8. 预检真跑之前先做危险意图扫描：越界写目标、重定向越界、注册表/系统配置写、杀进程停服务动词（含 `+` 拼接、`[char]` 编码归一形态）、WMI/CIM 方法杀（`.Terminate()`/`.Kill()`/`Invoke-CimMethod`）、`-EncodedCommand`，命中转 HITL，不进预检真跑。
9. 杀进程命令另过保护盾：目标命中后端自身/父进程/进程池 PID 或进程名直接拒；按名口径含 `-Name`（含引号）、`Get-Process … | Stop-Process`、`taskkill /IM`（含引号）与 `/FI IMAGENAME` 过滤器、WMI `where`/`-Filter` 与 CIM 查询名、`killall`/`pkill` 实参（含 `-f` 模式串）；抽不出任何目标的无界杀形（管线裸杀、无参 taskkill、`kill %1` 之类）同样直接拒；`-EncodedCommand` 内容不可静态见，转 HITL（残留风险）。
10. 风险分级按三壳并集判定：ps7/cmd/bash 各查一遍，命中即返回；HIGH 直接拒，MEDIUM 转 HITL。

## 二、delete 命令安全规整

1. 项目根和授权目录本身拒绝删除；上级目录中属于禁区（含盘根）的拒绝删除，其余上级按白名单外处理（需确认，见第 4 条）；两个根内部的具体文件与子目录仍可删除。
    - 项目根：{{project_root}}
    - 授权目录：{{allowed_dirs}}
2. 白名单内（根下级）、非递归：放行免确认。
3. 白名单内（根下级）、递归：放行。
4. 白名单外、非递归：需 HITL 确认。
5. 白名单外、递归：直接拒。

## 三、HTL 人工确认规整

1. 「HTL人工开关」关闭时，写文件、编辑文件等需确认的操作不会弹窗确认，直接执行。
2. 「HTL人工开关」开启时，写操作执行前弹框 HITL 确认；目录已被信任、同一目标本任务内刚被你拒绝的情况不问。
3. 确认弹窗带倒计时，超时无人点击：关闭时自动放行，开启时按拒绝处理；两个倒计时分别由「自动确认延迟」和「人工确认超时」控制。

## 四、信任安全规整

1. 你在弹框里点过「信任此目录」后，该目录记入信任库，本会话内不再重复问。
2. 信任按目录记，信任目录及其子目录都算；信任记录按会话生效（同会话跨任务有效），TTL 默认 90 天，过期或撤销后失效。
3. shell 同样适用会话信任豁免——终端命令的确认弹窗在目录已被信任时跳过（与文件工具同一豁免链）。

## 五、沙箱与运行限制安全规整

1. 沙箱限制内存与进程数（Windows JobObject，含退出杀全树）与工作区磁盘容量，不限制路径；路径越界由危险意图扫描与路径判定负责拦截。
2. 单次执行有超时上限，超时截断并转裁决。
3. 沙箱开关关闭后不再做沙箱预检，命令与文件操作直通执行。
4. 沙箱预检不替代路径校验——两者是先后两道关（先路径判定后沙箱预检），各自独立生效。
