## 七步速查

| 步 | 判定 | 读 | 写 | 删 |
|---|---|---|---|---|
| ① | 由工具名定操作类型 | — | — | — |
| ② | 不是路径类工具 | 放行 | 放行 | 放行 |
| ③ | 无路径参数 | 放行 | 放行 | 放行 |
| ④ | 路径为空 | 拒 | 拒 | 拒 |
| ⑤ | 系统禁区 | 放行 | 永不授权 | 永不授权 |
| ⑤ | 非系统禁区（代码目录+允许根自身+自启动目录） | 放行 | 临时授权后放行 | 硬拦 |
| ⑥ | 含 `..` 穿越 | 拒 | 拒 | 拒 |
| ⑦ | 在白名单里 | 放行 | 放行 | 根下级放行/根本身硬拦 |
| ⑦ | 不在白名单里 | 放行 | 临时授权 / 问你 | 临时授权 / 问你 |

> 读这一列几乎全绿——这就是「权限墙只挡写删」的直观依据。

## 白名单里有哪些

白名单是扁平的，只有「在不在列表里」一个状态，**没有只读/读写之分**：

- 用户主目录
- 项目根目录：{{project_root}}
- 授权目录：{{allowed_dirs}}
- 系统临时目录（Windows 为 %TEMP%）
- 会话工作区（任务级，仅任务内出现）

## 终端命令不走这张表

上表只管**文件类工具**。终端命令走下节六道关，但命令内的路径仍按读/写/删三线查这张表——写到工作区外面会被危险意图扫描拦下（见下节第②关），不是照样能改。

## 终端命令六道关

一句话：所有逻辑只防一件事——**别让 agent 的命令杀掉后端自己、删掉不该删的东西**。层数多是每次出事故补一块叠出来的，不是设计出来的。

```mermaid
graph TD
    S([shell 命令<br/>例 Get-Process…Stop-Process]) --> W{"① 只读白名单<br/>git status·ls…30条<br/>shell_readonly"}
    W -->|否·进预检| D2{"② 危险意图<br/>越界写·杀进程·拼接·方法杀<br/>executor._scan_command_danger_intent"}
    D2 -->|命中·杀意| H2(["→ HITL 不进真跑"])
    D2 -->|通过| P4{"③ 保护盾<br/>杀的是我自己？<br/>后端·父·池 path_tool_safety_checker"}
    P4 -->|命中·自己| X4(["✗ 拒　不弹窗"])
    P4 -->|否·别人| D3{"④ 24条分级<br/>三壳并集取最严<br/>danger+risk"}
    D3 -->|HIGH·删库| X3(["✗ 拒"])
    D3 -->|MEDIUM·弹窗| H3(["→ HITL 弹窗"])
    D3 -->|无| C5{"⑤ 连点3次？<br/>react_dispatch"}
    C5 -->|是| X5(["✗ 任务失败"])
    C5 -->|否| S6["⑥ 沙箱真跑<br/>临时目录先跑一遍<br/>sandbox executor"]
    S6 --> E(["真机执行"])
```

| 关 | 问什么 | 命中会怎样 | 为哪次事故生的 |
|---|---|---|---|
| ① | 是纯查询吗（`ls`/`git status`…） | 是就直放 | 每次查询都弹窗就没法干活 |
| ② | 写到工作区外面了？要杀进程？ | 弹窗，不进真跑 | 预检在宿主真跑，P9-03 后端被自己杀掉 |
| ③ | 杀的是后端自身/父进程/进程池？ | 直接拒，**不弹窗** | 两次弹窗点"允许"就能自杀 |
| ④ | 24 条里哪级（diskpart/format…） | HIGH 拒，MEDIUM 弹窗 | 高危和中危不能一个待遇 |
| ⑤ | 同一拒绝连点 3 次？ | 任务直接失败 | agent 死循环弹同一窗 |
| ⑥ | 临时目录跑一遍看效果 | 干净才去真机 | 盲跑，跑错才知道 |

三条命令走一遍：

| 命令 | 路径 | 结论 |
|---|---|---|
| `git status` | ①是查询 → ②无危险 → … → 执行 | 全程无感 |
| `taskkill /F /IM notepad.exe`（杀别人的记事本） | ③杀的不是我 → … → ②有杀意 → 弹窗 → 放过 | 杀别人可以，问你一声 |
| `Get-Process python \| Stop-Process`（杀后端自己） | ③命中自己 → 直接拒 | 连弹窗都不给——你看不出这是自杀，问了也白问 |

> 第③关不弹窗的原因：弹窗默认"用户看得懂命令"。但 `python` 就是后端自己——一行命令里看不出自杀，**看不懂的确认框等于摆设**，所以杀自己的命令跳过人，由机器直接拒掉。
