### 1. record_operation容错处理

**文件**: `backend/app/services/safety/file_safety/operation_recorder.py`

**修改**:
```python
# 修改前
def record_operation(...) -> str:
    try:
        # 插入数据库
        return operation_id
    except Exception as e:
        logger.error(f"Failed to record operation: {e}")
        raise  # ❌ 直接抛异常

# 修改后
def record_operation(...) -> Optional[str]:  # ✅ 返回Optional[str]
    try:
        # 插入数据库
        return operation_id
    except Exception as e:
        logger.warning(f"Failed to record operation: {e}, continue without recording")
        return None  # ✅ 返回None，不阻塞
```

## 三、设计原则

**核心原则**: 核心功能不应依赖非核心服务

- **核心功能**: 文件操作（写/编辑/移动/删除/压缩）
- **辅助功能**: 记录操作历史到数据库

**实现方式**:
- 数据库可用 → 使用execute_with_safety，记录历史
- 数据库不可用 → 直接执行文件操作，不记录历史
