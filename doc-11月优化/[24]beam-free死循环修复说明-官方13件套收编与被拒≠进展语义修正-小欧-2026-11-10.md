## 二、根因链（五因一果）

按因果序，第一张多米诺是环境缺包，不是模型也不是网关：

```
① html2text 环境缺装
   └ fetchpage 依赖它 → network_register.py:100 import 崩
      → network 分类注册三连败（11:41:28 三条 WARNING，registry.py:556/559）
      → searchweb/fetchpage/httpget/ping_port 全部未注册

② 自掩盖死循环（为什么一直没被发现）
   └ 启动期依赖预装 scanner 同样靠 import 收集依赖（registry.py:492）
      → import 崩 → html2text 进不了依赖清单 → 永不被自动安装
      → 每次重启仅一条 WARNING，静默缺席，永不自愈

③ 模型无联网工具可用
   └ 14 工具清单里没有任何网络工具 → 模型只能抓网关强塞的官方 websearch

④ "被拒≠进展"语义缺陷（烧穿 19 轮的直接机制）
   └ handle_action 对每轮 action 无条件 note_progress 清零空转计数
      → 假动作反复清哨兵 → REASONING_ONLY_MAX_ROUNDS=3 永不可达

⑤ 重复病句加剧误判
   └ 拒绝观察拼成"[Observation] 工具 websearch 工具 websearch 未注册"
     （observation_builder 前缀 + reason 自带前缀，双拼）
```

要点：**网关 toolshape.go 强塞官方 13 件套**（v2OfficialToolOrder，[17]/[18] 已述）是常驻行为；模型调官方名本身不是病，病在系统没有收编通道 + 没有真工具可执行。

### 3.1 修4 官方 13 件套收编明细

网关强塞的官方工具名，凡与我方注册工具**参数逐字兼容**的，收编进既有别名表（`TOOL_NAME_ALIASES`，与 writefile→write 同款机制，零新代码）：

| 官方名 | 我方注册名 | 兼容性判定 |
|---|---|---|
| `websearch` {query} | `searchweb` | ✅ 必填 {query} 逐字一致，真联网搜索 |
| `glob` {pattern, path} | `find` | ✅ 必填参数逐字对齐；官方 hidden/limit 被管线安全忽略 |
| `webfetch` {url, format, timeout} | `fetchpage` | ✅ url 必填同名；`format→extract_format` 参数别名（枚举值 markdown/html/text 一致）；timeout 同名直通 |
| `execute` {code} | — | ❌ 不收：是 **JS 代码运行时**，不是 shell，喂给 bash 会乱执行 |
| `patch` {patchText} | — | ❌ 不收：diff 格式，塞进 edit 的查找替换 = 垃圾进垃圾出 |
| `question` / `skill` / `subagent` | — | ❌ 不收：无诚实对应能力 |

收编效果：模型调官方名 → `normalize_tool_name` 归一 → **真工具真执行**（假动作变真动作）。`read`/`write`/`edit`/`grep`/`shell`(→bash 已在表) 等其余官方名天然命中或已有映射。

### 3.2 searchweb 归 FUNDAMENTAL 首批注入 — 零改动

`tool_constants.py:399` `TOOL_CATEGORY_OVERRIDE`（2026-10-02 已配）+ `universal_agent.py:38` `_INITIAL_CATEGORIES={FUNDAMENTAL, FILE}`：注册成功即自动归入 FUNDAMENTAL、自动首批注入，无需任何代码调整。

## 七、经验沉淀

1. **"缺包导致扫描不到缺包"**：依赖预装 scanner 与被扫描模块共用 import 通路，模块级 import 崩 = 依赖声明永不入册。教训：模块级 import 崩的告警（每启动一条 WARNING）必须当故障对待，不是噪声。
2. **收编优于拦截**：对外部强塞的名字，参数逐字兼容就收编执行，无诚实对应就靠机制底线（3 轮终止）兜底——映射降发生率，机制保底线，两者互补。
3. **计数器语义必须诚实**："发生了动作"不等于"取得了进展"；归零条件应与真实进展（工具真执行/真作答）严格对齐。
