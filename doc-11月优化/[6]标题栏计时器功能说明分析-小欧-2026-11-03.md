## 一、功能概述

本功能把「步骤级 / 全局等待计时」从三个等待图标中解剖出来重新分层落位，**图标位置与动画一律不动**，只新增两套「计时皮」：

1. **顶栏表盘钟面**（`HeaderWaitClock`）：挂载在品牌字 `OmniAgentAst.` 之后，表盘模式，常驻。
2. **步骤标题行右端 / 工具首行右端文字数码**（`WaitTimerText`）：纯数码 + 同色淡底色框（无描边）。
3. **蓝色波纹**仍留在句尾，位置不动。

计时口径抽到单一真源 `waitTiming.ts`，表盘与数码两套皮共用，颜色必然同秒变化。

**本次顺带修复**：任务在跑时点「新建会话」导致发送钮永久置灰、停止/暂停常驻的缺陷（`useChatStreaming`/`useChatSend` 闩锁复位）。

## 二、需求背景与设计决策

### 2.1 设计原则（北京老陈定案）

| 项 | 决定 |
|----|------|
| 三个等待图标（绿 270°弧 / 橙 8 臂 loader / 蓝波纹） | 位置与动画一律不动 |
| 顶栏计时器 | 表盘模式，继承 `ClockStopwatch`，不要"任务跑了多久"文字 |
| 步骤标题行右端 / 工具首行右端 | 文字计时数码，不要计时图标；"纯文字加一个底色框"，框的边线去掉、只留底色 |
| 计时功能分支 | 门槛 / 三档色 / 断连 / 里程碑 全部保留，只是文案可优化 |
| 顶栏表盘指针 60s 归零 + 中央数字累计 | 并存，"没关系" |
| 两套阈值（步骤 60s 转黄 / 顶栏胶囊 30s 流迟滞） | "没关系"，表盘与数码转色同步 |
| 窄面板顶栏溢出（710px） | 先不搞 |

### 2.2 口径抽到单一真源

`waitTiming.ts` 是唯一口径（阈值/档位/文案/读数格式），表盘与数码两皮共用 → 颜色必然同秒变化。避免两处各算各的导致转色不同步。

## 四、实现逻辑

### 4.1 计时唯一口径 `waitTiming.ts`

常量：

| 常量 | 值 | 含义 |
|------|----|------|
| `APPEAR_SEC` | 10 | 出现门槛（短等待不显示，避免闪烁） |
| `YELLOW_SEC` | 60 | 业务静默转黄 |
| `ORANGE_SEC` | 120 | 业务静默转橙红（里程碑文字起点） |
| `DATA_LOST_SEC` | 60 | 任意数据静默 ≥60s = 连接疑似中断（与 useSSE IDLE_TIMEOUT 同源） |

档位（`WaitLevel`）：`green` / `yellow` / `orange` / `gray`。灰档 = 连接疑似中断。

`useWaitTiming(signals, { kind, sinceTs })`：
- 计时起点：`sinceTs > 0` 时按该事实时刻算（顶栏：距最近业务帧）；不传则按组件挂载时刻算（步骤级：本步等了多久）。
- 每秒 `setTick` 刷新读数/档位；档位在渲染期直接读 ref（零高频 setState）。
- 心跳到达 → `beatTick++`，表盘外圈重放光波（存活确认，不参与计时）。
- `bizSilenceSec = Date.now() - lastBizTsRef.current`；`dataSilenceSec = Date.now() - lastDataTsRef.current`。
- 判定：`dataSilenceSec ≥ 60` → gray（连接疑似中断）；`bizSilenceSec ≥ 120` → orange（里程碑文案）；`bizSilenceSec ≥ 60` → yellow；否则 green。

里程碑文案 `formatSpan(sec)`：`<60min` 只报分钟（`N 分钟`）；`≥60min` 折为 `X 小时 Y 分`。

数码读数 `formatClock(sec)`：`<1min` → `12s`；`≥1min` → `1:23`；`≥1h` → `1:02:03`（等宽 tabular-nums）。

### 4.2 表盘钟面 `clockStopwatch.tsx`（顶栏皮）

- Props：`ClockStopwatchProps extends ClockSignals`，含 `kind`、`sinceTs`、`className`、`hideNote`。
- `elapsedSec < APPEAR_SEC(10)` → 不渲染（短等待避免闪烁）。
- 短针角度：`(elapsedSec % 60) * 6` → 60s 归零重扫。
- 中央纯秒数：`elapsedSec`（等宽字体）。
- 心跳微闪光波：`beatTick` 变化 → `key` 变更 → 重挂 → 重启动画。
- `hideNote=true`（顶栏实例）：只留表盘 + 秒数，里程碑/断连文字由步骤级数码与胶囊承担；aria-label 仍带 note。

### 4.3 文字数码 `waitTimerText.tsx`（步骤皮）

- `role="timer"`，aria-label/title 带里程碑/断连文案（不撑宽标题行）。
- 内联 `color` + `backgroundColor`（tint.bg），无 borderColor（无描边）。
- 尺寸固定：等宽数字 + `min-width: 34px` + `padding: 0 6px` + `border-radius: 6px`，防标题行随秒数抖动。
- 门控（`!hasResult && tools.length > 0 && !interrupted && !replay`）与齿轮同源。

### 4.4 顶栏钟面 `HeaderWaitClock.tsx`

- 门槛：`view.bizStale`（≥30s）且 `phase ∈ {stalled, silent, reconnecting}` → 与胶囊"流迟滞"同频。
- 起点：`sinceTs = p.lastBizTs`。
- `hideNote` 保证宽度恒定。
- `className="clock-stopwatch-header"` 供顶栏实例区分。

### 4.5 三等待图标（保持不变）

绿 270°弧 / 橙 8 臂 loader / 蓝波纹位置与动画一律不动；蓝色波纹留在句尾。

### 4.6 新建会话闩锁修复（配套）

- 根因：`chatState.loading` 是页面级全局闩锁，只由当前订阅会话的 `onComplete` 清；切到新会话后旧流终态回调不再执行 → `loading` 永真 → `SubmitActions` 恒显停止/暂停、发送钮恒灰。
- `useChatStreaming` 的会话切换复位 effect 补 `setLoading(false)`（prev 非 null 时，避免首发自动建会话清掉在跑任务）。
- `useChatSend` 的 `isSendingRef`/`isInterjectingRef` 同样在真切换时复位（prev 非 null）。

## 五、技术要点

1. **单一真源（DRY）**：阈值/档位/文案/格式全部在 `waitTiming.ts`，表盘与数码两皮共用 → 颜色同秒变化，避免两处各算各的。
2. **组件挂载时刻计时**：用 `performance.now()` 差值，防系统时钟跳变/后台节流丢秒。
3. **零高频 setState**：档位在渲染期直接读 ref（`lastBizTsRef.current`），每秒只 `setTick` 驱动读数刷新。
4. **心跳存活确认**：`heartbeatTs` 变化 → `beatTick++` → 表盘外圈光波重放（key 变更强制重挂）。
5. **里程碑/断连文案进 aria-label + title**：不撑宽标题行，仅悬停可读。
6. **无描边底色框**：`borderWidth: 0px / borderStyle: none`，只留淡底色（`rgba(颜色, 0.10)`），三档一眼可辨。
7. **等宽数字**：`font-variant-numeric: tabular-nums` + `min-width: 34px`，防标题行随秒数抖动。
8. **订阅换绑**：计时器组件跟随 `sessionId` 换绑，切会话时旧会话钟面自动卸载，新会话按新起点起算。

## 六、公用函数接口

### 6.1 `waitTiming.ts`

```ts
export const APPEAR_SEC = 10;
export const YELLOW_SEC = 60;
export const ORANGE_SEC = 120;
export const DATA_LOST_SEC = 60;

export type WaitLevel = 'green' | 'yellow' | 'orange' | 'gray';

export const LEVEL_COLOR: Record<WaitLevel, string>;
export const LEVEL_TINT: Record<WaitLevel, { bg: string }>;

export const formatSpan = (sec: number): string;   // 里程碑文案
export const formatClock = (sec: number): string;  // 数码读数

export interface WaitTimingOptions {
  kind?: 'llm' | 'tool';   // 里程碑主语
  sinceTs?: number;        // 计时起点 epoch ms
}

export interface WaitTiming extends ClockSignals {
  elapsedSec: number;
  level: WaitLevel;
  color: string;
  tint: { bg: string };
  note: string | null;
  beatTick: number;
}

export const useWaitTiming = (
  signals: ClockSignals,
  options?: WaitTimingOptions
): WaitTiming;
```

## 七、数据流与订阅

```
流状态 (useChatStreamSession) ──ClockSignals──► useWaitTiming ──► ClockStopwatch (顶栏表盘)
                                                              └──► WaitTimerText (步骤数码)
HeaderWaitClock ──bizStale+phase──► ClockStopwatch (sinceTs=lastBizTs, hideNote)
ThinkingStream ──► WaitTimerText (kind="llm", sinceTs=挂载时刻)
ToolCallLine ──► WaitTimerText (kind="tool", sinceTs=挂载时刻, 门控同齿轮)
```

切会话时：ClockSignals 换绑 → 旧会话钟面卸载 → 新会话按新起点起算；`prevSessionIdRef` 判据保证真切换时复位页面闩锁。
