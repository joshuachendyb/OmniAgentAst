## 一、改哪、为什么改（问题全部对码实证）

**对象**：`frontend/src/features/chat/components/input/SessionWorkspacePanel.tsx`——事项工作区面板（ChatInput 挂载）。

### 1.1 硬伤：垃圾条目赖库不掉（北京老陈 2026-11-01 质，最优先）

`D:\data\denied-dir   不可用：不存在` 这种行为什么会在面板里赖着？为什么删了还会回来？整条链四环都在烂：

1. **入库不拦**：前端添加只查「是不是绝对路径」（:219，存在性因决策74交后端判）；后端 PATCH 预检只查归一化/禁区/宽根（:157-164），**不查目录存不存在**——不存在的路径直接写进库表 `chat_session_workspaces`。
2. **只判不清**：打开面板时后端 GET 实时探测（:268-270），把不存在的行挑出来标「不可用」下发，但注释原话「**本函数只判定不落盘**」(:246)——库行分毫不动，每次打开都挑给你看，就是不删。
3. **UI 零按钮**：渲染分支注释原话「置灰，无编辑/删除」(:546)，按钮组对不可用行直接 undefined（:460）；删除函数(:287)只够得到有效行，不可用行是独立 state(:133/:192)——UI 永远够不到它。唯一出路是知情后点一次「确定」（全量覆盖清库行），界面毫无提示。
4. **死而复生**：建任务时后端 reconcile 对不存在的行**自动把磁盘目录 mkdir 建回来**(:348-355)——在资源管理器删掉它，下一条消息系统又建回来。

### 1.2 留痕区是第二坨垃圾（同判）

面板下沿那块「上次保存以下 N 项目录被后端拒绝…」灰虚线框红字(:640-675)：被拒条目**从未入库**（PATCH 整单拒绝，库分毫未动），本无「留库史」需要回看——纯多余显示。

## 二、方案（先根子、后表面，六个节）

### 2.1 后端闭环——库里必须只有可用目录【北京老陈令「库里都必须正常可用目录」】

老设计把「存在性」当成了展示问题，两头都不把「存在」当真。v3.4 起定为**不变式**：

| 环节 | 现状（对码） | After |
|------|-------------|-------|
| GET /sessions/{id}/workspaces | classify 挑出 unusable 只上报不清库（:246） | unusable 行**直接 DELETE 清库**（只删库行，**绝不删磁盘目录**）；响应删 `unusable` 字段 |
| PATCH set_session_workspaces | 预检不查存在性（:157-164/:229）——missing 路径合法入库 | 预检补一条：**目录必须存在**（is_dir）；missing → 整单 422 逐条点名（复用既有 rejected 链，零新机制） |
| reconcile | denied 清库、missing **mkdir 补建磁盘目录**（:348-355）、illegal 跳过不管（:337-338） | **三类 kind（missing/denied/illegal）一律 DELETE 清库**；**废除 mkdir 补建**；默认工作区自身的创建逻辑保留（系统自己的区，不在本裁决） |
| 前端 panel | unusable 独立 state(:133/:192)+置灰渲染分支(:545-566) | **全部删除**——面板上不再有「不可用行」 |
| 前端 store | notice 留痕(:56/:151)+WorkspaceRejection | 留痕机制删除：422 仍逐条 toast 点名，不再跨关闭留存——下次打开面板 = GET 还原库真值（全可用） |
| 类型/契约 | UnusableEntry(:406)、WorkspacesResponse.unusable(:420)、WorkspaceRejection(store :40) | 全部删除（同版本发布，禁 backward） |

落点文件：`backend/app/services/chat/workspace_service.py`（GET/PATCH/reconcile）、`frontend/src/features/chat/components/input/SessionWorkspacePanel.tsx`、`.../services/sessionWorkspaceStore.ts`、`frontend/src/types/chat.ts`。

**边界情景认账（白纸黑字，禁后人翻案）**：「移动盘暂时未挂载」时该行已被清，需要时重新添加一次——北京老陈裁定库里不许有不存在的目录，接受此代价。

### 2.2 弹窗壳层统一（与设置页同套语言）

| 维度 | Before | After | 理由 |
|------|--------|-------|------|
| 宽度 | settingsModalWidth.display = 800 | **settingsModalWidth.workspace = 640（新增档）** | 路径可读优先，640 介于 form(520) 与 display(800) 之间 |
| 高度 | 无限制 | bodyMaxHeight = '62vh' | 防长列表撑出屏幕，footer 常驻可见 |
| 关闭语义 | maskClosable 无声明 | closeBehavior = 'discard' | 表单类弹窗：遮罩/ESC = 放弃，与设置页一致 |
| 销毁语义 | destroyOnHidden | **保持 true 不变** | 每次打开重新 load，状态零残留 |

落点文件：`frontend/src/theme/settingsTokens.ts`（宽度档）；壳参数落面板 Modal 自身（不强移 SettingsModal，避免 ChatInput→theme 依赖反转）。

### 2.3 布局与列表（一切看得见的地方规整）

**区块节标题钉死**（13px、MEDIUM、TEXT.SECONDARY）——「在哪操作」一眼可见：
- 列表区标题：`已配置目录（N 条）`——右侧同行 [复制全部]；
- 新增区标题：`+ 新增目录`。

**列表行**：
- 路径 = 主信息：mono（FontFamily.MONO，var(--font-mono) 真源）+ PRIMARY=14 + TEXT.STRONG；
- 属性 Tag /「默认」Tag：SMALL=11、圆角 4、**色全部并入 PROP_COLORS 单一真源**（wsProp.ts，「默认」档新增映射）；
- [编辑][删除] **常驻行尾**（14px，删除钮 danger 色），**严禁藏进悬停**；编辑态=点[编辑]现行行内切换（同现状骨架，仅样式归一 28/4px）；
- 列表项统一 minHeight=40px。

**新增区一行式**（现状两行 Space.Compact 废除）：
```
+ 新增目录
[输入完整路径........................]  [读写工作区 ▾ 140]  [+ 添加 88]
[备注（可选）.............................................]
```
行1 = 路径 flex:1 + 属性▾定宽 140 + [+ 添加]定宽 88（右列零参差）；行2 = 备注全宽；路径框挂 Enter 添加、paste 多行拆条、即时校验红字。

**只读区**（项目根/授权目录）改 ModalSection 式弱容器：背景 BG.LIGHT (#fafafa)、边框 BORDER.LIGHT、圆角 6、内边距 6px 12px、图标 16px TEXT.SECONDARY、两行紧凑标签+值布局。

**加载失败提示**（条件块，仅 loadState='failed' 渲染 :573）：从 Text+Button 平排改标准警示条——`Colors.ERROR_BG` 背景 + `1px solid Colors.ERROR_BORDER` + Radius.DEFAULT，重试钮内嵌行内。

### 2.5 交互与可用性

- **编辑态键盘**：Enter 保存（现有保持）、**Esc=行级取消且不关窗**（现 :332 ESC 直接连弹窗关——未保存改动整批丢；落地：编辑容器捕获 Esc → cancelEdit+stopPropagation，或面板 keyboard=false 行级自理，实施二选一并补测试锁定）、Tab：路径→属性→备注→保存。
- **新增键盘**：Enter 添加（现有 ×2 保持）、Tab 同上。
- **添加按钮禁用态**：空或非绝对路径时 disabled（isAbsolute 同源判据，与提交流程一致）。
- **即时校验**：非绝对路径当场红字（输入框下 11px），校验通过红字消失零残留。
- **批量粘贴**：paste 多行自动按行拆条（空行过滤），逐条走现有 addEntry 链。
- **[复制全部]**：一次复制全部条目路径（每行一条），message.success 反馈，走 navigator.clipboard。
- **自动聚焦**：面板打开后光标落新增路径框——直接粘贴就能干。
- **空态**：Empty.PRESENTED_IMAGE_DEFAULT + 引导文案「此会话尚未配置目录，发送消息后系统将自动创建默认工作区」+ Ghost 钮「手动添加目录」聚焦输入框。

## 四、不可动的业务约束（设计必须尊重）

1. **is_default 行**：路径只读（UI disabled+系统生成）、属性/备注可改、无删除入口（:446-458），remove 内部兜底(:291)
2. **不可用条目（v3.4 裁定）**：库里必须只有可用目录——GET 即清 unusable 库行（只删库行，不删磁盘）；PATCH 对 missing 整单 422；reconcile 废除 mkdir 补建；UI 无此区块
3. **loadState !== 'ready'**：确定禁用（:333），杜绝空列表覆盖写
4. **dirtyRef**：用户编辑期间不被 load 覆盖(:182)；打开面板重置并重新 load(:209-216)
5. **rejected 反馈**：422 整单拒绝逐条 toast 点名（留痕区已废除 v3.4）；确定提交与关闭解耦（commit 不 await）
6. **destroyOnHidden=true**：每次打开重新 load（当前行为保持）

## 五、验收标准

1. **库内垃圾清零闭环**：打开面板一次，GET 清掉库中全部不可用行——库表只剩可用目录；再添加不存在目录 → 422 整单逐条点名；手动删磁盘目录不会再被系统建回
2. **视觉一致**：控件高 28px、圆角 4px、间距 12/4/6 节奏；路径 mono+14；Tag 色走 PROP_COLORS 无孤例
3. **交互**：Enter 保存/添加、Esc 行级取消且不关弹窗（测试锁定）、Tab 焦点流；**按钮常驻可见（禁藏悬停）**
4. **业务约束零破坏**：§四六条全绿（单测锁定）
5. **排列规整**：G1-G7 全达标——同网格左右对齐、块距唯一 12、新增区一行式定宽零参差、节标题齐整（§六图对照）
6. **测试**：Phase 0 基线全绿，每个 Phase 收口全绿

def _normalize_ws_path(p: str) -> str:
    """归一化唯一源：空串/非绝对/超长硬拒 → resolve 绝对化 + 去尾分隔符。

    订正：**保大小写入库**。Windows 大小写不敏感是"比较规则"不是"存储规则"，
    casefold 存库会导致面板全小写且无法恢复。去重走 casefold 键 + 库级 COLLATE NOCASE，
    存储本身必须无损。

    空串必须硬拒：`Path("").expanduser().resolve()` 返回**进程 cwd** 且不抛异常，
    不拦等于把整个后端启动目录静默授权。

    ⚠ 仍可能抛 OSError/ValueError（断开的 UNC 实测抛 OSError WinError 64），调用方必须捕获。"""
    if not p or not p.strip():
        raise ValueError("路径为空")
    _raw = p.strip()
    if not Path(_raw).is_absolute():
        raise ValueError(f"须为绝对路径(相对路径会随进程 cwd 漂移): {_raw}")
    if len(_raw) > MAX_PATH_CHARS:
        raise ValueError(f"路径过长({len(_raw)}>{MAX_PATH_CHARS}): {_raw[:60]}...")
    return str(Path(_raw).expanduser().resolve()).rstrip("\\/")

def _is_broad_root(p: str) -> bool:
    """是否"宽根"：家目录本身或其上级(用户目录/盘根)。

    家目录**之内**的路径不拦(那是正常用法)。

    订正：fail-closed。安全判据解析失败时必须按"宽根"处理(拒绝)，
    不能按"非宽根"放行，且必须留日志，否则保护静默消失。"""
    try:
        home = Path.home().resolve()
        target = Path(p)
        return target == home or target in home.parents
    except (OSError, ValueError) as _e:
        _ws_warn(f"宽根判定异常, 按 fail-closed 拒绝: {p} ({_e})")
        return True

    from app.safety.path_dir_lists import SCOPE_FORBIDDEN_SYSTEM
    _ok, _msg, scope = _validate_write_path(p)
    if scope == SCOPE_FORBIDDEN_SYSTEM:
        return _msg or "路径在全局禁区内"
    if _is_broad_root(p):
        return "宽根目录(家目录/用户目录/盘根)不可作为会话目录: 会放大删除允许范围"
    return None


def _ws_precheck(paths: list[str]) -> list[dict]:
    """合法性预检：逐条走判据。返回被拒清单，不抛异常（调用方整单 422）。

    2026-11-01 小欧 - 补「目录必须存在」预检(is_dir): missing 整单 422 逐条点名，
    库中禁止不存在的目录。禁区判定先行（与 classify_workspace_rows 裁决顺序一致）。"""
    rejected = []
    for p in paths:
        reason = _ws_deny_reason(p)
        if not reason and not Path(p).is_dir():
            reason = "目录不存在（不收不存在的路径）"
        if reason:
            rejected.append({"path": p, "reason": reason})
    return rejected


def prune_unusable_rows(conn, session_id: str, unusable: list[dict]) -> None:
    """不可用行清库唯一出口（2026-11-01 小欧 新增）—— GET 与 reconcile 共用。

    库里必须只有可用目录（北京老陈令）: 不可用行（禁区/非法/不存在）一律从库表
    删除，不再"只上报不清"。三类 kind 处置口径一致，无差别清库。

    ⚠ 只删数据库行，绝不删除磁盘目录。磁盘目录的处置权在用户：
    移动盘未挂载时该行已被清，需要时重新添加一次（白纸黑字认账，禁后人翻案）。

    逐条 try/except：单条 DELETE 失败只跳过本轮，不拖垮整个请求。"""
    for u in unusable:
        try:
            conn.execute(
                "DELETE FROM chat_session_workspaces WHERE session_id = ? AND path = ?",
                (session_id, u["path"]))
        except Exception as _e:
            _ws_warn(f"不可用行清库失败(本轮保留, 下轮再试): {u['path']} - {_e}")
            continue
        _ws_warn(f"不可用行已清库({u['kind']}): {u['path']}")


def _ws_apply(conn, session_id: str, entries: list[tuple[str, str, Optional[str]]]) -> None:
    """覆盖写 —— PATCH 的唯一写库实现（懒建占行不走这里）。

    DELETE 全删 → executemany INSERT(path, workspace_property, memo, is_default)。
    全删全插天然支持编辑：前端改了某条 path/属性/memo 后整批提交，
    后端不需要区分"新增/修改/删除"——全量覆盖即可。

    ⚠ is_default 由系统维护，前端 PATCH 无权携带：写库前先读旧默认行，
    覆盖时按 path（大小写不敏感）原样继承。否则用户每点一次「确定」都会把
    默认标志抹成 0，下次建任务再建一个新时间戳目录，历史产物被拆散。

    默认行被删除或被改名时，旧 path 不在新列表 → 不继承，该会话本轮零默认行；
    下次建任务 reconcile 按 [54] 规则2 重建默认区。这里**不做**"把首条顶上"的
    兜底：默认区是系统按项目根创建的隔离区，把用户目录标成 default 会让
    reconcile 误判"默认已存在"，反而废掉"删除后重建"。默认行路径在面板已锁定，
    "改名"只剩程序调用方一种来源，重建即正确语义。"""
    _old_defaults = {
        r["path"].casefold()
        for r in conn.execute(
            "SELECT path FROM chat_session_workspaces "
            "WHERE session_id = ? AND is_default = 1", (session_id,)).fetchall()
    }
    conn.execute("DELETE FROM chat_session_workspaces WHERE session_id = ?", (session_id,))
    if not entries:
        return
    conn.executemany(
        "INSERT INTO chat_session_workspaces"
        "(session_id, path, workspace_property, memo, is_default) "
        "VALUES (?, ?, ?, ?, ?)",
        [(session_id, p, r, m, 1 if p.casefold() in _old_defaults else 0)
         for p, r, m in entries])


def set_session_workspaces(conn, session_id: str, items: list[dict]) -> list[dict]:
    """PATCH 唯一写入口：数量先拦 → 归一化 → 去重 → 预检 → 写库。
    返回被拒清单；非空即调用方返 422，空即 200。

    入参固定 list[dict]（{"path", "workspace_property", "memo"}），与 WorkspaceItem 一对一。
    **不接收 list[str]**：API 层已收单形态，前后端同版本发布，没有旧形态需要兼容；
    保留分支会让"路径数组"与"三字段对象"两套语义长期并存（违反禁止 backward）。
    属性/memo **不参与预检**（不是路径，与安全判定无关）。
    前端编辑（改 path/属性/memo）后整批提交，本函数不区分新增/编辑——全量覆盖。"""
    if len(items) > MAX_WORKSPACES:
        return [{"path": f"({len(items)} 条)", "reason": f"目录数超上限({MAX_WORKSPACES})"}]

    entries, rejected, _seen = [], [], set()
    for it in items:
        _p = it.get("path", "")
        try:
            _n = _normalize_ws_path(_p)
        except (OSError, ValueError) as _e:
            rejected.append({"path": _p, "reason": f"路径非法: {type(_e).__name__}: {_e}"})
            continue
        _k = _n.casefold()
        if _k in _seen:                      # 去重(大小写不敏感)，存值保大小写
            continue
        _seen.add(_k)
        _prop, _memo = _normalize_ws_meta(it.get("workspace_property"), it.get("memo"))
        entries.append((_n, _prop, _memo))
    if rejected:
        return rejected                      # 归一化失败即整单 422，不再写库

    rejected = _ws_precheck([p for p, _r, _m in entries])
    if rejected:
        return rejected

    _ws_apply(conn, session_id, entries)
    logger.info(f"[workspace] 会话工作区已更新: session={session_id} 数量={len(entries)}")
    return []


def classify_workspace_rows(rows) -> tuple[list, list]:
    """行 → (有效条目集, 不可用清单)：**会话工作区过滤唯一真源**。

    返回值：effective 为 list[tuple[str, str, Optional[str], bool]]
    = [(path, workspace_property, memo, is_default)]。
    属性/备注/默认标志只**透传**，不参与任何裁决 ——
    归一化/禁区/宽根/存在性判定全部只看 path，安全语义零变化。

    ⚠ 本函数纯判定不落盘（不建目录、不删行）；清库由调用方经 prune_unusable_rows 执行。

    裁决顺序（禁区判定必须先于存在判定）：
       归一化失败 → 不可用（优雅跳过，绝不抛；调用方整单不崩）
       `_ws_deny_reason` 全套判据 → 不可用（禁区/系统保护/宽根）
       非目录（不存在，或是个文件）→ 不可用
       通过 → 有效

    unusable 每项带机器可读 `kind`，供清库出口记日志与前端调试定位：
      illegal（归一化失败）/ denied（禁区/系统保护/宽根）/ missing（非目录或不存在）
    v3.4 起三类 kind 处置一致——一律清库。"""
    effective, unusable = [], []
    for r in rows:
        try:
            p = _normalize_ws_path(r["path"])
        except (OSError, ValueError) as _e:
            unusable.append({"path": r["path"], "reason": f"路径非法({type(_e).__name__})",
                             "kind": "illegal"})
            continue
        reason = _ws_deny_reason(p)          # 禁区判定先行，全套判据
        if reason:
            unusable.append({"path": p, "reason": reason, "kind": "denied"})
            continue
        if not Path(p).is_dir():             # 必须是目录：不存在/是文件都不收
            unusable.append({"path": p, "reason": "不是目录或不存在", "kind": "missing"})
            continue
        _prop, _memo = _normalize_ws_meta(r["workspace_property"], r["memo"])
        _is_def = bool(r["is_default"])
        effective.append((p, _prop, _memo, _is_def))
    return effective, unusable


def _load_workspaces_conn(conn, session_id: str) -> list[tuple[str, str, Optional[str], bool]]:
    """任务快照源：读行 → 过滤（复用 classify_workspace_rows 单一真源）。
    返回 [(path, workspace_property, memo, is_default)] 四元组，供 _load_ws_snapshot 构造。

    不可用行必须告警：目录被改名、移动或盘符没挂时若静默跳过，徽标显示 N 而运行时生效 0。
    （v3.4 起此类行随即被 prune_unusable_rows 清库，告警为其留痕。）"""
    effective, unusable = classify_workspace_rows(get_session_workspaces(conn, session_id))
    for u in unusable:
        _ws_warn(f"会话工作区本轮不生效({u['reason']}): {u['path']}")
    return effective


def _ensure_ws_dir(p: str) -> bool:
    """默认工作区物理目录创建/修复唯一出口（2026-11-01 小欧 新增）。

    mkdir 补建废除后，系统只在一处建目录——即默认工作区（系统自己的区）；
    用户目录绝不在此建（北京老陈令：磁盘目录归用户处置，系统绝不自动建用户目录）。
    失败仅告警返回 False：该行将被 classify 判 missing→清库，下次 reconcile 自愈重建。"""
    try:
        Path(p).mkdir(parents=True, exist_ok=True)
        return True
    except Exception as _e:
        _ws_warn(f"默认工作区目录创建失败(下轮 reconcile 自愈重建): {p} - {_e}")
        return False


def reconcile_session_workspaces(conn, session_id: str) -> list[tuple[str, str, Optional[str], bool]]:
    """创建新 Task 并绑定该会话时的唯一落盘入口。

    流程（v3.4，北京老陈令「库里都必须正常可用目录」）：
      1) 默认工作区缺失（无默认行/默认行不在当前项目根下）→ 登记新默认行 + _ensure_ws_dir 建物理目录
      2) 存量默认行磁盘目录丢失 → _ensure_ws_dir 修复（系统自己的区，不在清库裁决内）
      3) 其余条目：三类 kind（missing/denied/illegal）一律经 prune_unusable_rows 清库
         —— **废除 mkdir 补建**：不存在的路径不再被系统建回、不再占用库行，
            资源管理器删掉它，它就真的不在库里了。
      4) 重读重判返回有效条目集（供 _load_ws_snapshot 构造任务快照）。

    ⚠ 只删数据库行，绝不删除磁盘目录；用户目录永不自动建。"""
    from app.config import get_config
    rows = get_session_workspaces(conn, session_id)
    current_root = get_config().get_project_root()

    # ── 默认工作区是否需创建/重建 ──
    # 需要（任一）：a) 无任何 is_default=1 行（首次，或用户删了默认行）
    #               b) 默认行不在当前项目根下（项目根变了）
    need_new_default = True
    for r in rows:
        if r["is_default"] and Path(r["path"]).parent == Path(current_root):
            need_new_default = False
            break

    if need_new_default:
        d = _build_default_workspace_dir(session_id)
        if d:
            try:
                _p = _normalize_ws_path(d)
                # 先登记/升级新默认（同路径已存在则原地置 1），再降级其余默认行 ——
                # 顺序不可颠倒：先降后插一旦插入失败，会话将没有任何默认工作区
                conn.execute(
                    "INSERT INTO chat_session_workspaces"
                    "(session_id, path, workspace_property, memo, is_default) "
                    "VALUES (?, ?, ?, ?, 1) "
                    "ON CONFLICT(session_id, path) DO UPDATE SET "
                    "workspace_property = excluded.workspace_property, "
                    "memo = excluded.memo, is_default = 1",
                    (session_id, _p, DEFAULT_WS_PROP, DEFAULT_MEMO))
                # 旧默认目录降为普通目录（保留历史产物，用户可自行处置）
                conn.execute(
                    "UPDATE chat_session_workspaces SET is_default = 0 "
                    "WHERE session_id = ? AND is_default = 1 AND path <> ?",
                    (session_id, _p))
                _ensure_ws_dir(_p)     # mkdir 补建废除后，默认区物理目录只在此建（2026-11-01 小欧）
                logger.info(f"[chat] 默认工作区已就绪: session={session_id} path={_p}")
            except Exception as _e:
                logger.warning(f"[chat] 默认工作区登记失败（本轮无默认区，下次再试）: {_e}")
        rows = get_session_workspaces(conn, session_id)

    # 存量默认行的磁盘目录丢失 → 系统自己的区，修复而非清库（用户目录绝不在此建）
    for r in rows:
        if r["is_default"] and not Path(r["path"]).is_dir():
            _ensure_ws_dir(r["path"])

    _, unusable = classify_workspace_rows(rows)
    prune_unusable_rows(conn, session_id, unusable)   # 三类 kind 一律清库，共用唯一出口（2026-11-01 小欧）

    return _load_workspaces_conn(conn, session_id)    # 重读重判：有效条目集最终确认


def _build_default_workspace_dir(session_id: str):
    """默认事务目录 = {项目根}\\{YYYYMMDD-HHMMSS}-{会话标识前4位}。
    从 stream_orchestrator 下沉至此(2026-10-10)：它是 workspace 的事不是编排的事，
    reconcile 在本模块，倒挂 import 会破分层。

    撤回(2026-10-10)：此前称"前4位会重名"是误报 —— 验证用的
    aaaa1111/aaaa2222 是人为构造的同秒同前缀，真实 UUID 前4位随机(65536 种)，
    碰撞需同秒建会话且前缀相同，概率可忽略。恢复 [:4] 原设计，不做过度工程。
    sanitize: Windows 非法字符 \\/:*?"<>| → _；首尾空格与结尾 . 去除；空 → session。
    同名已存在**直接返回同一路径**(不换名)：调用方 mkdir 用 exist_ok=True，已存在即复用。
    项目根不存在/非目录 → 返回 None（调用方降级走项目根兜底）。"""
    from app.config import get_config
    from app.utils.time_utils import now_str
    root = get_config().get_project_root()
    if not root or not Path(root).is_dir():
        return None
    import re

    ts = now_str("%Y%m%d-%H%M%S")
    name = re.sub(r'[\\/:*?"<>|]', "_", (session_id or "").strip())[:4].strip(" .") or "session"
    return str(Path(root) / f"{ts}-{name}")


def session_exists(conn, session_id: str) -> bool:
    """会话存在性：存在且未删才放行，否则调用方返 404。
    必要性：PRAGMA foreign_keys=ON 下，对不存在 session_id 的 INSERT 会抛
    sqlite3.IntegrityError → 500。

    订正：`is_deleted = FALSE` 漏掉 NULL。is_deleted 列是后 ADD 的，
    存量行全是 NULL，三值逻辑下 `NULL = FALSE` 恒不成立 → 老会话全 404。
    改 COALESCE，NULL 按未删处理（与 link_enabled 的存量 NULL 惯例一致）。"""
    row = conn.execute(
        "SELECT 1 FROM chat_sessions WHERE id = ? AND COALESCE(is_deleted, FALSE) = FALSE",
        (session_id,),
    ).fetchone()
    return row is not None

  }

/** 保存提交：**不再有返回值可等** —— 调用方（编辑器）点完就关，结果走 store 与 toast。
 *  成功：以请求列表为权威落位（后端 422 是整单拒绝，200 即库中全部有效行）；
 *  422：toast 逐条点名一次（不跨关闭留存）+ 对账；
 *  其他：全局错误通道 + 对账。 */
const commit = async (
  sessionId: string,
  items: WorkspacePatchItem[]
): Promise<void> => {
  const seq = ++commitSeq;
  try {
    await sessionApi.patchWorkspaces(sessionId, items);
    if (seq !== commitSeq || state.sessionId !== sessionId) return;
    setState({
      sessionId,
      // 成功即以请求列表为权威落位：三字段原样保留，禁止退化成 { path }
      list: items.map((i) => ({ ...i })),
    });
  } catch (e: unknown) {
    if (seq !== commitSeq) return;
    const rejectedItems = rejectionsOf(e);
    if (rejectedItems.length) {
      // 统一错误通道：走 showMessage（查表+去重+分级），禁自造 notify/裸调 message
      rejectedItems.forEach((x) =>
        showMessage(ErrorType.WORKSPACE_REJECTED, `${x.path}：${x.reason}`)
      );
    } else {
      handleError(e);
    }
    await reconcile(sessionId);
  }
};

export const workspaceStore = {

  getSnapshot,
  loadSession,
  commit,
};

/** 面板内部草稿：path + 属性 + memo + 默认标志（is_default 只读展示，PATCH 不携带） */

  is_default: boolean;
};

const CUSTOM_PROPS_KEY = 'ws_custom_props';
const MAX_CUSTOM_PROPS = 16;

/** 读自定义属性列表（localStorage，失败降级空数组） */
function loadCustomProps(): string[] {
  try {
    const raw = localStorage.getItem(CUSTOM_PROPS_KEY);
    return raw ? JSON.parse(raw) : [];
  } catch {
    return [];
  }
}

/** 存自定义属性（预设不存、已有不存、FIFO 淘汰、失败静默） */
function saveCustomProp(prop: string): void {
  if (WS_PROP_PRESETS.some((p) => p.value === prop || p.label === prop)) return;
  const list = loadCustomProps();
  if (list.includes(prop)) return;
  list.push(prop);
  if (list.length > MAX_CUSTOM_PROPS) list.shift();
  try {
    localStorage.setItem(CUSTOM_PROPS_KEY, JSON.stringify(list));
  } catch {
    /* 隐私模式/配额满：静默降级，不影响主流程 */
  }
}

            emptyText: (
              <Empty
                image={Empty.PRESENTED_IMAGE_DEFAULT}
                description="此会话尚未配置目录，发送消息后系统将自动创建默认工作区"
              >
                <Button
                  ghost
                  type="primary"
                  size="small"
                  onClick={() => addPathRef.current?.focus()}
                >
                  手动添加目录
                </Button>
              </Empty>
            ),
          }}
          dataSource={entries.map((d) => ({ ...d, key: d.path }))}
          renderItem={(e) => {
            const editing = editingPath === e.path;
            return (
              <List.Item
                style={{ minHeight: 40 }}
                actions={
                  editing
                    ? []
                    : [
                        <Tooltip
                          key="edit"
                          title={
                            e.is_default
                              ? '编辑属性/备注（默认工作区路径由系统生成）'
                              : '编辑该目录'
                          }
                        >
                          <Button type="text" size="small" onClick={() => startEdit(e)}>
                            编辑
                          </Button>
                        </Tooltip>,
                        /* 默认工作区系统内不可删除：删目录只能去系统外（资源管理器）手动删，
                           下次建任务 reconcile 会重建。列表条目不提供删除入口。 */
                        ...(e.is_default
                          ? []
                          : [
                              <Tooltip key="del" title="移除该目录">
                                <Button
                                  type="text"
                                  size="small"
                                  danger
                                  onClick={() => remove(e.path)}
                                >
                                  删除
                                </Button>
                              </Tooltip>,
                            ]),
                      ]
                }
              >
                {editing ? (
                  /* 编辑态：同现状骨架（三字段两行），仅样式令牌归一；默认行 path 只读 */
                  <div style={{ width: '100%' }}>
                    <Input
                      value={editPath}
                      placeholder="目录路径"
                      disabled={e.is_default}
                      status={editErr ? 'error' : undefined}
                      onChange={(ev) => {
                        setEditPath(ev.target.value);
                        setEditErr('');
                      }}
                      onPressEnter={saveEdit}
                      onKeyDown={(ev) => {
                        if (ev.key === 'Escape') {
                          ev.stopPropagation(); // Esc=行级取消，不关窗（keyboard=false 双保险）
                          cancelEdit();
                        }
                      }}
                    />
                    {e.is_default && (
                      <Typography.Text
                        type="secondary"
                        style={{ fontSize: FontSize.SECONDARY }}
                      >
                        默认工作区的路径由系统按项目根生成，不可修改；如需换落点请新增目录。
                      </Typography.Text>
                    )}
                    {editErr && (
                      <Typography.Text
                        type="danger"
                        style={{ fontSize: FontSize.SECONDARY }}
                      >
                        {editErr}
                      </Typography.Text>
                    )}
                    <Space.Compact style={{ width: '100%', marginTop: Spacing.SM }}>
                      <AutoComplete
                        value={editProp}
                        options={propOptions}
                        onChange={setEditProp}
                        style={{ flex: 1 }}
                        placeholder="工作区属性"
                      />
                      <Input
                        value={editMemo}
                        placeholder="备注（可选）"
                        onChange={(ev) => setEditMemo(ev.target.value)}
                        onPressEnter={saveEdit}
                        onKeyDown={(ev) => {
                          if (ev.key === 'Escape') {
                            ev.stopPropagation(); // 备注框 Esc 同走行级取消
                            cancelEdit();
                          }
                        }}
                        style={{ flex: 1 }}
                      />
                    </Space.Compact>
                    <Space style={{ marginTop: Spacing.SM }}>
                      <Button type="primary" size="small" onClick={saveEdit}>
                        保存
                      </Button>
                      <Button size="small" onClick={cancelEdit}>
                        取消
                      </Button>
                    </Space>
                  </div>
                ) : (
                  /* 展示态：路径=主信息（mono 14 STRONG）；属性/默认 Tag 11px 圆 4 色走真源；备注弱化 */
                  <Space size={Spacing.XS} style={{ width: '100%' }}>
                    <Typography.Text
                      ellipsis={{ tooltip: e.path }}
                      style={{
                        fontFamily: FontFamily.MONO,
                        fontSize: FontSize.PRIMARY,
                        color: Colors.TEXT.STRONG,
                        flex: 1,
                      }}
                    >
                      {e.path}
                    </Typography.Text>
                    {e.is_default && (
                      <Tag
                        color={PROP_COLORS.default}
                        style={{ fontSize: FontSize.SMALL, borderRadius: Radius.SM }}
                      >
                        默认
                      </Tag>
                    )}
                    <Tag
                      color={
                        PROP_COLORS[propValue(e.workspace_property)] || 'default'
                      }
                      style={{ fontSize: FontSize.SMALL, borderRadius: Radius.SM }}
                    >
                      {propLabel(e.workspace_property)}
                    </Tag>
                    {e.memo && (
                      <Typography.Text
                        type="secondary"
                        ellipsis={{ tooltip: e.memo }}
                        style={{ fontSize: FontSize.SECONDARY }}
                      >
                        {e.memo}
                      </Typography.Text>
                    )}
                  </Space>
                )}
              </List.Item>
            );
          }}
        />

        {/* 取数失败警示条：全幅 ERROR_BG 容器，重试钮内嵌行内；正常路径永不出现 */}
        {loadState === 'failed' && (
          <div
            style={{
              marginTop: Spacing.LG,
              padding: `${Spacing.XS}px ${Spacing.MD}px`,
              background: Colors.ERROR_BG,
              border: `1px solid ${Colors.ERROR_BORDER}`,
              borderRadius: Radius.DEFAULT,
              display: 'flex',
              alignItems: 'center',
              gap: Spacing.SM,
            }}
          >
            <Typography.Text
              style={{ fontSize: FontSize.SECONDARY, color: Colors.ERROR, flex: 1 }}
            >
              目录读取失败，暂不能保存（避免用空列表覆盖已有目录），请重试。
            </Typography.Text>
            <Button size="small" type="text" onClick={() => void load()}>
              重试
            </Button>
          </div>
        )}

        {/* 新增区：节标题 + 一行式（路径 flex + 属性▾140 + [+ 添加]88）+ 备注全宽 */}
        <div
          style={{
            display: 'flex',
            alignItems: 'center',
            marginTop: Spacing.LG,
            marginBottom: Spacing.XS,
          }}
        >
          <Typography.Text
            style={{
              fontSize: 13,
              color: Colors.TEXT.SECONDARY,
              fontWeight: FontWeight.MEDIUM,
            }}
          >
            + 新增目录
          </Typography.Text>
        </div>
        <Space.Compact style={{ width: '100%' }}>
          <Input
            ref={addPathRef}
            style={{ flex: 1 }}
            placeholder="输入完整路径…（绝对路径）"
            status={inputErr ? 'error' : undefined}
            value={input}
            onChange={(e) => {
              setInput(e.target.value);
              setInputErr(
                e.target.value.trim() && !isAbsolute(e.target.value.trim())
                  ? '请输入绝对路径'
                  : ''
              );
            }}
            onPaste={handlePaste}
            onPressEnter={addEntry}
            onKeyDown={(ev) => {
              if (ev.key === 'Escape') {
                ev.stopPropagation(); // 新增行 Esc=行级清错纠错收回，不关窗
                setInputErr('');
              }
            }}
          />
          <AutoComplete
            value={propInput}
            options={propOptions}
            onChange={setPropInput}
            style={{ width: 140 }}
            placeholder="属性"
          />
          <Button
            type="primary"
            icon={<PlusOutlined />}
            style={{ width: 88 }}
            disabled={!input.trim() || !isAbsolute(input.trim())}
            onClick={addEntry}
            aria-label="添加目录"
          >
            添加
          </Button>
        </Space.Compact>
        <Input
          style={{ width: '100%', marginTop: Spacing.XS }}
          placeholder="备注（可选，如：后端源码、产物输出、别碰 legacy）"
          value={memoInput}
          onChange={(e) => setMemoInput(e.target.value)}
          onPressEnter={addEntry}
          onKeyDown={(ev) => {
            if (ev.key === 'Escape') {
              ev.stopPropagation(); // 备注框 Esc 同走行级（keyboard=false 兜底）
              setMemoInput('');
            }
          }}
        />
        {inputErr && (
          <Typography.Text
            style={{
              fontSize: FontSize.SMALL,
              color: Colors.ERROR,
              marginTop: Spacing.XS,
              display: 'block',
            }}
          >
            {inputErr}
          </Typography.Text>
        )}
      </ConfigProvider>
    </Modal>
  );
}
