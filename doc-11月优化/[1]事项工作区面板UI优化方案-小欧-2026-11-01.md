## 〇 设计判断（先问该不该有，再问怎么好看）

### 0.1 这块面板的职责，一句话

**让用户确认"这次任务可以把东西写到哪些目录"，并允许他增删改。**

不是目录浏览器，不是工作区管理后台。它一次只服务一个会话，绝大多数时间只被打开几秒。所有设计取舍都从这句话出发。

### 0.2 三条原则（本版所有决策的根）

| 原则 | 含义 | 反例（v4.1 踩过的） |
|------|------|--------------------|
| **P1 少即是准** | 屏幕上每多一件东西，主信息就弱一分。能不显示的不显示，能合并的合并。 | 每行 2 个彩色 Tag 与路径抢注意力；[复制全部] 这种无落点的功能 |
| **P2 路径第一** | 这个面板唯一的"数据"就是路径。任何装饰都不许和路径抢宽度、抢注意力。 | 800→640 变窄却把图标钮换成文字钮，路径列反被挤掉 |
| **P3 草稿即事务** | 面板打开 = 一次事务开始，点「确定」= 提交，关掉 = 放弃。既然有事务，就必须有**撤销**和**失败不丢**。 | 422 整单拒绝后关闭面板，用户粘的 20 条目录蒸发 |

### 0.3 内容去留裁决（做减法是本版最大改动）

| 原先有什么 | v4.1 处置 | v5.1 裁决 | 理由 |
|-----------|----------|-----------|------|
| 顶部只读区（项目根 + 授权目录，两行 + 图标 + 复制） | 蓝底、标签/值/复制挤一行 | **保留两行常驻**，只做紧凑对齐：标签列 72 定宽、值列 mono、复制跟值走 | 它是"这次能写哪里"的上下文，扫一眼就有用；折叠省 20px 却多一个状态、一次点击、一个要解释的词（北京老陈 2026-11-01 判「画蛇添足」） |
| 不可用目录置灰区 | 后端清库后整块删除 | **保持删除** | 库里不再有不可用行，UI 无需表达 |
| 「上次保存被拒」留痕区 | 整块删除 | **改为「草稿恢复」**（不是常驻留痕） | 删掉留痕会丢数据（见 §4.5）；但常驻红字框是噪音。改成：422 时把用户提交原样存进 store，下次打开面板据此恢复草稿 + 一条可关闭的黄色恢复条 |
| [复制全部] | 新增 | **删除** | 没有下游任务（面板内没有"粘贴到提示词"的落点）。行级「复制路径」才是真需求 |
| 每行 2 个彩色 Tag（属性 + 默认） | 保留并统一颜色 | **属性降级为纯文字**，只保留「默认」一个视觉标记 | 属性是**分类文字**，不是**状态**。四种颜色并排 = 颜色通胀，路径反成配角 |
| 行尾 `[编辑][删除]` 文字钮 | 由图标钮改成文字钮 | **回到图标钮**，固定 104px 动作列 | 文字钮占宽翻倍，且在 720 宽下挤路径；图标 + `aria-label` + Tooltip 一样可达 |
| 打开自动聚焦新增框 | 新增 | **删除** | 打开面板的第一意图是"核对现有配置"，不是"加一条"。抢焦点还会让 Esc 落在输入框里，把关闭语义吃掉 |
| `keyboard={false}`（禁用弹窗级 Esc） | 新增 | **删除**，恢复 Esc=关闭 + 脏数据二次确认 | 关闭是最高频操作，禁用 ESC 是拿常识换实现便利 |

### 0.4 被本版推翻的 v4.1 决策（留档，防翻案）

| 编号 | v4.1 决策 | 推翻理由（含实测） |
|------|-----------|-------------------|
| R1 | 弹窗宽 800→**640** | 640 内容宽 592、动作钮换文字后路径列只剩 ≈378px（mono 14 约 54 字）。本仓典型路径 `F:\OmniAgentAs-01\backend\app\services\chat\workspace_service.py` 64 字 **必截**。改 720 + 两行结构 + 中段省略 |
| R2 | 行尾文字钮 + "严禁藏进悬停" | 现状本来就是常驻图标钮（`SessionWorkspacePanel.tsx:426-459`），问题不存在；改文字钮后动作区 56→104px，路径净损失 48px |
| R3 | 节标题 `fontSize: 13` | `stepStyles.ts:82` 明令"废 13 半档，统一 14/12 二档"。新写 13 是把已消灭的游离档重新引回来。改用 `FontSize.SECONDARY(12)+MEDIUM` |
| R4 | 间距 "块间 LG=12 / 块内 XS·SM" | 4/6/12 三档混排正是"狗啃"来源。改等比三档 **4 / 8 / 16**（XS / MD / XL），本面板禁用 LG=12 |

| R6 | `bodyMaxHeight: 62vh` | 62vh 不解决问题（长列表照样撑高），且 §七 代码根本没落。改为列表区 `max-height: 40vh` 内部滚动，footer 恒定可见 |
| R7 | 「默认」Tag 色并入 `PROP_COLORS` | 属性不再用颜色，`PROP_COLORS` 本面板不再引用（历史页继续用，不动）。少一个共享物，少一处漂移 |
| R8 | 编辑态"消除高度跳变" | 行内编辑必然展开高度。不假装消除，改为**不设动画**（避免抖动），并在验收里如实写明 |

## 二 信息架构

### 2.1 内容分层

| 层级 | 内容 | 处理 |
|------|------|------|
| **L1 必看** | 已配置目录列表（路径 = 唯一主信息） | 常驻，占最大面积 |
| **L2 高频操作** | 新增目录、行级编辑/删除/复制 | 常驻但克制（图标钮、一行式） |
| **L3 偶尔** | 属性、备注 | 第二行小字，不与路径抢位 |
| **L4 参考** | 项目根、授权目录 | **折叠**，默认一行摘要，按需展开 |
| **L5 异常** | 加载失败、保存被拒 | 条件渲染，出现即全幅，消失即腾空 |

### 2.3 只读区（两行常驻，不折叠）

| 项 | 规格 |
|----|------|
| 结构 | 两行固定：`图标(14) + 标签列(72 定宽) + 值列(flex, mono 12) + 复制图标(跟在值末尾)` |
| 行高 | 22px；上下内边距 `Spacing.XS(4)` → 整块 ≈52px（原 72px） |
| 标签 | 「项目根」「授权目录」，12px `#595959`，定宽 72 才可能值列同列起 |
| 值 | mono 12 `#595959`，单行尾省略 + `title` 全量；授权目录多条用「；」连接 |
| 复制 | `Typography.copyable`，图标紧跟值末尾（近邻原则，比右缘对齐少一列且更少鼠标移动）；无值时不渲染 |
| 底色 | 无底色无边框，仅靠 52px 的组间留白（`Spacing.XL`）与列表分开 |

**为什么不折叠**：这两行回答的是"这次能写哪里"，是每次打开都要扫一眼的上下文，不是低价值信息。折叠需要多一个状态、一次点击、一个「详情/收起」的词汇，换来的只有 20px——**这是画蛇添足**（北京老陈 2026-11-01 裁定）。要压高度就压排版，不压可读性。

### 2.4 列表行（核心结构）

行 = 一个 2 列网格，不是三列 flex：

```
grid-template-columns: minmax(0, 1fr) 104px;   /* 内容列 | 动作列 */
column-gap: 8px;
min-height: 48px;                              /* 两行统一高度，禁按有无备注变高 */
```

| 行内元素 | 规格 | 说明 |
|---------|------|------|
| 行1 路径 | mono 14 / `Colors.TEXT.STRONG` / 单行 / **中段省略** / `title=全路径` | 唯一主信息 |
| 行2 属性 | 12 / `#595959` / 纯文字（无底色无边框） | 分类不是状态 |
| 行2 分隔 | `·` 11 / `#8c8c8c`（图形级，非文字信息） | 极弱分隔 |
| 行2 备注 | 12 / `#595959` / 单行尾省略 / `title` | 无备注则整段不渲染 |
| 行2「默认」 | 11 / `Colors.INFO` / 1px 描边 / 圆角 4 | 列表里**唯一**彩色元素 |
| 动作列 | 3 个图标钮（复制 / 编辑 / 删除），32×28，间距 4 | 固定列宽 → 换行/长短路径都不会左右跳 |
| 删除钮 | 默认 `TEXT.SECONDARY`，hover 转 `ERROR` | 颜色留给意图，不给常态 |

**行高为什么是 48 而不是 40**：两行文本（20 + 16）+ 上下 6px 内边距 = 48；单行 40 放两行会挤到行间无呼吸。48 同时保证"有无备注的行高度一致"——这才是真正的规整。

### 2.5 新增区（一行式 + 备注第二行）

```
新增目录
[ 路径 flex:1 ] [ 属性 ▾ 140 ] [ + 添加 88 ]      ← 三件套同一行，右端一条线
[ 备注（可选）          全宽                    ]  ← 第二行
```

- 路径框：`flex:1` 吃掉剩余宽度（672 − 140 − 88 = 444px）；
- 属性：定宽 140（"读写工作区" 5 字 + 箭头 + 内边距刚好，禁自适应）；
- 添加钮：定宽 88（`+ 添加` 图标+两字），**右端与属性框右缘同一竖线**；
- 备注：全宽第二行，永不和路径抢宽；
- 校验红字：挂在路径框**正下方** 11px（让错误贴着出错的东西，而不是飘到区块底部）。

### 2.6 状态互斥表（同一时刻只允许一种）

| 状态 | 列表区 | 新增区 | 确定钮 | 附注 |
|------|--------|--------|--------|------|
| `loading` | 3 行骨架（与真实行等高） | 隐藏 | 禁用 | 不显示空态 |
| `ready` + 空 | 空态（图标 + 一句引导 + 添加钮） | 显示 | 可用 | 空态文案要说明"发送消息会建默认区" |
| `ready` + 有 | 列表 | 显示 | 可用 | — |
| `failed` | **不渲染**（禁显示空态） | 隐藏 | 禁用 | 只显示全幅错误条 + 重试 |
| `rejected`（草稿恢复） | 列表 + 问题行红字原因 | 显示 | **禁用**（需先修正/移除） | 顶部黄色恢复条 + 「放弃修改」 |
| 编辑中 | 该行展开为编辑块 | 显示 | 可用 | 动作列该行为空 |

## 三 视觉系统

### 3.1 网格（唯一真网格）

### 3.2 排版层级（只用 14 / 12 / 11 三档）

| 角色 | 字号 | 字重 | 颜色 | 颜色令牌 |
|------|------|------|------|---------|
| 路径（主信息） | 14 mono | 400 | `#333333` | `Colors.TEXT.STRONG` |
| 节标题（已配置目录/新增目录） | 12 | 500 | `#595959` | `Colors.TEXT.PRIMARY` |
| 行数/计数 | 11 | 400 | `#595959` | `Colors.TEXT.PRIMARY` |
| 属性 / 备注 | 12 | 400 | `#595959` | `Colors.TEXT.PRIMARY` |
| 「默认」标记 | 11 | 400 | `#096dd9` | `Colors.INFO` |

### 3.3 间距节奏（4 / 8 / 16，等比三档）

| 层级 | 令牌 | 值 | 用在哪 |
|------|------|----|--------|
| 行内 | `Spacing.XS` | 4 | 图标与文字、Tag 与备注、动作钮之间 |
| 块内 | `Spacing.MD` | 8 | 节标题与内容、路径行与备注行、输入框与红字 |
| 区块间 | `Spacing.XL` | 16 | 只读区↔列表、列表↔新增区、内容↔footer |

**本面板禁用 `Spacing.LG(12)` 与 `Spacing.SM(6)`**：4/6/12 三档混排是"看着齐、实际乱"的根源，等比 4/8/16 才能让眼睛一次建立节奏。

### 3.4 颜色规则（颜色=状态，分类=文字）

| 允许用色的地方 | 色 | 语义 |
|---------------|----|------|
| 「默认」标记 | `Colors.INFO` | 系统所有、不可删（状态） |
| 删除钮 hover | `Colors.ERROR` | 破坏性意图（意图） |
| 错误条背景/边框 | `ERROR_BG` / `ERROR_BORDER` | 失败（状态） |
| 错误文字 | `Colors.ERROR_TEXT` | 失败（状态，可读性优先） |
| 恢复条背景/边框 | `WARNING_BG` / `WARNING` | 待处理（状态）；**条内正文用 `TEXT.PRIMARY`**（`#AD6800` 在 `#fffbe6` 上仅 4.3:1，不足以承载正文） |

**禁止**：用颜色区分「读取工作区 / 读写工作区 / 写工作区」。它们是**分类**，用文字表达；一旦上色，四种颜色并列会让路径（真正的数据）沦为背景。`PROP_COLORS` 本面板**不再引用**（历史页继续使用，不动）。

### 3.5 控件与圆角

| 项 | 值 | 依据 |
|----|----|------|
| 控件高 | **28**（`SETTINGS_CONTROL_HEIGHT`） | 已有推导：14px 文字行盒 20 + 留白 3×2 + 边框 2 = 28 |
| 控件圆角 | **4**（`SETTINGS_RADIUS`） | 同页多数派，已有审计依据 |
| 容器圆角 | **6**（`Radius.DEFAULT`） | 嵌套规则：**外层 ≥ 内层**，容器 6 包控件 4 才不"内圆顶外角" |
| 图标钮尺寸 | 32 宽 × 28 高 | 与控件同高，横向留 2px 触达余量 |
| footer 按钮 | 28 高，间距 8 | `controlHeight` 不覆盖 footer，需 `style` 单补 |

**圆角只有一套规则**：不是"两个标准"，是"外层容器 6 / 内层控件 4"的嵌套关系。v4.1 把这条写成"双重标准"是表述失误。

### 3.6 路径可读性专项（本版的核心）

#### 3.6.1 字符预算实测

| 指标 | Before（v4.1 现状） | After（v5.1） |
|------|--------------------|--------------|
| 弹窗宽 | 800 | **720** |
| 内容宽 | 752 | 672 |
| 行结构 | 单行（路径+2 Tag+备注同排） | **两行**（路径独占行1） |
| 动作区占宽 | 2 图标 24×2 + antd `margin-inline-start:48` ≈ 104 | 3 图标 32×3 + 8 = **104**（固定列） |
| 路径列净宽 | ≈ 752−104−110(Tag)−12 ≈ **526** | 672−104−8 = **560** |
| 路径字号 | 12 比例体（≈6.6px/字） | **14 mono（≈7.0px/字）** |
| 可见字符 | ≈ 79 字 | ≈ **80 字** |
| 截断策略 | 尾省略（丢掉末段） | **中段省略**（保住末段）+ `title` 全路径 |

**结论要说实话**：可见字符数几乎持平（79→80）。真正的收益不是"看得更多"，而是**看得到该看的那一段**——路径的价值在末段（目录名/文件名），尾省略恰好先扔掉它。

#### 3.6.2 中段省略算法

```
max = 76 字（560px ÷ 7px，留 4 字给光标/滚动条）
若 len ≤ max → 原样
否则 head = floor((max−1)×0.35)，tail = max−1−head
输出 = p.slice(0, head) + "…" + p.slice(-tail)
```

- 头 35% / 尾 65%：盘符与前两级目录用于定位，末段用于识别；
- 保留 `white-space:nowrap; overflow:hidden; text-overflow:ellipsis` 作为兜底（字体回退时仍不破版）；
- 完整路径走原生 `title`——鼠标悬停即见，且**不引入 tooltip 组件层级**（弹窗内 tooltip 常被 z-index 咬）。

#### 3.6.3 为什么不加宽到 900

720 是"内容宽 672 = 80 字 mono"与"1280 屏仍留 280px 背景"的平衡点。加宽到 900 只能多 25 字，却让弹窗在 1280 屏上压迫感陡增。**路径问题用截断策略解决，不用宽度解决。**

## 四 交互规格

### 4.1 事务模型

```
打开面板 ──► 载入（skeleton） ──► 编辑（draft，可撤销）
                                      │
                     ┌────────────────┼─────────────────┐
                     ▼                ▼                 ▼
                  [取消]/×/遮罩    [确定]            Esc（脏→确认）
                     │                │
                  丢弃草稿        提交 PATCH
                                      │
                         ┌────────────┴────────────┐
                         ▼                         ▼
                      200 OK                  422 整单拒绝
                      关闭面板                 ① 草稿存 store
                                              ② 逐条 toast 点名
                                              ③ 下次打开恢复草稿
```

要点：
- **一切破坏性行操作都是"草稿内"的**（删行、改路径），点「确定」才落库。因此**行级删除不需要二次确认**——「取消」就是撤销。v4.1 只在"删到空列表"时弹确认，是逻辑不一致（凭什么只有最后一条要确认）。
- 「确定」不 await 网络（v4.1 的正确设计，保留）：界面进度不能由一次网络往返决定。代价是失败后必须能恢复草稿 → §4.5。

### 4.2 键盘矩阵

| 位置 | 键 | 行为 |
|------|----|------|
| 窗体（无焦点在编辑行） | `Esc` | 关闭面板；**有未保存改动时先弹确认** |
| 路径输入框（新增区） | `Enter` | 添加当前条 |
| 路径输入框 | `Esc` | 有内容/有错 → 清空并清错；已空 → 冒泡到窗体（关闭） |
| 备注输入框 | `Enter` | 添加当前条 |
| 属性下拉 | `↑/↓/Enter` | 选择预设（antd 原生） |
| 列表行编辑 · 路径/备注 | `Enter` | 保存本行 |
| 列表行编辑 · 任意字段 | `Esc` | **取消本行编辑，不关窗**（`stopPropagation`） |
| 任意 | `Tab` | 只读区（复制）→ 列表（复制/编辑/删除）→ 新增路径 → 属性 → 备注 → 添加 → 取消 → 确定 |
| 任意 | `Shift+Tab` | 反向 |

**焦点陷阱**：不改 antd 默认（弹窗内 Tab 循环）。打开时不抢焦点到输入框——首焦点落在弹窗容器（antd 默认），读屏与键盘用户先听到标题。

### 4.3 焦点管理

| 时机 | 焦点去向 | 理由 |
|------|---------|------|
| 打开 | 弹窗容器（不抢） | 第一意图是核对，不是输入 |
| 空态点「添加目录」 | 新增路径框 | 明确的"我要加"信号 |
| 行点「编辑」 | 该行路径框（或备注框，若路径只读） | 就地编辑 |
| 行保存/取消 | 回到该行「编辑」钮 | 焦点不坠入 body |
| 行删除 | 下一行「编辑」钮；无则空态「添加目录」 | 键盘用户不迷路 |
| 422 恢复 | 恢复条 | 先告知，再操作 |

### 4.4 批量粘贴与输入兜底

```
粘贴文本含换行 → 按行拆分 → trim → 过滤空行
  合法行（绝对路径）→ 逐条入列（同路径覆盖属性/备注，不产生重复行）
  非法行 → **原样留在输入框**，红字提示「N 行不是绝对路径，已保留在输入框」
```

原则：**输入永不静默丢弃**。合法部分立即生效（省一次点击），非法部分留在原地等修正（不逼用户重打）。

### 4.5 保存被拒（422）的恢复

v4.1 的做法是"toast 一次，草稿随关闭蒸发"。v5.0 的做法：

1. `commit` 捕获 422 → `rejected = { items: 本次提交全量, bad: [{path, reason}] }` 存入 store（**不落库、不落 localStorage**，内存态）；
2. 逐条 toast 点名（保留 v4.1 的反馈方式）；
3. 用户下次打开面板：`GET` 仍照常拉（拿 `pruned` 与上下文），但**列表以 `rejected.items` 为准恢复草稿**，问题行第二行改为红字原因；
4. 顶部黄色恢复条：`上次保存未通过，已恢复你的修改（N 条需修正）` + 右端「放弃修改」（清空快照 → 重载库真值）；
5. 此时「确定」禁用，必须先修正或删除问题行——避免"点第二次还是 422"的死循环；
6. 提交成功 → 快照清空。

`is_default` 在恢复时按路径从 GET 结果重新贴上（否则默认行会"长出"删除按钮，见 §9.5 注释）。

### 4.6 三态视觉

| 态 | 视觉 | 文案 |
|----|------|------|
| 加载 | 3 行骨架（48px 行高） | — |
| 空 | `Empty.PRESENTED_IMAGE_SIMPLE`（小图，不用大图）+ Ghost「添加目录」 | 此会话尚未配置目录。发送消息后系统会自动创建默认工作区。 |
| 失败 | 全幅 `ERROR_BG` 条 + 左边文字 + 右边「重试」文字钮；**列表与空态都不渲染** | 目录读取失败，暂不能保存（避免用空列表覆盖已有目录）。 |

### 4.7 动效

**不加新动效**。沿用 antd Modal 默认开合（≈200ms）；行内编辑展开**不做高度动画**（会抖，且动画期间焦点框漂移）。理由是这类工具面板以效率为先，动画只保留"是否出现"的语义，不做"怎么出现"的表演。

def prune_unusable_rows(conn, session_id: str, unusable: list[dict]) -> int:
    """不可用行清库唯一出口（2026-11-01 小欧 新增）—— GET 与 reconcile 共用。

    库里必须只有可用目录（北京老陈令）: 不可用行（禁区/非法/不存在）一律从库表
    删除，不再"只上报不清"。三类 kind 处置口径一致，无差别清库。

    返回本轮实际清掉的行数（GET 带进响应 → 前端一次性提示，清理不再静默）。

    ⚠ 只删数据库行，绝不删除磁盘目录。磁盘目录的处置权在用户：
    移动盘未挂载时该行已被清，需要时重新添加一次。

    逐条 try/except：单条 DELETE 失败只跳过本轮，不拖垮整个请求。"""
    removed = 0
    for u in unusable:
        try:
            conn.execute(
                "DELETE FROM chat_session_workspaces WHERE session_id = ? AND path = ?",
                (session_id, u["path"]))
        except Exception as _e:
            _ws_warn(f"不可用行清库失败(本轮保留, 下轮再试): {u['path']} - {_e}")
            continue
        removed += 1
        _ws_warn(f"不可用行已清库({u['kind']}): {u['path']}")
    return removed


def _ws_precheck(paths: list[str]) -> list[dict]:
    """合法性预检：逐条走判据。返回被拒清单，不抛异常（调用方整单 422）。

    2026-11-01 小欧 - 补「目录必须存在」预检(is_dir)：missing 整单 422 逐条点名，
    库中禁止不存在的目录。禁区判定先行（与 classify_workspace_rows 裁决顺序一致）。"""
    rejected = []
    for p in paths:
        reason = _ws_deny_reason(p)
        if not reason and not Path(p).is_dir():
            reason = "目录不存在（不收不存在的路径）"
        if reason:
            rejected.append({"path": p, "reason": reason})
    return rejected


def _ensure_ws_dir(p: str) -> bool:
    """默认工作区物理目录创建/修复唯一出口（2026-11-01 小欧 新增）。

    mkdir 补建废除后，系统只在一处建目录——默认工作区（系统自己的区）；
    用户目录绝不在此建（北京老陈令：磁盘目录归用户处置）。
    失败仅告警返回 False：该行将被 classify 判 missing→清库，下次 reconcile 自愈重建。"""
    try:
        Path(p).mkdir(parents=True, exist_ok=True)
        return True
    except Exception as _e:
        _ws_warn(f"默认工作区目录创建失败(下轮 reconcile 自愈重建): {p} - {_e}")
        return False


def reconcile_session_workspaces(conn, session_id: str) -> list[tuple[str, str, Optional[str], bool]]:
    """创建新 Task 并绑定该会话时的唯一落盘入口。

    流程：
      1) 默认工作区缺失（无默认行 / 默认行不在当前项目根下）→ 登记新默认行 + _ensure_ws_dir
      2) 存量默认行磁盘目录丢失 → _ensure_ws_dir 修复（系统自己的区，不在清库裁决内）
      3) 其余条目：三类 kind（missing/denied/illegal）一律经 prune_unusable_rows 清库
         —— 废除 mkdir 补建：资源管理器删掉的目录不再被系统建回。
      4) 重读重判返回有效条目集（供 _load_ws_snapshot 构造任务快照）。

    ⚠ 只删数据库行，绝不删除磁盘目录；用户目录永不自动建。"""
    from app.config import get_config
    rows = get_session_workspaces(conn, session_id)
    current_root = get_config().get_project_root()

    # ── 默认工作区是否需创建/重建 ──
    need_new_default = True
    for r in rows:
        if r["is_default"] and Path(r["path"]).parent == Path(current_root):
            need_new_default = False
            break

    if need_new_default:
        d = _build_default_workspace_dir(session_id)
        if d:
            try:
                _p = _normalize_ws_path(d)
                # 先登记/升级新默认，再降级其余默认行 —— 顺序不可颠倒：
                # 先降后插一旦插入失败，会话将没有任何默认工作区
                conn.execute(
                    "INSERT INTO chat_session_workspaces"
                    "(session_id, path, workspace_property, memo, is_default) "
                    "VALUES (?, ?, ?, ?, 1) "
                    "ON CONFLICT(session_id, path) DO UPDATE SET "
                    "workspace_property = excluded.workspace_property, "
                    "memo = excluded.memo, is_default = 1",
                    (session_id, _p, DEFAULT_WS_PROP, DEFAULT_MEMO))
                conn.execute(
                    "UPDATE chat_session_workspaces SET is_default = 0 "
                    "WHERE session_id = ? AND is_default = 1 AND path <> ?",
                    (session_id, _p))
                _ensure_ws_dir(_p)     # mkdir 补建废除后，默认区物理目录只在此建
                logger.info(f"[chat] 默认工作区已就绪: session={session_id} path={_p}")
            except Exception as _e:
                logger.warning(f"[chat] 默认工作区登记失败（本轮无默认区，下次再试）: {_e}")
        rows = get_session_workspaces(conn, session_id)

    # 存量默认行的磁盘目录丢失 → 系统自己的区，修复而非清库
    for r in rows:
        if r["is_default"] and not Path(r["path"]).is_dir():
            _ensure_ws_dir(r["path"])

    _, unusable = classify_workspace_rows(rows)
    prune_unusable_rows(conn, session_id, unusable)   # 三类 kind 一律清库，共用唯一出口

    return _load_workspaces_conn(conn, session_id)    # 重读重判：有效条目集最终确认

  bad: { path: string; reason: string }[];
}

interface WorkspaceState {
  /** 当前所属会话；异步结果回来时与它比对，不同即丢弃（切会话竞态） */
  sessionId: string;
  list: WorkspaceEntry[];

const listeners = new Set<() => void>();

let loadSeq = 0;
/** 提交代际：并发提交只认最后一次 */
let commitSeq = 0;

const subscribe = (listener: () => void): (() => void) => {
  listeners.add(listener);
  return () => {
    listeners.delete(listener);
  };
};

/** 422 信封：后端 detail 经全局异常处理器包装成 error.workspace_rejected */
const rejectionsOf = (e: unknown): { path: string; reason: string }[] => {
  const raw = (
    e as {
      response?: { data?: { error?: { workspace_rejected?: unknown } } };
    }
  )?.response?.data?.error?.workspace_rejected;
  return Array.isArray(raw) ? (raw as { path: string; reason: string }[]) : [];
};

/** 失败对账：把徽标拉回库里的真值。
 *  超时/连接中断时后端可能已写成功，前端无从分辨，只能以库为准。 */
const reconcile = async (sessionId: string) => {
  try {
    const r = await sessionApi.getWorkspaces(sessionId);
    if (state.sessionId !== sessionId) return;
    setState({ ...state, list: r.workspaces });   // rejected 保留：草稿还没处置
  } catch {
    // 对账本身失败：保持旧值，不做二次提示（用户刚看过主错误）
  }
};

/** 切会话取数：无会话=清场；有会话=向库真源拉一次 */
const loadSession = async (sessionId: string): Promise<void> => {
  const seq = ++loadSeq;
  if (!sessionId) {
    setState(EMPTY);
    return;
  }
  if (state.sessionId !== sessionId) {
    setState({ sessionId, list: [], rejected: null });   // 换会话即弃旧草稿
  }
  try {
    const r = await sessionApi.getWorkspaces(sessionId);
    if (seq !== loadSeq || state.sessionId !== sessionId) return;
    setState({ ...state, list: r.workspaces });
  } catch {
    if (seq !== loadSeq || state.sessionId !== sessionId) return;
    setState({ ...state, list: [] });
  }
};

/** 提交：调用方点完就关，结果走 store 与 toast。
 *  成功 → 以请求列表为权威落位，清空快照；
 *  422  → 快照留存（下次打开恢复草稿）+ 逐条点名 + 对账；
 *  其他 → 全局错误通道 + 对账。 */
const commit = async (
  sessionId: string,
  items: WorkspacePatchItem[]
): Promise<void> => {
  const seq = ++commitSeq;
  try {
    await sessionApi.patchWorkspaces(sessionId, items);
    if (seq !== commitSeq || state.sessionId !== sessionId) return;
    setState({
      sessionId,
      // 三字段原样保留，禁止退化成 { path }
      list: items.map((i) => ({ ...i })),
      rejected: null,
    });
  } catch (e: unknown) {
    if (seq !== commitSeq) return;
    const bad = rejectionsOf(e);
    if (bad.length) {
      if (state.sessionId === sessionId) {
        // 草稿原样留住：被拒的是"整单"，用户改完一条不该重打另外 19 条
        setState({ ...state, rejected: { items: items.map((i) => ({ ...i })), bad } });
      }
      // 统一错误通道：toast 逐条点名（查表+去重+分级），禁自造 notify/裸调 message
      bad.forEach((x) => showMessage(ErrorType.WORKSPACE_REJECTED, `${x.path}：${x.reason}`));
    } else {
      handleError(e);
    }
    await reconcile(sessionId);
  }
};

/** 用户放弃被拒草稿：清快照，面板据库真值重载 */
const clearRejected = (sessionId: string): void => {
  if (state.sessionId !== sessionId || !state.rejected) return;
  setState({ ...state, rejected: null });
};

export const workspaceStore = {
  subscribe,
  getSnapshot,
  loadSession,
  commit,
  clearRejected,
};

  /** 确定 → 本地立即关闭 + 后台提交（不可 await，界面进度不能由网络往返决定） */
  const confirm = () => {
    if (loadState !== 'ready' || badCount > 0) return; // 有未修正的问题行时禁提交
    void workspaceStore.commit(
      sessionId,
      entries.map((e) => ({
        path: e.path,
        workspace_property: propValue(e.workspace_property),
        memo: e.memo.trim() || null,
      }))
    );
    dirtyRef.current = false;
    onClose();
  };

  /** 关闭请求：脏数据先确认（Esc / × / 遮罩 同一入口） */
  const requestClose = () => {
    if (!dirtyRef.current) {
      onClose();
      return;
    }
    Modal.confirm({
      title: '放弃未保存的修改？',
      content: '目录列表的改动尚未保存，关闭后不再保留。',
      okText: '放弃修改',
      cancelText: '继续编辑',
      okButtonProps: { danger: true },
      onOk: onClose,
    });
  };

  /** 放弃被拒草稿 → 清快照 + 按库真值重载 */
  const discardRecovered = () => {
    workspaceStore.clearRejected(sessionId);
    dirtyRef.current = false;
    setBadMap({});
    setRecovered(false);
    void load();
  };

  /** 快照里未能对应到任何行的原因（极少见：后端归一化后路径形态变了） */
  const matchedKeys = new Set(entries.map((e) => e.path.toLowerCase()));
  const unmatchedBad = Object.entries(badMap).filter(([k]) => !matchedKeys.has(k));

  return (
    <Modal
      open={open}
      width={settingsModalWidth.workspace}
      destroyOnHidden
      maskClosable
      title="事项工作区"
      okText="确定"
      cancelText="取消"
      onOk={confirm}
      onCancel={requestClose}
      okButtonProps={{
        disabled: loadState !== 'ready' || badCount > 0,
        style: { height: SETTINGS_CONTROL_HEIGHT },
      }}
      cancelButtonProps={{ style: { height: SETTINGS_CONTROL_HEIGHT } }}
      styles={{ body: { paddingTop: Spacing.MD } }}
    >
      <ConfigProvider
        theme={{
          token: {
            controlHeight: SETTINGS_CONTROL_HEIGHT, // 控件高 28（单点收口）
            borderRadius: SETTINGS_RADIUS, // 圆角 4（单点收口）
          },
        }}
      >
        {/* 只读区：两行常驻（项目根 / 授权目录）。标签列定宽 → 值列同列起；
            复制图标跟值走（近邻），不做右缘对齐 —— 两行不值得为此加一列。 */}
        <div style={{ display: 'flex', flexDirection: 'column', padding: `${Spacing.XS}px 0` }}>
          <div style={{ display: 'flex', alignItems: 'center', gap: Spacing.XS, minHeight: 22 }}>
            <FolderOutlined style={{ fontSize: 14, color: Colors.TEXT.SECONDARY, flexShrink: 0 }} />
            <Typography.Text
              style={{
                width: CTX_LABEL_WIDTH,
                flexShrink: 0,
                fontSize: FontSize.SECONDARY,
                color: Colors.TEXT.PRIMARY,
              }}
            >
              项目根
            </Typography.Text>
            <Typography.Text
              ellipsis={{ tooltip: projectRoot || '（未配置）' }}
              copyable={
                projectRoot
                  ? { text: projectRoot, tooltips: ['复制', '已复制'] }
                  : false
              }
              style={{
                fontFamily: FontFamily.MONO,
                fontSize: FontSize.SECONDARY,
                color: Colors.TEXT.PRIMARY,
                minWidth: 0,
              }}
            >
              {projectRoot || '（未配置）'}
            </Typography.Text>
          </div>
          <div style={{ display: 'flex', alignItems: 'center', gap: Spacing.XS, minHeight: 22 }}>
            <LockOutlined style={{ fontSize: 14, color: Colors.TEXT.SECONDARY, flexShrink: 0 }} />
            <Typography.Text
              style={{
                width: CTX_LABEL_WIDTH,
                flexShrink: 0,
                fontSize: FontSize.SECONDARY,
                color: Colors.TEXT.PRIMARY,
              }}
            >
              授权目录
            </Typography.Text>
            <Typography.Text
              ellipsis={{ tooltip: allowedDirs.join('；') || '（未配置）' }}
              copyable={
                allowedDirs.length
                  ? { text: allowedDirs.join('\n'), tooltips: ['复制', '已复制'] }
                  : false
              }
              style={{
                fontFamily: FontFamily.MONO,
                fontSize: FontSize.SECONDARY,
                color: Colors.TEXT.PRIMARY,
                minWidth: 0,
              }}
            >
              {allowedDirs.length ? allowedDirs.join('；') : '（未配置）'}
            </Typography.Text>
          </div>
        </div>

        {/* 恢复条：保存被拒后草稿已恢复，问题行需修正或移除 */}
        {recovered && badCount > 0 && (
          <div
            role="status"
            style={{
              marginTop: Spacing.MD,
              padding: Spacing.MD,
              background: Colors.WARNING_BG,
              border: `1px solid ${Colors.WARNING}`,
              borderRadius: Radius.DEFAULT,
            }}
          >
            <div style={{ display: 'flex', alignItems: 'center', gap: Spacing.MD }}>
              <Typography.Text
                style={{ fontSize: FontSize.SECONDARY, color: Colors.TEXT.PRIMARY, flex: 1 }}
              >
                上次保存未通过，已恢复你的修改（{badCount} 条需修正）。修正或移除后才能保存。
              </Typography.Text>
              <Button
                type="text"
                size="small"
                style={{ height: SETTINGS_CONTROL_HEIGHT, flexShrink: 0 }}
                onClick={discardRecovered}
              >
                放弃修改
              </Button>
            </div>
            {unmatchedBad.slice(0, 3).map(([p, r]) => (
              <div
                key={p}
                style={{ fontSize: FontSize.SMALL, color: Colors.TEXT.PRIMARY, marginTop: Spacing.XS }}
              >
                · {p}：{r}
              </div>
            ))}
          </div>
        )}

        {/* 节标题：已配置目录 + 计数 */}
        <div
          style={{
            display: 'flex',
            alignItems: 'baseline',
            gap: Spacing.XS,
            marginTop: Spacing.XL,
            marginBottom: Spacing.MD,
          }}
        >
          <Typography.Text
            style={{
              fontSize: FontSize.SECONDARY,
              fontWeight: FontWeight.MEDIUM,
              color: Colors.TEXT.PRIMARY,
            }}
          >
            已配置目录
          </Typography.Text>
          <Typography.Text style={{ fontSize: FontSize.SMALL, color: Colors.TEXT.PRIMARY }}>
            {entries.length} 项
          </Typography.Text>
        </div>

        {/* 三态互斥：加载骨架 / 失败只给错误条 / 就绪才出列表 */}
        {loadState === 'loading' && (
          <div aria-hidden>
            {[0, 1, 2].map((i) => (
              <div
                key={i}
                style={{
                  minHeight: 48,
                  display: 'flex',
                  flexDirection: 'column',
                  justifyContent: 'center',
                  gap: Spacing.XS,
                }}
              >
                <Skeleton.Input active size="small" style={{ width: '70%', height: 16 }} />
                <Skeleton.Input active size="small" style={{ width: '40%', height: 14 }} />
              </div>
            ))}
          </div>
        )}

        {loadState === 'failed' && (
          <div
            role="alert"
            style={{
              marginTop: Spacing.MD,
              padding: Spacing.MD,
              background: Colors.ERROR_BG,
              border: `1px solid ${Colors.ERROR_BORDER}`,
              borderRadius: Radius.DEFAULT,
              display: 'flex',
              alignItems: 'center',
              gap: Spacing.MD,
            }}
          >
            <Typography.Text
              style={{ fontSize: FontSize.SECONDARY, color: Colors.ERROR_TEXT, flex: 1 }}
            >
              目录读取失败，暂不能保存（避免用空列表覆盖已有目录）。
            </Typography.Text>
            <Button
              size="small"
              type="text"
              style={{ height: SETTINGS_CONTROL_HEIGHT, flexShrink: 0 }}
              onClick={() => void load()}
            >
              重试
            </Button>
          </div>
        )}

        {loadState === 'ready' && (
          <List
            role="list"
            dataSource={entries.map((d) => ({ ...d, key: d.path }))}
            locale={{
              emptyText: (
                <Empty
                  image={Empty.PRESENTED_IMAGE_SIMPLE}
                  description={
                    <span style={{ fontSize: FontSize.SECONDARY, color: Colors.TEXT.PRIMARY }}>
                      此会话尚未配置目录。发送消息后系统会自动创建默认工作区。
                    </span>
                  }
                >
                  <Button
                    ghost
                    type="primary"
                    size="small"
                    style={{ height: SETTINGS_CONTROL_HEIGHT }}
                    onClick={() => addPathRef.current?.focus()}
                  >
                    添加目录
                  </Button>
                </Empty>
              ),
            }}
            renderItem={(e) => {
              const editing = editingPath === e.path;
              const reason = badMap[e.path.toLowerCase()];
              return (
                <List.Item style={{ padding: 0, minHeight: 48 }}>
                  {/* 真网格：内容列多少字都不影响动作列位置 */}
                  <div
                    style={{
                      width: '100%',
                      display: 'grid',
                      gridTemplateColumns: `minmax(0, 1fr) ${ACTION_COL}px`,
                      columnGap: Spacing.MD,
                      alignItems: 'center',
                    }}
                  >
                    <div style={{ minWidth: 0 }}>
                      {editing ? (
                        /* 编辑态：行内展开（高度变化是显式动作的结果，不做动画） */
                        <div style={{ width: '100%' }}>
                          <Input
                            ref={editPathRef}
                            value={editPath}
                            placeholder="目录路径"
                            disabled={e.is_default}
                            status={editErr ? 'error' : undefined}
                            style={{ fontFamily: FontFamily.MONO }}
                            onChange={(ev) => {
                              setEditPath(ev.target.value);
                              setEditErr('');
                            }}
                            onPressEnter={saveEdit}
                            onKeyDown={(ev) => {
                              if (ev.key === 'Escape') {
                                ev.stopPropagation(); // 行级取消，不关窗
                                cancelEdit();
                              }
                            }}
                          />
                          {e.is_default && (
                            <Typography.Text
                              style={{
                                fontSize: FontSize.SECONDARY,
                                color: Colors.TEXT.PRIMARY,
                                display: 'block',
                                marginTop: Spacing.XS,
                              }}
                            >
                              默认工作区路径由系统按项目根生成，不可修改；如需换落点请新增目录。
                            </Typography.Text>
                          )}
                          <Space.Compact style={{ width: '100%', marginTop: Spacing.XS }}>
                            <AutoComplete
                              value={editProp}
                              options={propOptions}
                              onChange={setEditProp}
                              style={{ width: 140 }}
                              placeholder="属性"
                            />
                            <Input
                              ref={editMemoRef}
                              value={editMemo}
                              placeholder="备注（可选）"
                              onChange={(ev) => setEditMemo(ev.target.value)}
                              onPressEnter={saveEdit}
                              onKeyDown={(ev) => {
                                if (ev.key === 'Escape') {
                                  ev.stopPropagation();
                                  cancelEdit();
                                }
                              }}
                              style={{ flex: 1 }}
                            />
                          </Space.Compact>
                          {editErr && (
                            <Typography.Text
                              style={{
                                display: 'block',
                                marginTop: Spacing.XS,
                                fontSize: FontSize.SMALL,
                                color: Colors.ERROR_TEXT,
                              }}
                            >
                              {editErr}
                            </Typography.Text>
                          )}
                          <Space size={Spacing.MD} style={{ marginTop: Spacing.XS }}>
                            <Button
                              type="primary"
                              size="small"
                              style={{ height: SETTINGS_CONTROL_HEIGHT }}
                              onClick={saveEdit}
                            >
                              保存
                            </Button>
                            <Button
                              size="small"
                              style={{ height: SETTINGS_CONTROL_HEIGHT }}
                              onClick={cancelEdit}
                            >
                              取消
                            </Button>
                          </Space>
                        </div>
                      ) : (
                        <>
                          {/* 行1：路径（唯一主信息，中段省略保末段） */}
                          <Typography.Text
                            title={e.path}
                            style={{
                              display: 'block',
                              fontFamily: FontFamily.MONO,
                              fontSize: FontSize.PRIMARY,
                              color: Colors.TEXT.STRONG,
                              lineHeight: '20px',
                              whiteSpace: 'nowrap',
                              overflow: 'hidden',
                              textOverflow: 'ellipsis',
                            }}
                          >
                            {midEllipsis(e.path)}
                          </Typography.Text>
                          {/* 行2：默认标记 + 属性（分类文字，不上色）+ 备注 */}
                          <div
                            style={{
                              display: 'flex',
                              alignItems: 'center',
                              gap: Spacing.XS,
                              marginTop: 2,
                              minHeight: 16,
                              minWidth: 0,
                            }}
                          >
                            {e.is_default && (
                              <Tag
                                style={{
                                  margin: 0,
                                  padding: '0 4px',
                                  fontSize: FontSize.SMALL,
                                  lineHeight: '14px',
                                  color: Colors.INFO,
                                  borderColor: Colors.INFO,
                                  background: Colors.BG.PRIMARY,
                                  borderRadius: Radius.SM,
                                }}
                              >
                                默认
                              </Tag>
                            )}
                            <Typography.Text
                              style={{
                                fontSize: FontSize.SECONDARY,
                                color: Colors.TEXT.PRIMARY,
                                flexShrink: 0,
                              }}
                            >
                              {propLabel(e.workspace_property)}
                            </Typography.Text>
                            {(reason || e.memo) && (
                              <Typography.Text
                                aria-hidden
                                style={{ fontSize: FontSize.SMALL, color: Colors.BORDER.STRONG }}
                              >
                                ·
                              </Typography.Text>
                            )}
                            {reason ? (
                              <Typography.Text
                                ellipsis={{ tooltip: reason }}
                                style={{
                                  fontSize: FontSize.SMALL,
                                  color: Colors.ERROR_TEXT,
                                  minWidth: 0,
                                }}
                              >
                                {reason}
                              </Typography.Text>
                            ) : e.memo ? (
                              <Typography.Text
                                ellipsis={{ tooltip: e.memo }}
                                style={{
                                  fontSize: FontSize.SECONDARY,
                                  color: Colors.TEXT.PRIMARY,
                                  minWidth: 0,
                                }}
                              >
                                {e.memo}
                              </Typography.Text>
                            ) : null}
                          </div>
                        </>
                      )}
                    </div>

                    {/* 动作列：常驻图标（复制/编辑/删除），删除 hover 才红 */}
                    <div style={{ display: 'flex', justifyContent: 'flex-end', gap: Spacing.XS }}>
                      {!editing && (
                        <>
                          <Tooltip title="复制路径">
                            <Button
                              type="text"
                              icon={<CopyOutlined />}
                              aria-label="复制路径"
                              style={{ color: Colors.TEXT.SECONDARY, height: SETTINGS_CONTROL_HEIGHT, width: 32 }}
                              onClick={() => void copyPath(e.path)}
                            />
                          </Tooltip>
                          <Tooltip
                            title={
                              e.is_default
                                ? '编辑属性/备注（默认工作区路径由系统生成）'
                                : '编辑该目录'
                            }
                          >
                            <Button
                              type="text"
                              icon={<EditOutlined />}
                              aria-label="编辑目录"
                              style={{ color: Colors.TEXT.SECONDARY, height: SETTINGS_CONTROL_HEIGHT, width: 32 }}
                              onClick={() => startEdit(e)}
                            />
                          </Tooltip>
                          {!e.is_default && (
                            <Tooltip title="移除该目录">
                              <Button
                                type="text"
                                danger
                                icon={<DeleteOutlined />}
                                aria-label="移除目录"
                                style={{ color: Colors.TEXT.SECONDARY, height: SETTINGS_CONTROL_HEIGHT, width: 32 }}
                                onClick={() => remove(e.path)}
                              />
                            </Tooltip>
                          )}
                        </>
                      )}
                    </div>
                  </div>
                </List.Item>
              );
            }}
          />
        )}

        {/* 新增区：就绪才出现（失败态不许用户在"看不到现状"时加东西） */}
        {loadState === 'ready' && (
          <>
            <div
              style={{
                marginTop: Spacing.XL,
                paddingTop: Spacing.MD,
                borderTop: `1px solid ${Colors.BORDER.LIGHT}`,
                marginBottom: Spacing.MD,
              }}
            >
              <Typography.Text
                style={{
                  fontSize: FontSize.SECONDARY,
                  fontWeight: FontWeight.MEDIUM,
                  color: Colors.TEXT.PRIMARY,
                }}
              >
                新增目录
              </Typography.Text>
            </div>
            <Space.Compact style={{ width: '100%' }}>
              <Input
                ref={addPathRef}
                style={{ flex: 1, fontFamily: FontFamily.MONO }}
                placeholder="输入完整路径（绝对路径）"
                status={inputErr ? 'error' : undefined}
                value={input}
                onChange={(e) => {
                  setInput(e.target.value);
                  setInputErr(
                    e.target.value.trim() && !isAbsolute(e.target.value.trim())
                      ? '请输入绝对路径'
                      : ''
                  );
                }}
                onPaste={handlePaste}
                onPressEnter={addEntry}
                onKeyDown={(ev) => {
                  if (ev.key !== 'Escape') return;
                  if (input || inputErr) {
                    ev.stopPropagation(); // 有内容时 Esc=就地清空，不关窗
                    setInput('');
                    setInputErr('');
                  }
                }}
              />
              <AutoComplete
                value={propInput}
                options={propOptions}
                onChange={setPropInput}
                style={{ width: 140 }}
                placeholder="属性"
              />
              <Button
                type="primary"
                icon={<PlusOutlined />}
                style={{ width: 88 }}
                disabled={!input.trim() || !isAbsolute(input.trim())}
                onClick={addEntry}
              >
                添加
              </Button>
            </Space.Compact>
            {inputErr && (
              <Typography.Text
                style={{
                  display: 'block',
                  marginTop: Spacing.XS,
                  fontSize: FontSize.SMALL,
                  color: Colors.ERROR_TEXT,
                }}
              >
                {inputErr}
              </Typography.Text>
            )}
            <Input
              style={{ width: '100%', marginTop: Spacing.MD }}
              placeholder="备注（可选，如：后端源码、产物输出）"
              value={memoInput}
              onChange={(e) => setMemoInput(e.target.value)}
              onPressEnter={addEntry}
              onKeyDown={(ev) => {
                if (ev.key === 'Escape' && memoInput) {
                  ev.stopPropagation();
                  setMemoInput('');
                }
              }}
            />
          </>
        )}
      </ConfigProvider>
    </Modal>
  );
}

## 十 收尾

本版把 UI 从"每处都规整"推到"每处都有理由"：

- 删了三样东西（常驻只读区、复制全部、彩色分类标签），加了两个必要承诺（草稿可恢复、清理可解释）；
- 网格不再是口号：行内真 `grid`，只承诺三条对齐线；
- 路径问题不靠加宽解决，靠**截断策略**解决——这才是一个设计师该给出的答案；
- 所有颜色、字号、间距、对比度都能落到令牌与实测值。

**未做（有意）**：不做拖拽排序（YAGNI，会话目录没有优先级语义）；不做目录树选择器（一个原生对话框 + Esc 就够，YAGNI）；不做"目录是否可写"探测（后端写线矩阵已裁决，前端重复判定只会漂移）。
