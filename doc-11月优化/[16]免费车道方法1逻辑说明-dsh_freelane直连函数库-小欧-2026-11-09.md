# [16] 免费车道方法1逻辑说明（dsh_freelane 直连函数库）

> 编写: 小欧 2026-11-09 | 状态: 冷备（未接进后端链路） | 验收记录: notes/调试笔记-2026-11-09.md §1、§4

## 一、定位：方法1 是什么

`D:\NDOOmniAgent\dsh_freelane\` 是 OpenCode Zen **免费车道的直连函数库**（Node）：
把上游 `dsh-our-free-model`（OpenCode Zen 免费车道 DSH 插件，JSDoc 周榜第 1）的核心车道逻辑
**原样**抽成可独立运行、可测试的库——`vendor/src/` 逐字拷贝（钉 upstream commit `9d714bb`，
O2A 1.4.7 血统），新写的只有薄编排层 `lib/`、CLI `bin/`、测试 `tests/`（25 文件, 0.2MB）。

**保真策略**：车道逻辑零重写；**Node 运行时本身就是门禁认可的官方客户端形状**
（2026-10-31 实测：curl/python 重放 429、Node/Go 200）——这层指针纹安全是选 Node 载体的根本原因。

## 二、与已投产的方法2 的关系（一句话讲清）

**方法2 = 方法1 的逻辑 + WARP 出口池**。两者同源（O2A 1.4.7 血统），协议形状逻辑逐条对应：

```
同一套免费车道协议逻辑（指纹 + 整形 + 工具改名）
├── 方法1  dsh_freelane/（Node 直连库, 钉 9d714bb）
│          = 这套逻辑 + 本机单出口 IP → 窗烧即瘫（等 Retry-After）
│          未接进后端，冷备中
└── 方法2  opencli/opencode2api（Go 网关, 钉 b296a61d, 同源）
           = 这套逻辑（已在生产跑）+ WARP 换 IP（429 换出口即刻 200）
```

**代码层面互不引用**：方法1 是 Node 库、方法2 是 Go 网关，后端只认 config.yaml 里
opencli 块的 HTTP 端点（`127.0.0.1:8080/v1`）。方法1 的价值已"并入"方法2 落地；
留库 = 留一份**无 WARP 依赖的等价实现**当最后回落。

## 三、核心逻辑：免费车道门禁事实（全部验收过，勿再考古）

| # | 门禁要求 | 做法 |
|---|---------|------|
| 1 | 端点族 | `/inference/openai/v1/chat/completions`（`/zen/v1/*` 对话已死） |
| 2 | UA 指纹 | `opencode/latest/2.2.3/cli` 整串、单独发送；**禁发** `x-opencode-request` |
| 3 | 会话头 | 四头同值（affinity/sid/opencode-session/opencode-session-id）+ `Bearer public` |
| 4 | 项目指纹 | `x-opencode-project` 每请求派生稳定 40-hex（`global` 是共享预烧桶，勿用） |
| 5 | 会话 id 铸造 | `ses_` + 12hex 降序编码（低 12 bit 0xfc0-0xfff）+ 14base62 + 慢钟日期（≤30 天） |
| 6 | 体整形 | 官方 13 工具逐字注入 + 客户端工具 `clint_<sha256:12>` 改名 + 历史/响应两侧还原；官方 CLI 系统提示全量前置；`tool_choice:'none'` 禁发；流式补 include_usage、无上限补 `max_completion_tokens:32000`；title 请求免整形 |

**判死活铁律**：`403 FreeTierError` = 指纹被拒（整形错）；`429 FreeUsageLimitError` = 配额窗
（按 project×出口 IP 记账，窗口缺省 ~6h）——拿到 429 即证明**整形正确**，等窗退避即可。

## 四、库结构与数据流

```
dsh_freelane/
├── vendor/src/    逐字拷贝的车道核心（钉 9d714bb）：upstream.applyFingerprint(body,style)、
│                  session 铸造持久化(session-map.json, $DSH_HOME)、http.js sniffBody
├── lib/freelane.js  薄门面：buildChatWire(整形) → sendWire(真发) → restoreToolNameOf(还原)
├── bin/cli.mjs    CLI：models(冒烟清单) / wire(打印整形请求) / send(真发, 烧配额)
└── tests/         21 绿 = 17 离线守卫(头/会话/端点/整形幂等/title免整形) + 4 门面
                   + 2 活体(env 开关 DSH_FREELANE_LIVE / DSH_FREELANE_PROBE)
```

调用流（完整 chat 线）：

```
调用方 messages+tools(宿主形状)
  → buildChatWire: 官方13工具前置 + clint_ 改名 + 系统提示注入 + 会话头/项目指纹装配
  → sendWire: Node fetch(指针纹安全) POST /inference/openai/v1/chat/completions
  → restoreToolNameOf: 回吐的 clint_* 还原调用方工具名 → 宿主 ReAct 执行
```
