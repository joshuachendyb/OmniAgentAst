## 三、10个真实问题清单

### 3.1 小强组 — 实现/合理性（3）

**[1] ChatInput.tsx:51-72 — 三重节奏容器 — 中**
根 `div padding4 0` 裹4节点（指令/TextArea/勾选行/SubmitBar）无 `flex column gap`，依赖 `SubmitBar marginTop4` 硬撑，与 `SessionLayout gap8` 外 + `TaskInfoBar gap8` 叠加成 12px。违 DRY/SLAP。复现：信息条与输入框间距 12px≠8px 主节奏。

**[2] ChatInput.tsx:52+59-62 — 孤行+死 spacer 超高 — 高**
`CommandPanel 指令` 独占首行、`TaskTypeToggle 行 flex gap12 + span flex1 空` 双行多耗22px；`autoSize3-4+SubmitBar1` 本已5行，叠加后潜在6-7行超 `4.3.6 ≤5行`。违 YAGNI/SRP。复现：窄屏 720p 输入区被 `calc(100vh-120px)` 挤压需内滚。

**[3] InputCore.tsx:34-36 — 事件双层校验 — 低**
`onPressEnter !shift→preventDefault+onPressEnter` 与 `ChatInput handleSendInternal draft.trim()/loading/isReceiving` 两层校验未抽 `canSend`，`Shift+Enter` 换行仅 placeholder 提示。违 KISS。

### 3.2 老杨组 — 视觉/系统一致（5）

**[4] InputCore.tsx:31-43 — 边框失控 — 高**
`TextArea` 默认 `border #d9d9d9 radius6` + 聚焦蓝晕，与系统 `border #f0f0f0 / 左线2px #e8e8e8` 未走 `Colors.BORDER` 令牌；周边 `TaskInfoBar transparent` 与 `TextArea` 白底卡片双体系。违 禁止backward。

**[5] 全局字阶割裂 — 中**
`InputCore 14px` 主、`Checkbox 14px` 同大，`SubmitBar/CommandPanel/Attachment Button small 12px` + `ModelPicker Select 12px` 混排，`placeholder 14px #bfbfbf` 与输入 `14px #262626` 仅色差，按钮 12px 显小。违 SLAP。

**[6] AttachmentArea.tsx:11-17 — 附件常灰 — 中**
`Upload disabled + Button disabled` 常驻灰态占 `Space` 一席，无 `Tooltip`，误导损坏；`SubmitBar SpaceBetween` 左空右挤时按钮顶右。违 YAGNI。

**[7] ModelPicker.tsx:105 — 选择器过重 — 中**
`Select minWidth180 small` + `Tooltip` + `DownOutlined` 重量远超同行 `指令/附件 12px` 小钮，窄屏挤压右侧发送区。违 SLAP。

**[8] CommandPanel.tsx:22-28 — 指令悬浮 — 中**
`指令 Appstore small` 孤置输入框顶部，与 `SubmitBar` 工具行分离，`gap 0` 紧贴 `TextArea` 边框，无分组归属。违 KISS。

### 3.3 小许组 — 规格/UX（2）

**[9] 规格超高 — 高** 同[2]，`4.3.6` ≤5行被 7 行突破。

**[10] 可发现性弱 — 低**
`Shift+Enter换行` 仅 placeholder 一次性，发送 `Enter/Send` 双通道无常驻徽标；`续聊任务` 文案与规格 `linked/independent` 未对齐；`disabled` 时仍“输入消息”。违 SLAP。

### 6.2 A组：指令续聊并行+gap8（对应 [1][2][8]）

**现状**
```tsx
<div style={{padding:'4px 0'}}>
  <CommandPanel/>
  <InputCore/>
  <div style={{display:'flex',gap:12}}><TaskTypeToggle/><span style={{flex:1}}/></div>
  <SubmitBar .../>
</div>
```
**改后**
```tsx
const [linked,setLinked]=useState(false);
return (
  <div style={{display:'flex', flexDirection:'column', gap:8}}>
    <InputCore value={draft} onChange={setDraft} onPressEnter={handleSendInternal} disabled={loading} />
    <SubmitBar
      leftExtra={<Space size={8}><CommandPanel onPick={c=>setDraft(d=>d?`${d}\n${c}`:c)} /><TaskTypeToggle checked={linked} onChange={setLinked} /></Space>}
      modelPickerSlot={modelPickerSlot}
      loading={loading} isReceiving={isReceiving} isPaused={isPaused} onSend={handleSendInternal} onCancel={onCancel} onTogglePause={onTogglePause}
    />
  </div>
);
```
`SubmitBar` 新增 `leftExtra?:ReactNode` 置最左（工具>模型>附件序），删 `padding4 0` 与 `flex1` 空 span，`flex column gap8` 对齐 `SessionLayout gap8`。验证：总高 `4+1=5` 行；窄屏 720p 无挤压。

### 6.3 B组：边框令牌化（对应 [4]）

**现状** `TextArea` 默认 `#d9d9d9`。
```tsx
<TextArea autoSize={{minRows:3,maxRows:4}} />
```
**改后**
```tsx
<TextArea style={{ borderColor: Colors.BORDER.LIGHT, borderRadius: Radius.SM }} autoSize={{minRows:3,maxRows:4}} />
// 聚焦态 CSS 覆盖：.ant-input:focus { border-color: Colors.PRIMARY; box-shadow: 0 0 0 2px rgba(22,119,255,0.1); }
```
`#d9d9d9→Colors.BORDER.LIGHT #f0f0f0`（水平分割令牌，垂直左线 `#e8e8e8` 区分），`radius6→SM` 统一。
验证：边框与 `TaskInfoBar borderTop #f0f0f0` 同灰；聚焦蓝晕 `#1677ff`。

### 6.4 C组：字阶与模型轻量化（对应 [5][7]）

**字阶** `Checkbox 14px→12px` 与按钮同档：`<Checkbox style={{fontSize:FontSize.SECONDARY}}>`；`InputCore 14px` 保留主文，按钮 12px 辅助二档统一。
**模型** `minWidth180→min(140px, 30vw)` 响应式，`Tooltip` 保留但 `Select size small` 不变；窄屏 `1100px` 时不挤压发送区。
验证：输入 14px/工具 12px 二档；1100px 缩放不换行。

### 6.5 D组：附件隐藏与空左对齐（对应 [6]）

```tsx
const AttachmentArea: React.FC<{visible?:boolean}> = ({visible=false}) => visible ? <Tooltip title="支持图片/文件"><Upload><Button size="small" icon={<PaperClipOutlined/>}>附件</Button></Upload></Tooltip> : null;
```
`SubmitBar` 联动：
```tsx
<Space style={{display:'flex', justifyContent: leftExtra||modelPickerSlot||visible ? 'space-between':'flex-end'}}><Space size={8}>{leftExtra}{modelPickerSlot}{visible && <AttachmentArea visible/>}</Space><Space>{...send/stop}</Space></Space>
```
暂缓期 `visible=false` 不占位；全空时 `flex-end` 贴右。验证：暂缓期无灰钮；启用后 `gap8` 对齐。
