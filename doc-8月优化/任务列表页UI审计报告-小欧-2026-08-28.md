## 三、8个真实问题清单

### 3.1 小强组 — 实现/合理性（3）

**[1] TaskListPanel.tsx:65 + SessionLayout.tsx:74-84 — 双重滚动容器 — 中**
`SessionLayout left` 已 `width240 borderRight#f0f0f0 overflowY auto`，`TaskListPanel` 内又套 `div overflowY auto minHeight0 scrollbarWidth thin`，双层滚动冗余，`scrollbarWidth thin` 仅内层生效。违 KISS/DRY。复现：左列滚动时内外两层滚动条叠加，窄屏滚动不跟手。

**[2] TaskListPanel.tsx:120-135 — 用户输入丢失 — 高**
`SessionTaskItem` 有 `user_input` 全量字段且 `api.ts:2` 注释“支撑双列”，但面板只渲染 `t.response` 不渲染 `t.user_input`，`4.8.2 user_input+response 双列` 未落地。违 关联退化/禁止backward。复现：新建 3 任务后左列无法追溯各任务提问原文。

**[3] TaskListPanel.tsx:120-135 — 响应嵌套滚动 — 中**
`response 11px #8c8c8c maxHeight5.3em overflow auto whiteSpace pre-wrap` 套在已滚动的任务列表内，形成三层滚动（外左列→任务列表→单条response），240px 窄列内长文本纵向滚易误触外层滚动。违 SLAP。

### 3.2 老杨组 — 视觉/一致性（4）

**[4] TaskListPanel.tsx:90-93 — 左选中重填色 — 高**
`active #e6f4ff + borderLeft3px #1677ff` 与已收敛的 `Pipeline 2px #e8e8e8`、`TaskInfoBar transparent+top` 去框无填色体系冲突；`3px` 又与 `2px/1px` 三档边宽不一，左列选中块成唯一浅蓝填色。违 关联退化。复现：左侧选中任务浅蓝块视觉重于右侧流水线。

**[5] TaskListPanel.tsx:120-135 — 字阶过小 — 中**
`response 11px #8c8c8c lineHeight1.4` 小于同面板时间行 `12px #595959` 与 `Badge 12px`，240px 宽下 11px 难读；与输入区 `14px`、信息条 `12px` 字阶断层。违 SLAP。

**[6] TaskListPanel.tsx:102-107 — 徽标 Tag 过重 — 中**
`context_link_mode Tag blue/green` 带边框浅底，与信息条已 `Tag→Text` 轻量化方向相反；时间 `12px #595959` 与 Tag 并列，pill 抢焦点。违 DRY。

**[7] TaskListPanel.tsx:57-63 + useSessionTasks.ts — 空态与加载缺失 — 低**
空态仅 `12px secondary padding8 暂无任务` 无 `Empty` 插画（右区 `Empty` 有插画）；`useSessionTasks loading` 未消费，切会话时旧列表闪旧数据无 `Skeleton`，与 `RightViewer Spin` 不一致。违 YAGNI 半截实现。

### 3.3 小许组 — 需求/规格（1）

**[8] SessionTaskItem:973-978 — 信息取舍未兑现 — 中**
规格 `8.2 左列应示 时间/类型/状态/耗时` 已满足，`4.5.1 token不入左列` 已遵守；但 `total_steps/llm_call_count/model/provider` 有字段零展示，`response` 占单项 1/3 高度，`user_input` 双列未兑现导致信息不全。属规格债。

### 6.2 A组：去双滚动与选中去填色（对应 [1][4]）

**现状** `SessionLayout.tsx:74` + `TaskListPanel.tsx:65` 双 `overflowY auto`；选中 `background #e6f4ff borderLeft 3px #1677ff`。
```tsx
<div style={{ width:240, borderRight:'1px solid #f0f0f0', overflowY:'auto' }}>{renderSlot('left')}</div>
<div style={{ overflowY:'auto', scrollbarWidth:'thin' }}>{tasks.map(... <div style={{background:active?'#e6f4ff':'transparent', borderLeft:active?'3px solid #1677ff':'3px solid transparent'}}>...</div>)}</div>
```
**改后**
```tsx
// SessionLayout.tsx 保留外层滚动，内层去滚动
<div style={{ width:240, flexShrink:0, borderRight:`1px solid ${Colors.BORDER.LIGHT}`, overflowY:'auto', overflowX:'hidden' }}>{renderSlot('left')}</div>
// TaskListPanel.tsx 内层改为纵向 flex  gap4，无滚动
<div style={{ display:'flex', flexDirection:'column', gap:4, padding:'4px 0' }}>{tasks.map(... 
  <div style={{ padding:8, cursor:'pointer', background:'transparent', borderLeft: active ? `2px solid ${Colors.PRIMARY}` : `2px solid transparent`, borderRadius:0 }}>...</div>)}</div>
```
- 外层 `borderRight #f0f0f0→Colors.BORDER.LIGHT` 令牌化；内层去 `overflowY` 改 `flex column gap4`，`scrollbarWidth thin` 上移至外层。
- 选中去 `#e6f4ff` 填色保留 `2px #1677ff` 左线（与 `Pipeline 2px #e8e8e8` 同宽不同色，语义区分），半径 0 与去框体系统一。
验证：左列单滚动条 `thin`；选中态左线 2px 蓝线不推挤文字；与右侧左线同宽。

### 6.3 B组：补双列与字阶徽标轻量化（对应 [2][5][6]）

**现状** 仅 `response` 11px，Tag blue/green。
```tsx
<div style={{fontSize:12, color:'#595959'}}>{formatTime(t.created_at)} {Tag 续聊/新任务}</div>
<div style={{fontSize:12}}><Badge .../>{duration}s</div>
{t.response && <div style={{fontSize:11, color:'#8c8c8c'}}>{t.response}</div>}
```
**改后**
```tsx
<div style={{fontSize:12, color:'#595959', display:'flex', alignItems:'center', gap:6}}>
  {formatTime(t.created_at)}
  {t.context_link_mode && <><span style={{width:4,height:4, borderRadius:'50%', background: t.context_link_mode==='linked'?'#1677ff':'#52c41a', display:'inline-block'}}/><Typography.Text type="secondary" style={{fontSize:12, color:'#8c8c8c'}}>{t.context_link_mode==='linked'?'续聊':'新任务'}</Typography.Text></>}
</div>
<div style={{fontSize:12}}><Badge status={st.color} text={st.text} />{t.duration!=null && <span style={{marginLeft:8, color:'#8c8c8c', fontSize:12}}>{Math.round(t.duration)}s</span>}</div>
{t.user_input && <div style={{fontSize:12, color:'#262626', fontWeight:500, marginTop:4, lineHeight:1.4, display:'-webkit-box', WebkitLineClamp:2, WebkitBoxOrient:'vertical', overflow:'hidden', wordBreak:'break-word'}}>{t.user_input}</div>}
{t.response && <div style={{fontSize:12, color:'#595959', marginTop:2, lineHeight:1.5, display:'-webkit-box', WebkitLineClamp:2, WebkitBoxOrient:'vertical', overflow:'hidden', wordBreak:'break-word'}}>{t.response}</div>}
```
- 补 `user_input` 首行 `12px #262626 500` 双列首位，`response` 次行 `12px #595959` 去 11px，统一 12px 字阶；`lineClamp2` 替代 `maxHeight5.3em overflow auto` 去嵌套滚动。
- `Tag→4px 点+Text 12px #8c8c8c` 轻量化（blue 续聊/green 新任务）与顶栏模型点统一。
验证：240px 宽下双列各 2 行截断不滚；点色区分续聊/新任务；Badge+耗时同行。
