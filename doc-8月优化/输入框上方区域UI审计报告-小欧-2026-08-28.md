## 三、12个真实问题清单

### 3.1 TaskInfoBar 组（5）

**[1] TaskInfoBar.tsx:76-85 — 悬浮灰胶囊与去框语言冲突 — 高**
`border:none background:#fafafa radius6 padding8px` 在白底 `SessionLayout` 上形成悬浮胶囊，与已收敛的 `PipelineRenderer borderLeft2px#e8e8e8`、`StaticStatsBlock borderTop` 去框无填色语言冲突。外层 `SessionLayout gap8` + 内 `padding8` 致双重留白。违反 KISS-DIRECT/关联退化。复现：输入框上方常驻淡灰块，与右侧流水线左线区背景割裂。

**[2] TaskInfoBar.tsx:87-94 — gap节奏分裂 — 中**
外 `gap8(SessionLayout)` + 内 `gap8(容器)` + 行 `gap12(信息行)` + 折叠区 `marginTop4+paddingTop4` 4档间距混用，未走 `Spacing` 令牌。嵌套后实际 8/12/16 混排，纵向节奏不齐。违反 DRY。

**[3] TaskInfoBar.tsx:98-135 — 字阶全等无主次 — 中**
耗时/步骤/轮次/token/上下文 5项均 `Typography.Text type=secondary 12px #8c8c8c`，数值与标签同色同字号，难扫描；`Tag volcano/orange` 反而最重，喧宾夺主。违 SLAP 同抽象层（高层摘要与底层细节混搭）。复现：执行中扫一眼分不清“耗时”数值与“上下文摘要”标签。

**[4] TaskInfoBar.tsx:87+135-136 — 折叠 affordance 弱 — 低**
整行 `cursor:pointer` 折叠仅靠尾部 `12px #999 展开/收起` 文字，无 hover 背景/箭头动画；与 `TrustPanel Collapse` 的默认箭头两套语言。违反 YAGNI（自造文字箭头）。

**[5] TaskInfoBar.tsx:140-150 — 折叠区双重内凹 — 中**
`maxHeight72 overflowYauto scrollbarWidththin borderTop#f5f5f5 marginTop4 paddingTop4` 坐在 `padding8` 父容器内，滚动条内嵌双内凹，72px 高时视觉拥挤。应与外 `gap8` 统一或改为 `maxHeight 96 + padding 8 0 0`。

### 3.2 TrustPanel 组（3）

**[6] TrustPanel.tsx:64-107 — 空态常驻占位 — 高**
`defaultVisible true` 后 `Collapse ghost` 即使 `tools.length===0` 仍渲染 32px 表头 + `emptyText`，会话 80%时间空占输入框正上方。违 YAGNI/关联退化。复现：新建会话首屏输入框上方多一条“本会话信任的操作（0）”灰行。

**[7] TrustPanel.tsx:65 — ghost 内边距失齐 — 中**
`Collapse ghost` 头部默认 `padding 12px 16px`，与 `TaskInfoBar padding8px` 左沿不齐；`List size small` 项 `padding 8px 0` 又与 `TaskInfoBar` 行 `gap12` 节奏不一致。违反 DRY（未复用 Spacing）。

**[8] TrustPanel.tsx:70-73 — 视觉权重与规格冲突 — 低**
标签 `type secondary 12px` 与 `TaskInfoBar` 同款，上下两块灰底/透明交替却同字阶，无分隔；且与规格 4.3.5/4.7“默认收起”冲突（修复#3为使其可达而常驻）。属产品决策债。

### 3.3 ChatInput 上部行组（4）

**[9] ChatInput.tsx:51-72 — 无节奏纵向堆叠 — 高**
根 `div padding4px 0` 裹 4个纵向节点（指令按钮/TextArea/勾选行/SubmitBar）无 `flex column gap`，依赖 `SubmitBar marginTop4` 硬撑；`SessionLayout gap8` 外 + `4px 0` 内叠加成 12px，纵向不齐。违 KISS-DIRECT/复用优先（未用 Spacing）。复现：输入框与信息条间距目测 12px，与顶栏/中部 gap8 不等。

**[10] ChatInput.tsx:52+59-62 — 指令按钮孤行+死 spacer — 高**
`CommandPanel` 独占首行仅1个 `Button 指令 small`，左对齐无对位；下方 `TaskTypeToggle` 行 `<div flex gap12><Checkbox/> <span flex1/></div>` 尾部 `flex:1` 空 span 无右侧内容，纯占位。两行本可合并为一工具行（指令+续聊），现拆2行多耗 22px 高度，使总高潜在 6行超 4.3.6“≤5行”规格。违 YAGNI/SRP。

**[11] InputCore.tsx:31-43 — TextArea 边框语言未收敛 — 中**
`TextArea` 保留 Antd 默认 `border #d9d9d9 radius6` + 聚焦蓝晕，与已去框的 `PipelineRenderer/ToolCallLine` 左线语言不一致；周边 `TaskInfoBar #fafafa`、`AttachmentArea disabled` 灰态混用，灰阶已达5档（#fafafa/#f5f5f5/#f0f0f0/#e8e8e8/#d9d9d9）未走 `Colors.BORDER/BG` 令牌。违 DRY/禁止backward（新旧混杂）。

**[12] SubmitBar.tsx:42-47 — 附件永久禁用误导 — 中**
`AttachmentArea.tsx:12` `Upload beforeUpload false disabled` + `Button disabled` 常驻灰态占位，无 `Tooltip disabledReason`，用户误以为功能损坏；且挤占 `SubmitBar Space justifyContent space-between` 左侧空间。违 YAGNI（暂缓功能应隐藏而非禁用占位）。复现：输入区底部“附件”钮常灰不可点且无说明。
