### 3.3 按用户体感重排 Top5

**必须修（下个迭代）**

1. index.css 全局污染 → 改为 CSS Module/局部类，移除 !important（P0）
2. 空/加载/错误三态补齐（空插画+局部 Skeleton+统一 ErrorDetail）（P0）
3. 响应式收敛：LEFT_WIDTH 改 clamp(200px,18vw,280px) 或抽屉（P0）
4. 无障碍对比度+键盘可达（#595959替代#8c8c8c，按钮加 aria）（P0）
5. 长列表虚拟化（Right 流水线+左任务列表 react-virtuoso）（P0）

**可缓修（视觉债务）**

- Token 收口：ConfigProvider theme={{token:{colorPrimary:'#1890ff', borderRadius:6}}} 接管 stepStyles
- 字号/间距/圆角收敛为 FontSize 12/13/14 + Spacing 4/8/12 + Radius 6
- break-all 统一为 overflowWrap:break-word + wordBreak:break-word
- 暗色模式要么删除 darkModeColors 要么全量接入

### 3.4 总体视觉评价

**5.5/10 — 骨架清晰、细节未收敛。**

### 4.2 Ant Design 5 设计语言符合度

**结论：结构合规，视觉 Token 偏离。**

| 维度 | AntD 5 规范 | 现状 | 偏离点 |
|------|-------------|------|--------|
| 布局 | Layout + Flex + Grid，间距 token.padding/margin 8点网格 | SessionLayout 用 flex gap4/8 手写 | 未用 theme.useToken()，gap 与 AntD paddingSM/padding 错位 |
| 色彩 | colorPrimary #1677ff + colorText/colorTextSecondary/colorBorderSecondary + 语义色 | 手写 #1890ff/#666/#999/#f0f0f0/#52c41a/#ff4d4f | 1890ff 为 AntD4 遗留，5 应为 1677ff；语义色未走 token |
| 字体 | fontSize 12/14 + lineHeight 1.57/1.8 + Typography | 11/12/13/14 混用，手写 lineHeight1.4/1.8 | 11px 非标，13px 在 AntD 无定义 |
| 圆角/阴影 | borderRadius 6/8 + boxShadow token | 4/6 混用 + 手写 boxShadow | 4 偏小，与 AntD borderRadiusLG=8 不统一 |
| 组件 | 统一 Badge/Tag/Spin/Typography.Text type="secondary" | 已用 AntD 组件但 style color:#999 覆盖 token | 用组件却手写色，丢失 token 联动 |
| 全局 | 禁止 !important 覆盖 .ant-* | index.css:19-34 !important 清零 ant-card-body/head | 严重偏离，破坏 AntD 层叠 |
