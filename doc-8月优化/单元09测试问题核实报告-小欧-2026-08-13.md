## 四、问题详查

### 4.1 问题1：文件名哈希前缀 —— 真实

- 现象：窗口内 71 个文件中出现 2 个非数字文件名：
  - `prompt_6c2c95f6+88ccdee8+20260813_081306.json`
  - `prompt_0bcf42fe+d7fb5537+20260813_091448.json`
- 根因：`backend/app/logger/prompt_logger.py` 的 `save()`（L456 附近）在 `ai_message_id` 与 `user_message_id` 均为 null 时，降级使用 `uuid4().hex[:8]` 作为文件名前缀，导致哈希命名。
- 实测佐证：两文件 `基本信息` 中 AI 消息ID 与 用户消息ID 均 null、状态=异常终止、组装过程仅 2 步、LLM 调用仅 1 次，无任何 step 产出。

### 4.2 问题2：异常任务缺消息ID —— 真实（与#1同根因的两面）

- 根因：`backend/app/services/agent/agent_runner.py` L179-182，`ai_message_id` **仅在产出第一个 step 时**才 `allocate_and_insert`；而 `start_request` 在 L100 于 ReAct 循环之前调用。
- 实际：任务若在产出任何 step 之前异常退出，`ai_message_id` 永为 null，DB 中该会话消息数 = 0（连 user 消息也未落库），prompt_logger 只能退化哈希文件名。
- **核心缺陷**：prompt-log 无法通过文件名/ID 关联回 DB 消息 → 数据溯源断裂。

### 4.3 问题3：内容长度记录不准确 —— 误报

- agent 声称约 45 处"记录长度 ≠ 实际长度"。
- 实测：用 Python `len()` 对窗口内全部 71 个文件逐条复验（含被报的 prompt_003635），**0 处不匹配**。
- 归因：agent 用 PowerShell `.Length`（UTF-16 码元计数）对比，与 Python `len()`（码点计数）在含非BMP/代理对字符时存在 diff=7/8，属**计数口径差异**，非记录 bug。

### 4.4 问题4：系统Prompt版本不一致 —— 现象真、归因错

- 现象真实：4 个文件 PS5.1，63 个文件 PS7+。
- **归因错误**：不是"缓存固定导致版本分裂"。
- 实测时间线：PS5.1 集中在 2026-08-13 早晨（08:10-08:13），08-12 晚与 08-13 白天均为 PS7+；不存在"同一时刻随机分裂"。
- 真实根因：`backend/app/services/prompts/system_adapter.py` L88-105 的模块级缓存 `_PWSH_VERSION`——进程启动时若 `get_pwsh_version()` 检测失败→缓存置空→`get_default_shell_code`（L117-125）fallback 为 ps5.1，且**整个进程生命周期固定**。
- 判定：属环境/进程启动时段差异或检测失败窗口，倾向环境波动，而非"缓存固定导致分裂"的代码缺陷定性。

### 4.5 问题5：AI消息ID编号不连续（缺失39个）—— 现象真、根因未挖（第一遍修正）

- **现象真实**（第一遍曾误判为"正常"，现修正）：
  - DB 窗口内 assistant 消息：**108 条**
  - prompt-log 有 AI ID 的文件：**69 个**
  - 差异 **39**，与 agent 报告值完全吻合。
- **agent 未深挖根因**：这 39 条缺失号对应的 DB 消息为 **status=None 的孤儿 assistant 消息**（content=hi/thinking.../空，role 含 unknown，时间分散 08-12/08-13），是**未 finalize、未产出 prompt-log 的残留消息**，而非正常任务漏日志。
- **真正问题**：DB 存在 status=None 孤儿 assistant 消息残留（全库 217 条 status=None assistant），agent 只报了编号不连续的表象，未定位到孤儿消息残留根因。

### 4.6 问题6：系统Prompt缓存过时 —— 方向对、描述错

- 方向对：模块级缓存确实存在（`system_adapter.py` L68-105）。
- **描述错**：agent 称"时间戳差异/过时"不成立——实测每个文件系统 Prompt 内【环境】时间与 `基本信息` 时间戳一致，为**请求时动态生成**（prompt_003631 = 2026-08-13 08:08:48），并非缓存死值。
- 真正被缓存的只有 shell 版本（见问题4），**不是时间戳**。agent 将"版本缓存"与"时间戳缓存"混淆。

## 五、关键证据链

- `agent_runner.py`：L100 start_request（循环前）→ L179-182 ai_message_id 仅首步分配 → 异常分支在产出 step 前退出时 ID 恒 null。
- `prompt_logger.py`：L456 附近 save() `ai_message_id is None` → 哈希文件名 fallback。
- `system_adapter.py`：L68-105 模块级缓存；L88-105 get_pwsh_version 检测失败缓存空；L117-125 fallback ps5.1。
- DB：两个异常文件会话（e22544c2-...、73dc827f-...）消息数 = 0；缺失号 role 分布：user 95 / unknown 13。

## 六、最终判定与建议

| 优先级 | 问题 | 建议 |
|--------|------|------|
| 高 | #1/#2 异常任务无ID+哈希文件名 | 修复 agent_runner：在任何异常路径 finalize 前确保已落 DB 并取得 ID，或在 save() 前联调 DB 查询兜底 |
| 中 | #5 孤儿 assistant 消息残留 | 排查 217 条 status=None assistant 消息产生来源，明确未 finalize 路径 |
| 低 | #4 版本缓存 | 评估 get_pwsh_version 失败时是否需要进程内重试/重检测 |
| 无 | #3 内容长度 | 无需处理（计数口径理解即可） |
| 无/低 | #6 时间戳缓存 | agent 定性纠正，无需改码 |
