### 6.2 A组：令牌统一与高亮收敛（对应 [1][2][9]）

**现状**
```tsx
// PipelineRenderer:94
borderLeft: '2px solid #e8e8e8'
// Generic:31
NEST_BLOCK_LINE = Colors.BORDER.DEFAULT // #d9d9d9
// shapeRenderers titleStyle #52c41a/#ff4d4f, Folder #faad14 File #1677ff
// ToolCallLine highlight 1px #faad14 + rgba(250,173,20,0.08)
```
**改后**
```tsx
import { Colors, BorderWidth, Spacing } from '@/utils/stepStyles';
// PipelineRenderer
borderLeft: `${BorderWidth.THICK}px solid ${Colors.BORDER.LIGHT}` // 2px #e8e8e8 令牌化
// Generic
NEST_BLOCK_LINE = Colors.BORDER.LIGHT // 统一 #e8e8e8，与 Pipeline 同灰
// shapeRenderers
color: success ? Colors.SUCCESS : Colors.ERROR
<FolderOutlined style={{color: Colors.WARNING}}/> <FileOutlined style={{color: Colors.PRIMARY}}/>
// ToolCallLine
borderLeft: highlight ? `${BorderWidth.THIN}px solid ${Colors.WARNING}` : `${BorderWidth.THICK}px solid ${Colors.BORDER.LIGHT}`
background: highlight ? Colors.WARNING_BG : 'transparent' // #fffbe6 令牌浅底，替 rgba
```
- 左线统一 `Colors.BORDER.LIGHT #e8e8e8`，分割用 `Colors.BORDER.LIGHT`，警告用 `Colors.WARNING #faad14`。
- 高亮 `1px→2px` 与非高亮同宽，仅色区分，`rgba→WARNING_BG` 令牌。
验证：流水线与通用嵌套左线同灰；暖改色单点改令牌。

### 6.3 B组：Tree/Code 去卡片填色（对应 [3][5]）

**现状**
```tsx
<div style={{ background:'#fafafa', border:'1px solid #f0f0f0', borderRadius:6, padding:'6px 10px', maxHeight:360, overflow:'auto' }}>{entries}</div>
<pre style={{ background:'#1e1e1e', border:'1px solid #303030', borderRadius:8, padding:'10px 14px', maxHeight:400, overflow:'auto', color:'#d4d4d4' }}>{content}</pre>
```
**改后**
```tsx
// Tree 列表/树 — 去 #fafafa 填色改透明+左线
<div style={{ background:'transparent', borderLeft:`${BorderWidth.THICK}px solid ${Colors.BORDER.LIGHT}`, paddingLeft: Spacing.SM, maxHeight:360, overflow:'auto' }}>{entries}</div>
// Code — 浅底左线替代深色块（与系统浅底一致；若需深色则走 CodeMirror 令牌另议）
<pre style={{ background: Colors.BG.LIGHT, borderLeft:`${BorderWidth.THICK}px solid ${Colors.BORDER.LIGHT}`, border:`none`, borderRadius: Radius.SM, padding: `${Spacing.XS}px ${Spacing.SM}px`, maxHeight:400, overflow:'auto', color: Colors.TEXT.PRIMARY, fontFamily:'Consolas, Monaco, monospace', fontSize: FontSize.SECONDARY }}>{content}</pre>
```
- 去 `background #fafafa/#1e1e1e` 填色卡片，改 `transparent + 左线 2px #e8e8e8`，`padding 6 10→8` 对齐 `gap8`，`radius6/8→SM` 统一。
- 树容器 `border 1px #f0f0f0→borderLeft 2px`，与 `Pipeline` 同语言。
验证：Tree/Code 与 Pipeline 同为左线透明，无深浅双体系；`maxHeight` 滚动保留。
