## 一、后端：思考内容的产生与传输

### 1.1 LLM 层面——思考内容的源头

**文件**：`backend/app/llm/reasoning.py:128-154`

不同模型把"思考过程"放在不同字段，本函数一网打尽：

```python
def extract_reasoning_from_chunk(delta: Dict) -> Optional[str]:
    rc = delta.get('reasoning_content') or delta.get('reasoning') or delta.get('thinking')
    if rc:
        return rc
    if delta.get('is_reasoning') is True or delta.get('reasoning_flag') is True:
        return delta.get('content') or ""
    return None
```

| 模型/网关 | 思考字段 | 识别方式 |
|-----------|---------|---------|
| DeepSeek 系 | `reasoning_content` | 直接取该字段 |
| Anthropic Claude | `thinking` | 直接取该字段 |
| OpenAI 系 | `reasoning` | 直接取该字段 |
| 打标记型 | 混在 content 里 | `is_reasoning=True` 或 `reasoning_flag=True` 标记，取 content 当思考 |

### 1.2 流式传输——ChunkStep 的 is_reasoning 标记

**文件**：`backend/app/llm/llm_stream.py:164-172` + `backend/app/services/agent/steps/chunk_step.py:9-56`

```python
class ChunkStep(ReasoningStep):
    TYPE: str = "chunk"
    def __init__(self, step: int, content: str, is_reasoning: bool = False, ...):
        self._is_reasoning = is_reasoning
    def _extra_fields(self) -> Dict[str, Any]:
        extra: Dict[str, Any] = {"is_reasoning": self._is_reasoning}
        if self._thought: extra["thought"] = self._thought
        if self._reasoning: extra["reasoning"] = self._reasoning
        return extra
```

每个 chunk 根据 `is_reasoning` 标记累加到不同缓冲区（`full_content` / `full_reasoning`）。

**发射点**：`backend/app/services/agent/react_cycle.py:444-449`


### 1.3 ThoughtStep 与 ThoughtStartStep——思考步骤定义

**文件**：`backend/app/services/agent/steps/thought_step.py:13-48` + `thought_start_step.py:10-19`

```python
class ThoughtStep(ReasoningStep):
    """思考步骤 - 仅落库不 yield 前端（§10.3.3(1)）"""
    TYPE: str = "thought"
    def _extra_fields(self) -> Dict[str, Any]:
        return {"thought": self._thought, "reasoning": self._reasoning}

class ThoughtStartStep(ReasoningStep):
    """思考开始信号 - 纯实时, 不落库（§10.3.3(1)）"""
    TYPE: str = "thought-start"
    def get_content(self) -> str: return ""
    def _extra_fields(self) -> Dict[str, Any]: return {}
```

| 步骤类型 | 通道 | 说明 |
|---------|------|------|
| `ChunkStep` | 仅 SSE | 逐字流，`is_reasoning` 区分思考/正文 |
| `ThoughtStartStep` | 仅 SSE | 思考开始信号（光标），不落库 |
| `ThoughtStep` | 仅落库 | 完整思考内容，历史回放用 |

### 2.3 onChunk 回调——内容累积

**文件**：`frontend/src/hooks/chat/useChatCallbacks.ts:274-319`

```typescript
const onChunk = useCallback((chunk: string, is_reasoning?: boolean) => {
  if (isPausedRef.current) {
    displayBufferRef.current.push({ type: 'chunk', content: chunk, is_reasoning });
    return;
  }
  streamingContentRef.current += chunk;
  setMessages((prev) => {
    const lastMessage = prev[prev.length - 1];
    if (lastMessage && lastMessage.role === 'assistant' && lastMessage.isStreaming) {
      const updated = [...prev];
      updated[updated.length - 1] = {
        ...lastMessage,
        content: streamingContentRef.current,
        is_reasoning: is_reasoning ?? false,
      };
      return updated;
    }
    return prev;
  });
}, [setMessages, isPausedRef, displayBufferRef, streamingContentRef]);
```

### 2.4 段构建——buildSegments()

**文件**：`frontend/src/components/Chat/pipeline/PipelineRenderer.tsx:29-68`

```typescript
export const buildSegments = (steps: ExecutionStep[]): PipelineSegment[] => {
  const segs: PipelineSegment[] = [];
  const appendToLast = (kind: 'thinking' | 'text', text: string) => {
    const last = segs[segs.length - 1];
    if (last && last.kind === kind) last.text += text;
    else segs.push({ kind, text } as PipelineSegment);
  };
  for (const s of steps) {
    switch (s.type) {
      case 'thought-start':
        break; // 光标信号由 streaming prop 承载，不产出内容
      case 'chunk':
        if (s.is_reasoning) appendToLast('thinking', s.content ?? '');
        else appendToLast('text', s.content ?? '');
        break;
      case 'thought':
        appendToLast('thinking', s.thought || s.content || '');
        break;
      case 'action':
        segs.push({ kind: 'tool', action: s, observations: [] });
        break;
      case 'observation': { ... }
      case 'final': segs.push({ kind: 'final', step: s }); break;
      case 'error': segs.push({ kind: 'error', step: s }); break;
      default: break;
    }
  }
  return segs;
};
```

- `chunk(is_reasoning=true)` → `thinking` 段
- `chunk(is_reasoning=false)` → `text` 段
- `thought` → `thinking` 段（历史回放重建）
- `thought-start` → 不产出段，仅作光标信号
- 相邻同类段自动合并（`appendToLast`）

## 四、完整链路时序图

```
后端 LLM 流式输出
  │
  ├─ reasoning_content / thinking / reasoning 字段
  │     └─ reasoning.py:extract_reasoning_from_chunk() 识别
  │           └─ StreamChunk(is_reasoning=True)
  │                 └─ llm_stream.py 累积进 full_reasoning
  │                       └─ react_cycle.py 生成 ChunkStep(is_reasoning=True)
  │                             └─ StepEmitter.emit() → agent.steps 记录
  │                                   └─ agent_runner.py:293-301 通道路由
  │                                         ├─ chunk(is_reasoning) → 仅 SSE
  │                                         └─ thought → 仅落库
  │
  ├─ SSE stream_reader → format_agent_sse() → HTTP Response
  │
  └─ 前端 EventSource 接收
        ├─ chunk(is_reasoning=true) → onChunk(content, true)
        │     └─ useChatCallbacks 累积 → setMessages
        │
        ├─ chunk(is_reasoning=false) → onChunk(content, false)
        │     └─ 同上，is_reasoning=false → 正文段
        │
        ├─ thought-start → ExecutionStep[] 追加（仅内存，不落 sessionStorage）
        │
        ├─ thought → ExecutionStep[] 追加（落 sessionStorage，历史回放用）
        │
        └─ PipelineRenderer
              ├─ splitSteps().business → 业务步骤过滤
              ├─ buildSegments() → thinking / text / tool / obs / final 段
              │     ├─ chunk(is_reasoning=true) → thinking 段
              │     ├─ chunk(is_reasoning=false) → text 段
              │     └─ thought → thinking 段（回放重建）
              └─ ThinkingStream 渲染
                    ├─ 灰色斜体文字
                    └─ 实时流: 呼吸光标 ▍ (1秒闪烁，仅最后一段)
```
