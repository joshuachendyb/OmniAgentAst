## 二、逐项审查结论

### 2.1 页面/路由/菜单切换 — ✅ 已修复1处泄漏
- **卸载清理链路**：`useSSE` 钩子 `useEffect` 卸载清理调 `disconnect()`（`sse.ts:950-952`），SSE 正确拆除。
- **🔴 真实 BUG（已修复）**：`sse.ts` 的 `disconnect()` 与卸载清理**只清 `reconnectTimeoutRef`，未清 `idleTimeoutRef`（60s 空闲超时）与 `fetchTimeoutRef`（180s）**。
  - 复现：流进行中切走页面/隐藏标签且 60s 无数据→`idleTimeoutRef` 在**已卸载组件**上触发 `onError('SSE 空闲超时')`→`handleSSEError`（非 AbortError→非静默）→弹出"空闲超时"错误 toast + 对死组件发起重连。
  - 这正对应"切页面/隐藏时弹莫名其妙提示"的体感。
  - **修复**：`disconnect()` 内补清 `idleTimeoutRef` / `fetchTimeoutRef`（`sse.ts:558` 附近）；`fetchTimeoutRef` 新增 ref 并在 `sendMessageInternal` 起止统一接管清空。
- **Abort 卸载静默正确**：`disconnect()` 调 `abort()`→`AbortError`→`isSilentError` 返回 true→不弹 toast/不重连。✅ 无问题。
- **状态保存**：`useChatPersistence` 有 visibilitychange 保存 + beforeunload 保存 + messages 变更自动保存；切回由 `restoreState` 恢复。✅ 闭环。

### 2.2 标签隐藏/显示 — ✅ 修复后无异常
- `useChatPersistence:317` 隐藏即存状态；`NewChatContainer:332` 显示即滚到底。✅ 正确。
- 修复前：隐藏期间若流空闲 60s，卸载（切走即卸载）后 `idleTimeoutRef` 泄漏弹错（见 2.1）。修复后消除。

### 2.3 窗口/标签切换（blur/focus） — ✅ 无问题
- 全仓**无 `blur`/`focus` 监听**；SSE 在失焦窗口持续运行（浏览器不切断连接），属正确行为，无隐藏断连/误重连。

### 2.4 beforeunload 卸载保存 — ✅ 闭环
- `NewChatContainer:387` `useBeforeUnload({ saveData: handleSaveBeforeUnload })` 已接线；`useBeforeUnload.ts` 对异步保存失败 `preventDefault` 阻止卸载防丢数据。✅ 无死代码、无缺口。
