## 一、整改依据

### 1.1 从十大规范反推出的八条硬约束

整改不是"修几个 bug"，而是把产物声明这件事重新做成合规的。八条约束由规范直接推导，任何一条不满足都算没改到位。

| 约束 | 来源规范 | 内容 | 违反的后果 |
|---|---|---|---|
| **C1 唯一落点** | SRP | 产物清单既不是动作描述（`action`），也不是本次执行输出（`data`）；唯一落点是 `other_data["artifacts"]` | 字段语义混淆，任何读 `action` 的代码都要额外知道"这里可能混着清单" |
| **C2 唯一契约** | DRY | 条目字段定义只能存在于一个模块；声明端、收集端、落库、读口、前端不得各自解释字段 | 同一个 `type` 出现三种含义，同一个 `path` 出现三种地址 |
| **C3 唯一判定** | KISS-DIRECT | 形态判定、类型判定、存在性判定、去重键判定，各只有一个函数实现 | 遥测与读口对"是否同一条"判断不一致，同一条数据两层结论相反 |
| **C4 无兼容层** | 禁止 backward | 旧三函数直接删除，不留别名、不双写、不双读；调用点全部改成新入口 | 新旧混杂，下次改动仍要同时维护两条路 |
| **C5 单层职责** | SLAP | 声明端只声明，收集端只收集，读口只读；任一层不做其他层的判断 | 读口被迫猜形态、收集端被迫改数据 |
| **C6 不改生产者数据** | SRP | 收集器只能拷贝后加工，绝不原地改写工具返回体 | 观测步落库的数据被下游污染，出问题无法定位是谁改的 |
| **C7 有界且保留有效数据** | KISS | 条目数有上限，超限丢最早、保留最新，截断必须可观测 | 长任务最后产出的文件进不了清单，且没人知道被丢了 |
| **C8 复用优先** | 复用优先 | 契约模块放全局层 `app/utils/`，新建即登记 `FUNCTIONS.md` | 局部重造轮子，下一个产出工具又手搓一份条目 |

### 1.2 由约束反推：三处必须推倒，不能修补

| 必须推倒的 | 对应约束 | 为什么不能修补 |
|---|---|---|
| **落点必须迁出 `llm_data.action`** | C1 | 只要清单还在 `action` 里，`action` 就永远不是纯动作描述。修补（例如"只在 action 里放一份副本"）会同时违反 C1 与 C4 |
| **契约必须重建** | C2 / C3 | 现有条目只有 `name/path/type` 三个字段，`path` 同时承载文件、目录、URL，`type` 同时承载扩展名与媒体类别。缺的是"形态"这一维，加补丁改不了结构性缺失 |
| **声明入口必须重写** | C4 | 旧入口签名是 `with_artifact_file(llm_data, path)`——第一个参数就是落点。落点迁走后签名必然变，不存在"改造后原样保留"的可能 |

### 1.3 为什么"只修读口"不成立

读口按 `path` 猜形态（URL 前缀 / `isdir` / 其余当文件）确实能让抽屉不再显示红字，但四个层面全部照旧不合规：

| 层面 | 修读口后仍存在的问题 | 违反 |
|---|---|---|
| 契约层 | `path` 一字段三义，任何新消费方（任务详情页、导出、审计）都必须重新猜一遍 | C2 / C3 |
| 声明层 | 媒体工具仍手搓条目 dict，`type` 仍是三套含义 | DRY / OCP |
| 收集层 | 仍原地改写生产者 dict，去重键与读口不一致，超限仍丢最新 | C6 / C7 |
| 落点层 | 清单仍在 `llm_data.action` | C1 |

读口特判的本质是**把歧义推给下游**。下游每多一个消费方，就多一份重复的猜测逻辑——这正是 DRY 要禁止的。所以本方案不设"止血档"，一次性改到位。

## 二、唯一目标契约

### 2.1 条目五字段

产物条目从此只有这五个字段，任何来源、任何环节都按这一份定义。

| 字段 | 类型 | 由谁产生 | 取值域 | 说明 |
|---|---|---|---|---|
| `tool_name` | str | **收集器注入** | 工具名 | 生产者不填；收集器拷贝条目时写入，保证条目可追溯到产出它的工具 |
| `name` | str | 规范化 | 非空 | 展示名。本地取 `basename`；目录取目录名；URL 取末段文件名（URL 解码、去 query/fragment） |
| `path` | str | **生产者** | 本地绝对路径 或 `http(s)://` URL | 唯一地址字段。不再有第二种解释 |
| `form` | str | 规范化 | `file` / `dir` / `url` | 唯一形态字段。下游所有"怎么打开、怎么判存在"都只看它 |
| `type` | str | 规范化 | 小写无点扩展名 / `dir` / 媒体类别 / `file` / `url` | 唯一类型字段，仅用于展示分类 |

### 2.2 判定规则（每类只有一个实现）

| 判定 | 规则 | 唯一实现 |
|---|---|---|
| **form** | 条目已带合法 `form` → **信任，不重新探测磁盘**；缺失 → URL 前缀判 `url`；`isdir` 判 `dir`；其余 `file` | `normalize_artifact` |
| **type** | 有扩展名 → 扩展名（小写无点）；目录 → `dir`；URL 认不出后缀 → 声明方给的媒体类别（`image`/`video`/…）；类别也缺 → `url`；本地无扩展名 → `file` | `normalize_artifact` |
| **去重键** | `url`：`scheme://host/path`（**去 query 与 fragment**，签名参数不影响"是同一资源"）；`file`/`dir`：`normcase(abspath(path))` | `artifact_dedup_key` |
| **存在性** | `url` 恒 `True`（远程资源，**不做网络探测**，避免读一次抽屉打一串外网请求）；`dir` 用 `isdir`；`file` 用 `isfile` | `artifact_exists` |
| **可引用** | 只有 `form == "file"` 且位于项目根内才给 `rel_path`；`dir` 与 `url` 的 `rel_path` 恒 `None` | `list_session_task_artifacts` |

两条关键取舍：

1. **信任已有 `form`，不重判**。产物声明时文件确实存在，形态当时是确定的；读口如果按磁盘现状重判，文件被删后形态会从 `file` 变成 `file`（碰巧对）或从 `dir` 变成 `file`（错）。信任存量字段才能保证历史数据稳定、`normalize` 幂等。
2. **`type` 的兜底是单条规则，不是三套含义**。旧代码的问题不是"有兜底"，而是三个生产者各自发明含义。现在由同一个函数按同一条规则产出，调用方不再参与决策。

### 2.3 三级记录的分工

三级记录不是重复存储，是三个不同粒度，消费方不同：

| 层级 | 位置 | 粒度 | 生命周期 | 消费方 |
|---|---|---|---|---|
| **单次调用证据** | `result["other_data"]["artifacts"]` | 一次工具调用声明了什么 | 随本次执行存在，不单独持久化 | `agent_telemetry` 收集器 |
| **任务终态** | `FinalStatsStep.artifacts` / `chat_tasks.artifacts` | 整个任务合并去重后的清单 | 持久化，单一真源 | 任务详情、终态统计块 |
| **会话视图** | `list_session_task_artifacts` 返回值 | 跨任务去重倒序 | 每次请求实时计算 | 前端「本会话产物」抽屉 |

单次调用层与终态层不是"重复"：前者是原始证据（同一文件被 `write` 和 `edit` 各声明一次，是两次真实产出），后者是任务级去重结果（同一文件只列一次）。两者粒度不同、用途不同。

### 2.4 契约模块的九个函数

新建 `backend/app/utils/artifacts.py`，全局层，唯一契约实现。九个函数各自对应一条约束，没有冗余：

| 函数 | 职责 | 对应约束 | 调用方 |
|---|---|---|---|
| `normalize_artifact(raw)` | 任意条目 → 五字段标准条目；不可成立返回 `None` | C2 C3 | 全部 |
| `artifact_from_file(path, name="")` | 本地文件/目录 → 标准条目（`form` 按磁盘实况） | C8 | 16 个本地产出工具 |
| `artifact_from_url(url, kind="")` | 公网 URL → 标准条目 | C8 | 2 个媒体工具 |
| `artifact_dedup_key(item)` | 去重键 | C3 | 收集器、读口 |
| `artifact_exists(item)` | 形态化存在性判定 | C3 | 读口 |
| `merge_artifacts(existing, new_items)` | 规范化 + 合并去重 + 上限保留最新 | C7 | 收集器、声明入口、读口 |
| `declare_artifacts(other_data, items)` | 声明入口（基座），追加语义 | C1 C4 | 2 个媒体工具 |
| `declare_artifact_file(other_data, path)` | 声明入口（便捷） | C1 C4 C8 | 16 个本地产出工具 |
| `read_declared_artifacts(result)` | 读取口：从工具返回体取已声明产物并规范化 | C5 | 收集器 |

模块完整代码见附录 B。

### 2.5 声明入口的调用形态

改前（落点在 `llm_data.action`，覆盖语义）：

```python
llm_data = _build_xxx_llm_data(...)
with_artifact_file(llm_data, str(path))       # 副作用：改 llm_data
return build_success(data=data, llm_data=llm_data)
```

改后（落点在 `other_data`，追加语义，无副作用）：

```python
other: Dict[str, Any] = {}
llm_data = _build_xxx_llm_data(...)
other = declare_artifact_file(other, str(path))
return build_success(data=data, llm_data=llm_data, other_data=other)
```

媒体工具（URL 形态）：

```python
other = declare_artifacts(other, [artifact_from_url(url, "image")])
return build_success(data=result_data, llm_data=llm_data, other_data=other)
```

媒体工具（本地落盘形态）不再手搓条目，直接走 `declare_artifact_file`。

## 三、现状与目标的差距

九项问题全部经实测成立（证据见附录 A）。下表把它们逐条映射到约束与目标状态，说明"改成什么算改完"。

| 编号 | 现状 | 违反约束 | 目标状态 | 由哪一步消除 |
|---|---|---|---|---|
| P1 | URL 产物 `path` 被当本地文件判存在，恒 `exists=False`，前端显示"源文件已不存在"、点击被拒 | C2 C3 C5 | `form="url"`，`exists=True`，前端走外链 | 步骤一 + 五 + 六 |
| P2 | 解压目录按文件声明，`isdir` 却用 `isfile` 判，恒失效；`extract_ext(目录)` 得到 `"file"` 或 `"b"` | C2 C3 | `form="dir"`，`type="dir"`，`exists=isdir`，前端走目录 | 步骤一 + 五 + 六 |
| P3 | `type` 三套含义：扩展名 / 媒体类别（本地手搓）/ 媒体类别（URL） | C2 | 单条规则，唯一函数产出 | 步骤一 + 三 |
| P4 | `with_artifacts` 赋值即覆盖，同工具第二次声明会静默丢前一批 | C7 | 追加语义 + 去重 | 步骤一 |
| P5 | `with_artifacts(None, …)` 返回无 `status` 的 `llm_data`，判态双 `False` | C2 C5 | 签名收为必填 `other_data`，无 `llm_data` 入参，问题从接口上消失 | 步骤二 |
| P6 | 收集器原地给生产者 dict 注入 `tool_name`，污染工具返回体与观测步落库 | C6 | 拷贝后注入 | 步骤四 |
| P7 | 遥测去重键 `(tool_name, path)` 与读口 `path` 不一致，同路径不同工具两层结论相反 | C3 | 统一 `artifact_dedup_key` | 步骤一 + 四 + 五 |
| P8 | 超 50 条保留最早，丢最新 | C7 | 保留最新，截断写 warning | 步骤一 |
| P9 | URL 条目名恒定 `generated_image.png`，多张图同名 | C2 | 取 URL 末段文件名 | 步骤一 |
| D1 | 规范称"产物声明均在 success 分支"，`fetch_webpage` 在 warning 分支也声明 | 文档一致性 | 收集条件明确为 `success`/`warning`，文档同步 | 步骤四 + 七 |
| D2 | 收集器只排除异常结果，不判 `exec_code` | C5 | 显式按 `exec_code` 过滤 | 步骤四 |

## 四、一次性实施方案

七个步骤构成一次完整整改，全部完成后才提交。步骤顺序即依赖顺序，中间态不做兼容处理。

### 4.1 步骤一：新建契约模块 `backend/app/utils/artifacts.py`

- 位置：全局层 `app/utils/`（符合"分层存放"与"复用优先"）；
- 内容：附录 B 全部代码，文件头写编辑历史（日期 + 小欧 + 目的）；
- 上限常量 `MAX_ARTIFACTS = 50` 定义在此，其他模块不得再各自定义；
- 依赖：仅标准库（`os`、`logging`、`urllib.parse`），不 import 任何业务模块，避免反向依赖。

### 4.2 步骤二：`tool_response.py` 删除旧入口

| 动作 | 对象 |
|---|---|
| 删除 | `extract_ext`（`:192`）、`with_artifacts`（`:198`）、`with_artifact_file`（`:210`）、`artifact_from_url`（`:222`）、`_ARTIFACT_SUFFIXES`（`:219`） |
| 保留 | `build_success` / `build_error` / `build_warning` / `build_missing_dep_error` / 判态函数 |
| 编辑历史 | 追加一行：删除产物声明三函数，契约迁至 `app/utils/artifacts.py`，落点由 `llm_data.action` 改为 `other_data` |

删除而非保留别名，是 C4 的直接要求。旧函数在 `FUNCTIONS.md` 的登记同步删除（步骤七）。

`_ARTIFACT_SUFFIXES` 一并删除：新模块用 `_ext_of(_url_basename(url))` 取真实后缀，不再维护硬编码后缀表，新增媒体类型无需改代码（消除 OCP 问题）。

### 4.3 步骤三：17 个产出工具改声明入口

27 处调用点，分布在 17 个文件。改动模式统一：**函数入口补 `other` 局部变量 → 声明改为返回值接收 → `build_*` 传 `other_data`**。业务逻辑零改动。

| `desktop/screen_capture.py` | `:200` | `declare_artifact_file` |
| `document/write_docx.py` | `:268` | `declare_artifact_file` |
| `document/write_pdf.py` | `:272` | `declare_artifact_file` |
| `document/write_pptx.py` | `:431` | `declare_artifact_file` |
| `document/write_xlsx.py` | `:265` | `declare_artifact_file` |
| `file/compress_files.py` | `:435` | `declare_artifact_file` |
| `file/copy_file.py` | `:233` | `declare_artifact_file` |
| `file/edit_text_file.py` | `:692` | `declare_artifact_file` |
| `file/extract_archive.py` | `:245` | `declare_artifact_file`（目录 → 自动 `form="dir"`） |
| `file/move_file.py` | `:236` | `declare_artifact_file` |
| `file/rename_file.py` | `:117`、`:137` | `declare_artifact_file` |

补充说明：

- 16 个文件当前**不传** `other_data`（仅 `fetch_webpage` 传），需在函数入口加 `other: Dict[str, Any] = {}`；
- `generate_image` / `generate_video` 的本地分支原先手搓 `{"name":..., "path":..., "type":"video"}`，改为 `declare_artifact_file`，`type` 自动取扩展名，`form` 自动判 `file`（消除 P3 的 DRY 违规）；
- `extract_archive` 传的是目录，`artifact_from_file` 内 `isdir` 判定为 `dir`，`type="dir"`，无需特判；
- `fetch_webpage` 的 warning 分支（Jina 成功但内容偏短、文件已落盘）继续声明产物，这是正确行为；文档表述同步改为"成功与警告分支"。

### 4.4 步骤四：遥测收集器改造 `agent_telemetry.py`

| 位置 | 改前 | 改后 |
|---|---|---|
| 收集来源 | `result["llm_data"]["action"]["artifacts"]` | `read_declared_artifacts(result)`（读 `other_data["artifacts"]`） |
| 收集条件 | 仅排除 `Exception` | `exec_code in ("success", "warning")` 才收集，其余跳过 |
| 注入 `tool_name` | 原地改生产者 dict | `dict(a, tool_name=...)` 拷贝后注入 |
| 去重 | 键 `(tool_name, path)` | `artifact_dedup_key` |
| 上限 | `[:50]` 保留最早 | `merge_artifacts` 保留最新 + 截断 warning |
| `_merge_artifacts` | 保留 | 删除，职责并入 `merge_artifacts` |

`on_tool_call` 的 `artifacts` 参数保留（外部签名不变），内部仍走 `merge_artifacts`。

`build_final_stats_step` 不动：它只消费 `self._artifacts`，条目已是五字段，前端类型同步后即对齐。

### 4.5 步骤五：读口改造 `storage.list_session_task_artifacts`

| 位置 | 改前 | 改后 |
|---|---|---|
| 条目来源 | 直接读 `it` 的 `path/name/type` | `normalize_artifact(it)`，`None` 跳过（兼容历史四字段数据） |
| 去重 | `seen_paths`（纯 `path`） | `seen`（`artifact_dedup_key`） |
| `rel_path` | 对所有 `path` 调 `root_relative` | 仅 `form == "file"` 计算；`dir`/`url` 恒 `None` |

## 七、结论

1. **旧三函数的分层是对的，落点和契约是错的**。基座 + 便捷封装 + 条目构造器的结构保留，但整体迁到 `app/utils/artifacts.py`，落点从 `llm_data.action` 改为 `other_data`。
2. **问题不是九个 bug，是一个结构性缺失**：条目缺"形态"这一维，导致 `path` 一字段三义、`type` 三套含义、下游各自猜。补齐形态、把判定收敛到一个函数，九项问题同时消失。

4. **改动面**：新增 1 个契约模块；后端改 21 个文件（17 个工具 + `tool_response.py` + `agent_telemetry.py` + `storage.py`）；前端改 6 个文件；文档 3 处 + `FUNCTIONS.md`。无数据库变更、无数据迁移。
5. **本次只出方案，代码与既有文档未改**。

## 附录 B 契约模块完整代码

```python
# -*- coding: utf-8 -*-
"""产物条目唯一契约模块 — 小欧 2026-11-21

产物清单的唯一字段定义、唯一规范化、唯一去重、唯一存在性判定。
声明端（产出工具）、收集端（agent_telemetry）、读口（storage）、前端类型
全部以此为准，任何模块不得再自行解释条目字段。

编辑历史:
2026-11-21 - 小欧 - 新建: 产物声明契约从 tool_response 三函数迁出, 落点由
  llm_data.action 改为 other_data["artifacts"]; 补 form 形态维度, type 收敛为
  单条规则, 去重键统一(URL 去签名/本地 normcase+abspath), 上限保留最新并告警。
"""
from __future__ import annotations

import logging
import os
from typing import Any, Dict, List, Optional
from urllib.parse import unquote, urlsplit

logger = logging.getLogger(__name__)

MAX_ARTIFACTS = 50

FORM_FILE = "file"
FORM_DIR = "dir"
FORM_URL = "url"
_FORMS = (FORM_FILE, FORM_DIR, FORM_URL)
_HTTP_PREFIXES = ("http://", "https://")


def _is_url(path: str) -> bool:
    return path.lower().startswith(_HTTP_PREFIXES)


def _ext_of(path: str) -> str:
    """小写无点扩展名；无扩展名返回空串。"""
    base = os.path.basename(str(path or "").rstrip("\\/"))
    head, dot, ext = base.rpartition(".")
    if not dot or not head or not ext:
        return ""
    return ext.lower()


def _url_basename(url: str) -> str:
    """URL 末段文件名（去 query/fragment 并解码），无则空串。"""
    try:
        path = urlsplit(url).path
    except ValueError:
        return ""
    return unquote(path.rsplit("/", 1)[-1]).strip()


def normalize_artifact(raw: Any) -> Optional[Dict[str, str]]:
    """任意来源条目 -> 五字段标准条目；不可成立返回 None。

    幂等：normalize(normalize(x)) == normalize(x)。
    form 已存在则信任，不重新探测磁盘，保证历史数据形态稳定。
    """
    if not isinstance(raw, dict):
        return None
    path = str(raw.get("path") or "").strip()
    if not path:
        return None

    form = str(raw.get("form") or "").strip().lower()
    if form not in _FORMS:
        if _is_url(path):
            form = FORM_URL
        elif os.path.isdir(path):
            form = FORM_DIR
        else:
            form = FORM_FILE

    raw_type = str(raw.get("type") or "").strip()
    if form == FORM_URL:
        name = str(raw.get("name") or "").strip() or _url_basename(path)
        type_ = _ext_of(name) or raw_type or FORM_URL
    elif form == FORM_DIR:
        name = str(raw.get("name") or "").strip() or os.path.basename(path.rstrip("\\/")) or path
        type_ = FORM_DIR
    else:
        name = str(raw.get("name") or "").strip() or os.path.basename(path)
        type_ = _ext_of(name) or _ext_of(path) or FORM_FILE

    return {
        "tool_name": str(raw.get("tool_name") or ""),
        "name": name,
        "path": path,
        "form": form,
        "type": type_,
    }


def artifact_dedup_key(item: Dict[str, Any]) -> str:
    """去重键：形态 + 去签名资源地址。"""
    form = str(item.get("form") or FORM_FILE)
    path = str(item.get("path") or "")
    if form == FORM_URL:
        try:
            parts = urlsplit(path)
        except ValueError:
            return f"{FORM_URL}:{path}"
        return f"{FORM_URL}:{parts.scheme.lower()}://{parts.netloc.lower()}{parts.path}"
    return f"{form}:{os.path.normcase(os.path.abspath(path))}"


def artifact_exists(item: Dict[str, Any]) -> bool:
    """产物是否仍可达：url 不做网络探测；dir 用 isdir；file 用 isfile。"""
    form = str(item.get("form") or FORM_FILE)
    path = str(item.get("path") or "")
    if form == FORM_URL:
        return bool(path)
    if form == FORM_DIR:
        return os.path.isdir(path)
    return os.path.isfile(path)


def artifact_from_file(path: str, name: str = "") -> Dict[str, str]:
    """本地文件/目录 -> 标准条目（form 按磁盘实况：目录 dir，其余 file）。"""
    p = str(path or "").strip()
    item = normalize_artifact({
        "name": name,
        "path": p,
        "form": FORM_DIR if os.path.isdir(p) else FORM_FILE,
    })
    return item or {}


def artifact_from_url(url: str, kind: str = "") -> Dict[str, str]:
    """公网产物 URL -> 标准条目（name 取末段文件名，type 取后缀，认不出用 kind）。"""
    u = str(url or "").strip()
    item = normalize_artifact({
        "name": "",
        "path": u,
        "form": FORM_URL,
        "type": _ext_of(_url_basename(u)) or str(kind or "").strip(),
    })
    return item or {}


def merge_artifacts(existing: Optional[List[Any]],
                    new_items: Optional[List[Any]]) -> List[Dict[str, str]]:
    """唯一合并入口：规范化 + 按去重键合并（后到覆盖先到）+ 保留最新 MAX_ARTIFACTS 条。"""
    out: List[Dict[str, str]] = []
    index: Dict[str, int] = {}
    for raw in list(existing or []) + list(new_items or []):
        item = normalize_artifact(raw)
        if item is None:
            continue
        key = artifact_dedup_key(item)
        pos = index.get(key)
        if pos is None:
            index[key] = len(out)
            out.append(item)
        else:
            out[pos] = item
    if len(out) > MAX_ARTIFACTS:
        dropped = len(out) - MAX_ARTIFACTS
        out = out[-MAX_ARTIFACTS:]
        logger.warning("[artifacts] 条目超过 %d 条, 丢弃最早 %d 条", MAX_ARTIFACTS, dropped)
    return out


def declare_artifacts(other_data: Optional[Dict[str, Any]],
                      items: List[Any]) -> Dict[str, Any]:
    """声明入口（基座）：产物条目挂 other_data['artifacts']，追加语义，不改入参。"""
    other: Dict[str, Any] = dict(other_data or {})
    other["artifacts"] = merge_artifacts(other.get("artifacts"), items)
    return other


def declare_artifact_file(other_data: Optional[Dict[str, Any]],
                          file_path: str) -> Dict[str, Any]:
    """声明入口（便捷）：由本地路径声明单个产物。"""
    return declare_artifacts(other_data, [artifact_from_file(file_path)])


def read_declared_artifacts(result: Any) -> List[Dict[str, str]]:
    """读取口：从工具返回体取已声明产物并规范化（收集器专用）。"""
    if not isinstance(result, dict):
        return []
    other = result.get("other_data")
    if not isinstance(other, dict):
        return []
    return merge_artifacts([], other.get("artifacts"))
```
