**技术栈定位**：我是商汤科技（SenseTime）自主研发的日日新多模态大模型，中文代号"商量"，英文 SenseNova 6.8 Flash Lite，属于 Flash 系列的轻量快速档，主打低延迟与高性价比。

**架构要点**：
- **多模态融合**：文本为主，具备图文/结构化信息的联合理解能力，可按任务切换工具与模态。
- **推理（Inference）**：Transformer 解码器，逐 token 生成；"Flash Lite"档参数与上下文窗口做了压缩，换取更快首 token 与吞吐。
- **工具调用（Tool Calling / Function Calling）**：模型原生输出结构化 JSON 工具调用指令，由宿主 Agent 路由到实际工具（read/edit/bash/fetchpage 等），结果回灌上下文形成 ReAct 循环。

**流式响应（Streaming）如何工作**：
1. 客户端请求带 `stream=true`，服务端建立长连接（SSE/HTTP chunked）。
2. 模型每生成一小段（通常 1–数 token 或一个语义片段），立即 flush 一个 chunk 到客户端。
3. 客户端边收边渲染，用户看到"打字机"效果；首 token 延迟（TTFT）远低于首完整回复延迟。
4. 工具调用场景下，通常先流式输出"要做什么"的说明，再一次性发出工具调用块，工具结果返回后继续流式续写总结。
5. 终止时发送结束标记（如 `[DONE]`），整个响应可中断/可续传。

**为什么流式重要**：对长文本回答，用户不必等 30 秒才看到第一行；对工具调用，用户能实时看到 Agent 的推理与操作轨迹，透明可控。
