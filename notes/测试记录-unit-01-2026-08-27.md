# OmniAgent 全能任务助手 — 能力全览

## 一、文件操作 📁

### 读写能力
| 能力 | 支持格式 | 说明 |
|------|----------|------|
| **读取文本** | txt/md/py/js/ts/json/yaml/yml/xml/html/css/csv/log 等 | 全文/分页/尾部N行/前N行，自动检测编码，支持GBK等 |
| **写入/编辑文本** | 同上 | 覆盖写、追加写、精确替换（once/all/before/after）、插入新逻辑 |
| **读取媒体** | 图片(JPG/PNG/GIF/BMP/WebP/SVG/ICO/TIFF)、音频(MP3/WAV/OGG/FLAC/AAC)、视频(MP4/AVI/MOV/MKV) | 返回Base64供分析 |
| **禁用范围** | .docx/.xlsx/.pptx/.odt/.ods/.odp/.rtf/.PDF 及媒体文件 | 用文本工具读取会失败 |

### 搜索能力
- **`find`** — 按文件名glob模式递归搜索（支持 `*.py`、`**/*.json`、中文文件名），支持 offset 分页
- **`grep`** — 在文件/目录中按正则搜索文本内容，含前后上下文行，结果按修改时间降序
- **`listdir`** — 列出目录扁平内容（文件+子目录），支持分页、排序、显隐藏文件
- **`tree`** — 展示目录层级树结构（可控制深度）

### 移动与归档
- **复制/移动/重命名** — 文件与目录均支持，目录默认递归，可覆盖
- **压缩** — zip/tar/tar.gz/tar.bz2，支持加密密码、排除模式
- **解压** — 自动识别格式，保留目录结构，加密ZIP需密码

## 二、代码执行 💻

### 原生能力
- **`shell`** — 执行系统命令，内置四种解释器可选：
  - **ps7**（PowerShell 7，推荐）原生支持 `&&` `||`
  - **ps5**（PowerShell 5.1，当前环境）需改用分号链式
  - **cmd** / **bash**
- 超时可控（1秒–10分钟），支持自定义成功退出码
- 路径含空格用 `& "path"` 调用

### 能力边界
| 场景 | 说明 |
|------|------|
| 运行脚本 | ✅ 可直接执行 Python/Node/PowerShell/Bash 脚本 |
| 编译程序 | ✅ 可调用 gcc/clang/make/cmake 等编译工具 |
| 交互式程序 | ⚠️ 超时限制，不适合长期运行的服务 |
| 网络请求 | ❌ 无内置HTTP工具，需通过 `searchtool` 注入备用工具 |
