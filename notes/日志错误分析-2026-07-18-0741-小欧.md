## 六、需修补清单（明确）
1. **【系统行为缺口·已修】非可重试客户端错误（400 内容审核等）终态应返回明确错误说明而非空响应**。
   - 根因：`response_text` 仅由 `final` 事件填充（e2e_helpers.py:365）；致命 LLM 错误走 `handle_answer` error 分支只发 `ErrorStep`、不发 `FinalStep`（agent_runner.py:25 注释明示），致 `response_text` 为空（unit-09 暴露）。
   - 修复：`app/services/agent/handlers/answer_handler.py` 的 error 分支与 unknown 分支补发 `FinalStep` 填充响应正文；`_dispatch_handler` 中 `error` 优先于 `final`，终态仍 FAILED，与 reasoning-only 终止分支 emit FinalStep 模式一致。修复时间 2026-07-18 小欧。
2. **【模型输出抖动·已有兜底·暂不修】** `write_xlsx` JSON 畸形、`write_pptx` 缺字段、FC 解析回退、reasoning-only 空转——系统已有 L1/L2 重试、参数校验、Text 回退兜底，能自愈，仅增加重试开销；如需可加强 JSON 提取鲁棒性（可选增强，非必须）。
3. **【预期行为·非缺陷】** 45 个 shell 脚本 Traceback、15 次安全 HITL 暂停、listdir 大目录截断、copy 目标已存在——均为设计内预期，不需修。
