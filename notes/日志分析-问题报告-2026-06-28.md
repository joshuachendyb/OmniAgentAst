## 问题2: WindowsPath.strip()错误（严重）

### 现象
```
2026-06-28 00:39:51,311 - ERROR - read_text_file.py:311 - read_text_file failed: C:\Users\chend\AppData\Local\Temp\omniagent_paramtest_round3: 'WindowsPath' object has no attribute 'strip'
```

### 根本原因分析

**问题定位**: `backend/app/tools/file_type_checker.py:122`

**错误代码**:
```python
def check_file_type(file_path: str, ...):
    if not file_path or not file_path.strip():  # ← 这里！
        return False, "文件路径不能为空", None
```

**问题原因**:
- 函数签名声明 `file_path: str`，但实际传入了 `Path` 对象
- `Path` 对象没有 `strip()` 方法，导致 `AttributeError`

**传入路径**:
- `read_text_file.py:204` → `check_for_text_tool(file_path, check_content=True)`
- 某处代码将 `Path` 对象传给了 `file_path` 参数

### 修复方案

**方案1: 强制转换为字符串（推荐）**
```python
def check_file_type(file_path: str, ...):
    # 防御性转换：确保file_path是字符串
    if isinstance(file_path, Path):
        file_path = str(file_path)
    
    if not file_path or not file_path.strip():
        return False, "文件路径不能为空", None
```

**方案2: 修改类型注解**
```python
from pathlib import Path
from typing import Union

def check_file_type(file_path: Union[str, Path], ...):
    # 统一转换为字符串
    file_path = str(file_path)
    
    if not file_path or not file_path.strip():
        return False, "文件路径不能为空", None
```

**修复步骤**:
1. 在 `check_file_type()` 函数开头添加类型转换
2. 检查所有调用 `check_file_type()` 的地方，确保传入的是字符串
3. 运行测试验证修复
