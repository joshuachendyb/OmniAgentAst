## 问题1: 测试脚本Unicode错误（严重）

### 现象

```python
UnicodeEncodeError: 'gbk' codec can't encode character '\U0001f4ca' in position 48: illegal multibyte sequence
Traceback (most recent call last):
  File "G:\OmniAgentAs-desk\backend\tests\test_e2e_p0_04a_data_persistence.py", line 90
    print(f"  [Step4] Response: {resp[:150]}...")
```

### 问题分析

**根本原因**: 
- 测试脚本使用 `print()` 输出LLM回复内容
- LLM回复包含emoji字符 `\U0001f4ca` (📊)
- Windows控制台默认GBK编码，无法编码emoji
- 导致测试脚本崩溃

**影响**: 
- 测试标记为FAILED
- 但实际功能正常，只是测试脚本输出失败

### 修复方案

**方案1: 设置环境变量（推荐）**
```python
# 在测试脚本开头添加
import sys
import io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
```

**方案2: 捕获异常**
```python
# 修改print语句
try:
    print(f"  [Step4] Response: {resp[:150]}...")
except UnicodeEncodeError:
    print(f"  [Step4] Response: {resp[:150].encode('utf-8', errors='ignore').decode('utf-8')}...")
```

**方案3: 移除emoji**
```python
# LLM回复中移除emoji
def remove_emoji(text):
    return text.encode('ascii', errors='ignore').decode('ascii')
```

## 问题4: SQL执行错误（中等）

### 现象

```
2026-06-28 00:36:27,470 - ERROR - execute_sql.py:157 - [execute_sql] ERR_SQL_EXEC: You can only execute one statement at a time.
2026-06-28 00:36:27,735 - ERROR - execute_sql.py:157 - [execute_sql] ERR_SQL_EXEC: UNIQUE constraint failed: users.id
```

### 问题分析

**错误1**: `You can only execute one statement at a time.`
- LLM尝试一次执行多条SQL语句
- execute_sql工具限制一次只能执行一条

**错误2**: `UNIQUE constraint failed: users.id`
- LLM尝试插入重复的ID
- 违反UNIQUE约束

**影响**: 
- execute_sql工具执行失败
- 但这是LLM参数错误，不是代码bug

### 改进建议

**工具Schema改进**:
```python
# execute_sql添加提示
description="执行单条SQL语句（不支持多条语句，请逐条执行）"
```

## 问题5: 工具参数错误（中等）

### 现象

```json
步骤4: read_text_file
参数: {"file_path": "E:\\test_dir\\dir_inventory.txt", "limit": 100}
观察结果: {
  "error_detail": "limit必须配合offset使用",
  "exec_code": "error"
}
```

### 问题分析

**错误原因**: LLM调用 `read_text_file` 时只传了 `limit`，未传 `offset`

**LLM修正过程**:
- 步骤4: `{"limit": 100}` ❌ 错误
- 步骤5: `{"offset": 1, "limit": 100}` ✅ 修正
- 步骤6: `{"offset": 100, "limit": 100}` ✅ 正确

**影响**: 
- 浪费1次工具调用（12ms）
- LLM需要额外思考修正
- 不影响最终结果
