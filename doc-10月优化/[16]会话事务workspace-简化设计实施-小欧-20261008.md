## 一、设计总体目标和要求

### 1.1 总体目标

给每个会话一份**会话使用目录列表**：本次任务产物落在这里。做到三件事 —— 建得对（一条规则）、用得上（两处接线）、不添乱（系统绝不删磁盘目录，前后端不纠缠）。

### 1.2 后端要求

| # | 要求 | 说明 |
|---|---|---|
| 1 | 表只装会话使用目录 | `chat_session_workspaces`，3 字段；授权目录归全局 config，不进表 |
| 2 | 建立规则一条 | 有→直接用；没有→建立；禁区行清库（只删库行） |
| 3 | 使用只有两处 | 并入写白名单；追加到 user 尾（只拼 LLM 那份） |
| 4 | 端点读写表 | GET 读（过滤后返回可用＋不可用）；PATCH 全量覆盖写 |
| 5 | 判据复用全局 | 不自造黑名单，接 `_is_forbidden_path`＋`validate_path` |
| 6 | 失败只降级不掀任务 | 快照失败按无目录跑完，不 500、不泄漏 ContextVar |

### 1.3 前端要求

| # | 要求 | 说明 |
|---|---|---|
| 1 | 面板读写列表 | 调 GET 展示、调 PATCH 修改；禁区行置灰（读 `unusable` 带的原因） |
| 2 | PATCH 即时生效 | 无 dirty、无暂存、无草稿（已定案的 UX 代价，见 §三） |
| 3 | 徽标现算 | 目录数＝列表长度，不另存状态 |
| 4 | 不碰磁盘语义 | 面板只有"增/删条目"，没有"删目录"按钮；文案不许用删除语言 |

### 1.4 前后端共同硬约束

| 约束 | 说明 |
|---|---|
| **删会话 ≠ 删目录** | 软删会话＋清库行，磁盘目录一律不动 |
| **面板移除 ＝ 只改列表** | 目录留磁盘，用户自行处置 |
| **系统绝不删磁盘目录** | 全链路只有 `mkdir`，无删除调用（已静态验证） |
| **落库存用户原文** | 注入块只拼给 LLM 那份 |
| **会话目录 ≠ 授权目录** | 两概念各走各的口，不遍历对方 |

### 1.5 明确不做的事

| 不做 | 理由 |
|---|---|
| 同名换名（`-2/-3`） | 定案"已存在直接使用" |
| 建失败回滚库行 | 行留着，下次自愈补建 |
| "清空后不重建"标记 | 与"没有就建立"直接冲突 |
| 会话层自造授权判据 | 授权归全局 config |
| 前端草稿/暂存/红点 | 为砍复杂度付出的明确代价（见 §三） |

## 二、后端设计实施结果

> 按本地代码实际（`workspace_service` 13 个公开成员，`MAX_WORKSPACES=64`，`MAX_PATH_CHARS=240`）。依赖链：`db_initializer` 建表 → `workspace_service` → `sessions.py` 端点 → `context` 快照 → 编排器 → 三处并入 → `session_service` 清行。

### 2.1 表结构

```sql
CREATE TABLE IF NOT EXISTS chat_session_workspaces (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT    NOT NULL,
    path       TEXT    NOT NULL COLLATE NOCASE,
    UNIQUE(session_id, path),
    FOREIGN KEY (session_id) REFERENCES chat_sessions(id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_csw_session ON chat_session_workspaces(session_id);
```

存值保大小写，去重靠 casefold 键＋库级 `NOCASE`；存量旧表由初始化按建表语句比对自动迁移。不设时间列、`is_default`、`ws_initialized`。

### 2.2 存储层 `workspace_service.py`（新建，唯一真源）

| 函数 | 职责 |
|---|---|
| `classify_workspace_rows(rows)` | 过滤唯一真源 → `(有效路径集 list[str], 不可用清单)`；禁区判定先于存在判定；`is_dir()`（文件不收）；unusable 带机器可读 `kind`（illegal/denied/missing） |
| `reconcile_session_workspaces(conn, sid)` | 进入会话唯一真源 → 空则造默认 → classify → 禁区行清库 / 缺目录建目录 → 返回有效路径集 |
| `set_session_workspaces(conn, sid, paths)` | PATCH 唯一写入口：数量先拦 → 归一化 → 去重 → 预检 → 写库；只改库行 |
| `get_session_workspaces(conn, sid)` | 读行（`ORDER BY rowid`） |
| `_normalize_ws_path(p)` | 归一化唯一源：空串/非绝对/超长硬拒 → resolve＋去尾分隔符（保大小写）；可抛 OSError/ValueError，调用方必须捕获 |
| `_ws_deny_reason(p)` | 合法性判据：复用 `_is_forbidden_path`＋`validate_path(system)`＋宽根规则 |
| `_is_broad_root(p)` | 宽根判据，fail-closed（异常按拒绝＋告警） |
| `_build_default_workspace_dir(sid)` | `{项目根}/{YYYYMMDD-HHMMSS}-{会话标识前4位}`（编排器下沉至此） |
| `session_exists(conn, sid)` | `COALESCE(is_deleted,FALSE)`，否则 404 |
| `_load_workspaces_conn` / `_ws_apply` / `_ws_precheck` | 快照源 / 覆盖写实现 / 预检 |

### 2.3 建立规则实现

`reconcile_session_workspaces` 即"有→直接用，没有→建立"：空列表造默认目录（`INSERT OR IGNORE`＋`mkdir exist_ok` 幂等）；`denied` 行 DELETE 清库（失败只报失败，不再打成功日志）；`missing` 行 `mkdir`；终判重读重算。编排器 `_ensure_and_load_workspaces` 只剩 atxn 回调壳（必须同步 def，`_run_txn` 不 await）。

### 2.4 使用①②实现

① `get_default_allowed_paths()`、`_get_allowed_roots()`、`_guard_forbidden_delete()` 分别并入快照 `all_paths`（后两者必须转 `Path`，混 str 会静默失效）；快照 `build()` 经 `_drop_nested` 去嵌套（同组父子只留顶层）。② `_append_ws_suffix()` 双层标签（`<system-reminder>`＋`<会话工作目录>`），文案只说"优先"（白名单是并集）；调用点只叠加在 `run_agent_in_background` 的 `last_message` 上，`user_input` 变量与落库零污染。

### 2.5 端点语义

GET 走 `classify` 过滤，返回 `workspaces`（可用）＋`unusable`（带原因，前端置灰）；PATCH body 即全量覆盖（`[]`＝清空），禁区整单 422（`error.workspace_rejected`），会话不存在 404。类型 `list[str]`，垃圾元素 422。

### 2.6 删会话

`session_service` 软删＋清库行，磁盘目录不动。真库现有 2 行真实用户数据，只读不碰。
