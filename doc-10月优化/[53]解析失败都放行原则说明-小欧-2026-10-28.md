## 一、原则背景

**北京老陈 2026-10-28 定下安全原则**：

> 解析出错，就是解析失败，必须放行，不能去拦截和进行风险弹窗。解析失败都放行。

本原则与同日裁定的「确定的才拦截，搞不定的解析去掉，不能错杀」一脉相承：
- **解析失败**（解析器跑不出/判定异常/输入畸形）→ 一律放行，不拦不弹窗。
- **确定危险**（路径明确在系统区、真路径含元字符的系统区删除）→ 仍拦截。

## 二、核心概念解释

### 2.1 一条 bash 命令如何被安全检查

当 LLM 想执行一条命令（如 `grep -rn "xxx" frontend/src`），会把命令打包成参数传给后端，关键字段：

```
command = "grep -rn \"xxx\" frontend/src"   ← 命令原文（字符串）
cwd     = "F:\OmniAgentAs-01"               ← 工作目录（字符串，相对路径以此为基准）
```

安全检查流程：**解析 command 里的路径 → 判断这些路径安不安全**。

### 2.2 术语解释

| 术语 | 大白话 | 处理 |
|------|--------|------|
| **command 非字符串** | 命令参数传成了数字/对象，不是文字 | 放行 |
| **cwd 非字符串/含元字符** | 工作目录传错了，或是数字/带 `\|` 特殊符号 | 放行 |
| **cwd 归属判定异常** | 判不出 cwd 属于系统区还是项目根（程序报错） | 放行 |
| **路径含元字符（假）** | grep 正则 `\|` 被误当路径 | 放行 |
| **路径含元字符（真）** | `del C:\Windows\a\|b` 真实删系统区 | 仍拦 |

### 2.3 逐条详解

#### (1) command 非字符串

`command` 参数应为一段文字，但传成数字 `123`、字典 `{...}` 等。LLM 生成参数出错所致。**为何放行**：非能执行的命令，解析不出任何路径，属解析失败；执行层收到非字符串同样报错，不执行危险命令。

#### (2) cwd 非字符串 / 含元字符

`cwd` 传成数字，或含 `>` `<` `|` 特殊符号。**何为元字符**：`>`（重定向）、`<`、`|`（管道）是命令行有特殊含义的符号；正常 Windows 目录名永不含这三个（`|` 在 Windows 文件名是非法字符），含之说明是解析污染/错误输入。**为何放行**：cwd 只是相对路径参照点，非删/写目标；畸形→相对路径解析不出，属解析失败。

#### (3) cwd 归属判定异常

拿到 cwd 后要判断它属于哪一类（系统禁区/项目根/授权目录），这一步叫**归属判定**（`classify_path`）。判定抛异常（名单读不出/格式解析失败），没判出来。**为何放行**：判不出归属 ≠ 确定危险，只是分析失败；不能因分析工具坏掉冤枉命令。

#### (4) 路径含元字符（分两种，处理不同）

- **假路径**：`grep "task-list-item\|task-text-block"` 里 `\|` 是 grep 正则交替符号，根本不是路径，解析器却误当路径 → 误判，已修。
- **真路径含元字符**：`del "C:\Windows\a|b"` 里路径 `C:\Windows\a|b` 含 `|`，但是真实删除目标、指向系统区 → 确定危险，仍拦。

**关键区别**：元字符在命令的模式串（grep 正则）→ 解析失败放行；元字符在真实系统区路径（del C:\Windows\...）→ 确定危险拦截。

## 四、修改清单

### 4.1 词法层治本（lexer.py）

`backend/app/safety/shell_parse/lexer.py` 新增 `_PATH_UNLIKELY_CHARS = (">", "<", "|")`，三处函数对**相对路径候选**排除含元字符 token：

- `_relative_tokens`：含 `> < |` 词条非路径（模式串/污染），排除。
- `pathish`：相对候选含元字符非路径，排除；绝对路径（盘符开头）保留。
- `refpath_like`：相对候选含元字符非路径，排除。

**安全边界**：绝对路径（盘符开头）不排除元字符——真路径含污染（如 `del "C:\Windows\a|b"`）交 `_malformed` 兜底硬拦，不因改而漏拦。

### 4.2 解析失败改放行（shell_path_check.py）

## 五、保持拦截（确定危险，非解析失败）

- **系统区删除/写**：`del C:\Windows\a.txt`、`echo x > C:\Windows\a.txt` → 仍拦。
- **真路径含元字符**：`del "C:\Windows\a|b"`、`rm -rf "C:\Windows\a|b"` → 仍拦。
- **递归删除系统区**：`rm -rf "C:\Windows\x"` → 仍拦。
