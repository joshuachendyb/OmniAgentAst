## 一、需求背景

### 1.1 现状问题

会话页面（ChatPage）的左侧和右侧区域使用固定的 flex 比例分配：
- 左列：`flex: '1 1 25%'`（约 25%）
- 右列：`flex: '1 1 75%'`（约 75%）

**问题**：
1. 用户无法根据内容调整面板宽度
2. 固定比例不适配不同屏幕尺寸
3. 左侧任务列表可能需要更宽空间显示

### 1.2 优化目标

1. 中间的线可以拖动改变两个区域的宽度
2. 左侧的宽度默认为 1/3
3. 不违反代码 10 大规范，全局逻辑代码最佳

---

## 二、技术方案

### 2.1 设计原则（10 大规范）

| 规范 | 应用 |
|------|------|
| **SRP** | SplitPane 组件只负责分割面板，不负责内容渲染 |
| **DRY** | 拖动逻辑只写一次，复用 Files 页的拖动模式 |
| **KISS-DIRECT** | 直接使用鼠标事件，不引入复杂抽象 |
| **SLAP** | SplitPane 是 UI 层，不混入业务逻辑 |
| **YAGNI** | 不引入第三方库，不预设未来需求 |
| **禁止 backward** | 不使用向后兼容的做法 |

### 2.2 架构设计

```
SessionLayout（布局容器）
  └── SplitPane（可拖动分割面板）
        ├── 左侧面板（任务列表等）
        ├── 分割线（可拖动）
        └── 右侧面板（查看器等）
```

### 2.3 核心实现

#### SplitPane 组件

**职责**：
- 管理左右面板的宽度拖动逻辑
- 提供键盘可访问性（←/→）
- 提供 ARIA 属性（role="separator"）

**状态管理**：
- `leftW`：左侧面板宽度（像素）
- 初始值：容器宽度的 1/3

**拖动逻辑**：
- `mousedown`：记录初始位置，添加 mousemove/mouseup 监听
- `mousemove`：计算新宽度，更新状态
- `mouseup`：清理监听器

**边界约束**：
- 最小宽度：200px
- 最大宽度：容器宽度的 80%（保留右侧最小空间）

#### SessionLayout 修改

**原代码**：
```tsx
<div style={{ flex: '1 1 25%', minWidth: 200, maxWidth: 560 }}>
  {renderSlot(panels, 'left')}
</div>
<div style={{ flex: '1 1 75%' }}>
  {renderSlot(panels, 'right')}
</div>
```

**新代码**：
```tsx
<SplitPane
  left={renderSlot(panels, 'left')}
  right={renderSlot(panels, 'right')}
/>
```

## 六、v1.1 宽度优化（2026-10-27 08:42）

### 6.1 问题反馈

用户反馈：左侧菜单栏宽度没有明显变窄，给右侧会话页面留的空间不够。

### 6.2 原因分析

1. **初始渲染问题**：`useEffect` 在容器渲染后执行，但 `container.offsetWidth` 可能为 0，导致宽度计算错误
2. **固定比例问题**：原来固定 1/3（约 33%），在 1440px 屏幕上约 480px，过宽
3. **状态无关**：右侧折叠/展开时，左侧宽度没有区别

### 6.3 优化方案

#### SplitPane 组件

| 状态 | v1.0 宽度 | v1.1 宽度 | 变化 |
|------|-----------|-----------|------|
| 右侧折叠 | 480px（1/3） | 240px（18%） | -50% |
| 右侧展开 | 480px（1/3） | 280px（22%） | -42% |

**核心逻辑**：
```typescript
const getInitialWidth = (containerW: number, rightOpen: boolean): number => {
  if (containerW === 0) {
    // 初始渲染时容器宽度为 0，返回固定默认值
    return rightOpen ? 280 : 240;
  }
  if (rightOpen) {
    return Math.min(280, Math.round(containerW * 0.22));
  }
  return Math.min(240, Math.round(containerW * 0.18));
};
```

#### TaskListPanel 紧凑化

| 属性 | v1.0 | v1.1 | 变化 |
|------|------|------|------|
| 外层 padding | 4px 0 | 2px 0 | -50% |
| 任务项 padding | 10px 12px | 8px 10px | -20% |
| 元信息行 gap | 8px | 6px | -25% |
| 元信息行 marginBottom | 6px | 4px | -33% |
