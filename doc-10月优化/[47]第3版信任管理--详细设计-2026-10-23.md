## 二、需求要求说明

> 编写：小欧 2026-10-23 20:39:12

### 2.1 背景与目标

**需求原点**：一次授权不再打扰、范围分档且事后可调、跨会话可继承与复制。

| 目标诉求 | 落地形态 |
|---|---|
| 一次授权不再打扰 | 信任条目命中即免弹（HTL） |
| 范围分档 + 事后可调 | 全局/会话/任务三域分档，条目可跨域提升/迁移 |
| 跨会话继承 | 全局域条目全局生效；会话 A→B 导入 |
| "任务"的口径 | 任务级 = 本任务及其 link 续聊的任务链（组）；隔离键 = 链根 `chat_tasks.context_root_task_id` |

贯穿性约束：① 档位不随会话切换漂移；② 撤销可发现；③ 不做信任变更历史/导出。

### 2.2 信任条目定义

信任条目 = 中风险操作授权/确认的记录；信任是权限的一部分（权限规则的应用产物）。

条目数据结构由四组构成：

| 信息组 | 字段 | 说明 |
|---|---|---|
| 核心组 | action + path | 条目主体。action 必有；path 可缺（bash/系统级命令无路径）。一期只处理有 path 的条目 |
| 产生组 | 时间 + 会话ID + 任务ID | 条目产生时的来源（辅助信息） |
| 生效域 | 全局 / 会话 / 任务 | 数据库三值字段，决定条目归属域 |
| 授权对象 | 会话ID / 任务ID | 定向指定条目可用的会话/任务，可空 |

### 2.3 产生机制（HTL 授权弹窗）

- 产生入口：HTL 授权弹窗，用户点击"同意"生成条目；弹窗选择含 action、path 与生效域。
- 产生截断：核心组(action+path) + 产生组(时间+会话ID+任务ID)。
- 授权对象继承：生成时，授权对象取当时的"启用域"选择（会话ID、任务ID），规则见 2.4。
- 一期范围：只做有 path 的条目；无 path 的 bash/系统级命令（仅 action）不纳入。

### 2.4 生效域与启用域语义

- 生效域：数据库字段，三值 全局/会话/任务；信任条目页面中称"生效域"。
- 启用域：任务执行时输入框下方的选择项（全局/会话/任务），决定本任务使用哪些条目。

产生 HTL 授权时，条目生效域 = 当前任务执行所选的启用域，并据此设定授权对象：

| 启用域 | 条目生效域 | 授权对象·会话ID | 授权对象·任务ID |
|---|---|---|---|
| 全局 | 全局 | 空 | 空 |
| 会话 | 会话 | 当前会话ID | 空 |
| 任务 | 任务 | 当前会话ID | 当前任务ID |

### 2.5 应用矩阵（任务执行时按启用域取条目）

任务开始执行时，在输入框下方选择"使用域/启用域"（全局/会话/任务），按下表取生效的条目集合：

| 启用域 | 生效的信任条目集合 |
|---|---|
| 全局 | 全局域条目 + 本会话级条目 + 会话域"会话ID空"条目 |
| 会话 | 会话域"会话ID空"条目 + 本会话ID条目 |
| 任务 | 任务域"任务ID空"条目 + 本任务ID条目 |

统一术语：条目的应用对象称"授权对象"（会话ID/任务ID）。

### 2.6 授权对象空值语义

授权对象标志共三种组合：无会话ID+无任务ID、有会话ID+无任务ID、无会话ID+有任务ID。

| 场景 | 含义 |
|---|---|
| 会话ID空 + 任务ID空 | 本会话及本任务下的新会话、新任务均可使用 |
| 会话域启用 + 会话ID空 | 生效"会话ID空"条目 + 本会话ID所属条目 |
| 任务域启用 + 任务ID空 | 生效"任务ID空"条目 + 本任务ID所属条目 |

特别说明：任务域条目主要面向 link 任务（单任务生命期仅一次，完成后指向无意义；仅 link 任务长期存在）。单任务条目可迁移到长生命期对象（会话、link 任务）及全局域。

### 2.7 信任管理页 /trust

定位：展示全部信任条目，支持域间迁移与对象变更。

**三列布局**（核心 UI 模式，对应三域）：

| 列 | 分组 | 显示内容 |
|---|---|---|
| 全局列 | 全局域 | 全局域下所有条目 |
| 会话列 | 会话 | 会话域所有条目：含"会话ID空"的新会话组（对应会话ID空条目的授权范围）+ 含具体会话ID 的会话组；空会话组也显示 |
| 任务列 | 任务 | 任务域所有条目：含"任务ID空"的新任务组（对应任务ID空条目的授权范围，新任务可为单次任务或 link 任务）+ 含具体任务ID 的任务组；空任务组也显示 |

**条目变更 = 条目迁移**（仅改归属，不改核心组）：
- 生效域变更：全局/会话/任务之间迁移。
- 生效对象变更：A会话→B会话；X任务→Y任务。

**变更交互（拖拽）**：
- 拖拽对象：条目块，核心信息为 action+path。
- 拖拽目标：目标区域对应的列/组（全局列/会话组/任务组）。
- UI 层级：第1层=条目块(action+path)；第2层=任务组；第3层=会话组。
- 产生组、授权对象等其他信息，决定条目落在哪个组内。

**范围约束**：本次仅变更 /trust 页；其他页面的信任相关 UI 大体保持不变。

### 2.8 贯穿约束

- 档位不随会话切换漂移：会话切换时，已选档位保持不变。
- 撤销可发现：条目的撤销（迁移/删除）在页面可被用户发现。
- 不做信任变更历史/导出：不记录变更流水，不提供导出。
