## 一、需求定义

### 1.1 总览：三个能力，一个面板

本次改造为会话事务空间面板带来三个核心能力：

| 能力 | 现状 | 改造后 |
|---|---|---|
| **新增目录** | ✅ 有（仅 path） | ✅ 增强（path + role + memo 三字段同时填） |
| **删除目录** | ✅ 有 | ✅ 不变 |
| **编辑目录** | ❌ 无 | ✅ **新增**：行内编辑，支持改 path、role、memo 三个字段 |

> 当前面板只有"输入框 + 添加按钮"和"每行一个删除按钮"。用户添加目录后想改 role 或 memo，只能删掉重新加。本次改造让每条目录支持原地编辑——点编辑按钮后该行切换为输入态，三字段全可改，保存即回写。

### 1.2 为什么是 role + memo 两个字段

| 字段 | 定位 | 解决什么 | 是否注入 prompt |
|---|---|---|---|
| **role** | 读写分区引导（结构化的三档语义） | 让 LLM 快速判断"这目录是拿来读的、拿来写的、还是主战场" | ✅ 注入为 `[读取工作区]/[读写工作区]/[写工作区]` 标注 |
| **memo** | 自由文本备注（非结构化的补充说明） | 表达 role 三档无法覆盖的具体信息，如"后端源码，别碰 legacy 目录"、"报告按 YYYYMMDD 命名" | ✅ 注入为行尾备注 |

**两者互补不重叠**：
- role 是**枚举化的粗粒度分类**（可快速筛选/着色/统计）
- memo 是**自由文本的细粒度补充**（role 装不下的具体约束、命名规约、注意事项）

> **为什么不用 alias**：alias 只是"短名标识"，与 role 承担的"读写语义"重叠 80%，且不携带任何可供 LLM 行动的信息。role + memo 组合的信息密度显著高于 alias，且直接作用于 prompt → LLM 行为，价值闭环完整。

### 1.3 role 的本质：引导标注，不是权限约束

**关键前提（必须在实现中守住）**：

- 本系统**没有"只读区域"设置** —— 路径是否可写一律由安全矩阵（`write_path_check` / `path_dir_lists` / `delete_path_check`）与确认层统一裁决
- role 是**纯 prompt 引导词**，让 LLM 自己理解"这个目录大概干嘛的"
- role **不影响**：安全判定、快照白名单、禁区判定、读写权限
- 即使 role=读取工作区 的目录，LLM 若发起写操作，安全矩阵照样按规则裁决（该放行就放行，该拦就拦）
- role 的效力边界：**只在 LLM 的语义理解层**，不在执行层

### 1.4 三档预设 + 自由输入

| role 预设值 | 语义 | LLM 行为引导 | badge 颜色 |
|---|---|---|---|
| **读取工作区** | 主要用来查阅参考 | 此目录以读取为主，写操作需谨慎 | 绿 |
| **读写工作区**（默认） | 默认可读写工作区 | 正常工作目录，按任务需要读写 | 蓝 |
| **写工作区** | 产物/报告输出目标 | 产物、报告、中间文件**优先**写这里 | 橙 |
| 自定义值 | 用户自由输入（如"构建产物"/"日志区"/"源码查阅"） | 按值本身的字面语义理解 | 灰 |

**role 为 TEXT 非 ENUM**：允许自由输入，识别不了的走灰色 badge + 默认引导，不报错不拦截。

### 1.5 自定义 role 值跨会话共享（localStorage）

用户在面板里自定义输入过的新 role 值（不在三档预设内），通过浏览器 `localStorage` 持久化，后续所有会话的 AutoComplete 下拉都能看到，避免重复手打。新增和编辑时都会触发持久化。

| 项 | 设计 | 理由 |
|---|---|---|
| 存储位置 | `localStorage["ws_custom_roles"]` = JSON 数组 | 浏览器本地，零后端改动 |
| 存储时机 | `addEntry` / `saveEdit` 时，若 role 值不在三档预设内，自动追加 | 无感知，用户不需要额外操作 |
| 去重 | 加入前检查数组中是否已有该值 | 避免重复项 |
| 上限 | 最多保留 16 条自定义值 | 防无限膨胀；超出按 FIFO 淘汰最旧的 |
| 跨会话 | ✅ 同浏览器所有会话共享 | 这是"个人习惯标签"，非团队规范 |
| 跨机器 | ❌ 不同浏览器/机器不共享 | YAGNI —— 没有多机器同步需求 |

**实现**（前端 ~15 行，仅 `SessionWorkspacePanel.tsx` 内）：

```typescript
const WS_ROLE_PRESETS = ['读取工作区', '读写工作区', '写工作区'];
const CUSTOM_ROLES_KEY = 'ws_custom_roles';
const MAX_CUSTOM_ROLES = 16;

function loadCustomRoles(): string[] {
  try {
    const raw = localStorage.getItem(CUSTOM_ROLES_KEY);
    return raw ? JSON.parse(raw) : [];
  } catch { return []; }
}

function saveCustomRole(role: string): void {
  if (WS_ROLE_PRESETS.includes(role)) return;   // 预设值不存
  const list = loadCustomRoles();
  if (list.includes(role)) return;               // 已有不存
  list.push(role);
  if (list.length > MAX_CUSTOM_ROLES) list.shift();   // FIFO 淘汰
  try { localStorage.setItem(CUSTOM_ROLES_KEY, JSON.stringify(list)); } catch {}
}
```

AutoComplete 的 options 合并预设 + 自定义：

```typescript
const roleOptions = useMemo(() => {
  const customs = loadCustomRoles();
  return [...WS_ROLE_PRESETS, ...customs]
    .filter((v, i, arr) => arr.indexOf(v) === i)   // 去重
    .map(v => ({ value: v }));
}, []);
```

### 1.6 memo 设计约束

| 项 | 取值 | 理由 |
|---|---|---|
| 类型 | `TEXT DEFAULT NULL` | 可选字段，NULL = 无备注 |
| 最大长度 | 256 字符 | 足够写一两句具体约束；防长串污染 prompt |
| 是否必填 | 否 | 不破坏现有流程；YAGNI |
| 是否唯一 | 否 | 备注内容可重复 |
| 换行 | 不允许 | 单行注入，避免破坏 prompt 行结构（前端换行符 → 空格） |
| 参与安全判定 | **否** | 纯 prompt 文本，不做任何路径校验 |

### 1.7 行内编辑设计

面板的每条目录行支持"展示态 ↔ 编辑态"切换，三字段（path、role、memo）全可改。

| 项 | 设计 | 理由 |
|---|---|---|
| 触发方式 | 展示态行内 ✏️ 编辑按钮 | 与 🗑 删除按钮并排，操作入口一致 |
| 编辑范围 | path + role + memo 三个字段全可改 | 用户可能填错路径、想换分区、想补备注 |
| path 可改的原理 | PATCH 写库是 DELETE 全删 → INSERT 全量，改 path = 改数组元素，不存在 UNIQUE 冲突 | 不需要单独的 UPDATE 某行 |
| 同一时间只编辑一行 | `editingIndex` 单值，点新行编辑自动退出旧行 | 避免多行同时编辑的 state 混乱 |
| 编辑不立即 PATCH | 改的是本地 `entries` state，点"确定"才统一提交 | 与 add/delete 一致（都是改 state → 确定时一次性 PATCH） |
| 编辑保存时校验 path | `isAbsolute` 检查，与 addEntry 同校验规则 | 保证数据一致 |
| role AutoComplete 复用 | 编辑态和新增区共享 `roleOptions` | DRY |
| 自定义 role 持久化 | `saveEdit` 里调 `saveCustomRole(r)` | 与 addEntry 同逻辑 |
| 回车保存 | path Input 和 memo Input 都绑 `onPressEnter={saveEdit}` | 快捷操作 |
| 取消编辑 | 点"取消"按钮丢弃修改回到展示态 | 不影响 state |

### 2.5 当前 Prompt 注入格式（基线）

`stream_orchestrator.py` L402-407：

```python
def _append_ws_suffix(user_input: str) -> str:
    snap = get_ws_snapshot()
    if not snap or not snap.all_paths:
        return user_input                    # 空/无快照不追加，不污染 prompt
    lines = "\n".join(f"  - {p}" for p in sorted(snap.all_paths))
    return (
        f"{user_input}\n\n<会话工作目录>\n"
        f"本次任务新增会话工作目录：\n{lines}\n"
        "要求你临时/中间文件优先写入会话工作目录.\n"
        "</会话工作目录>\n"
    )
```

    返回被拒清单；非空即调用方返 422，空即 200。

    入参兼容两形态（旧前端/脚本不炸）：
      list[str]  → 视为 (path, 默认role, 无memo)
      list[dict] → {"path": ..., "role": ..., "memo": ...}
    role/memo **不参与预检**（不是路径，与安全判定无关）。
    前端编辑（改 path/role/memo）后整批提交，本函数不区分新增/编辑——全量覆盖。"""

    if raw_items and isinstance(raw_items[0], str):
        raw_items = [{"path": p} for p in raw_items]
    if len(raw_items) > MAX_WORKSPACES:
        return [{"path": f"({len(raw_items)} 条)", "reason": f"目录数超上限({MAX_WORKSPACES})"}]

    entries, rejected, _seen = [], [], set()
    for it in raw_items:
        _p = it.get("path", "")
        try:
            _n = _normalize_ws_path(_p)
        except (OSError, ValueError) as _e:
            rejected.append({"path": _p, "reason": f"路径非法: {type(_e).__name__}: {_e}"})
            continue
        _k = _n.casefold()

            continue
        _seen.add(_k)
        _role, _memo = _normalize_ws_meta(it.get("role"), it.get("memo"))
        entries.append((_n, _role, _memo))
    if rejected:
        return rejected                      # 归一化失败即整单 422，不再写库

    rejected = _ws_precheck([p for p, _r, _m in entries])
    if rejected:
        return rejected

    _ws_apply(conn, session_id, entries)
    logger.info(f"[workspace] 会话使用目录已更新: session={session_id} 数量={len(entries)}")
    return []

def classify_workspace_rows(rows) -> tuple[list, list]:
    """行 → (有效条目集, 不可用清单)：**会话目录过滤唯一真源**。

    返回值变更：effective 由 list[str] 升级为 list[tuple[str, str, Optional[str], bool]]
    = [(path, role, memo, is_default)]。role/memo/is_default 只**透传**，不参与任何裁决 ——
    归一化/禁区/宽根/存在性判定全部只看 path，安全语义零变化。"""
    effective, unusable = [], []
    for r in rows:
        try:
            p = _normalize_ws_path(r["path"])
        except (OSError, ValueError) as _e:
            unusable.append({"path": r["path"], "reason": f"路径非法({type(_e).__name__})",
                             "kind": "illegal"})
            continue
        reason = _ws_deny_reason(p)          # 禁区判定先行，全套判据
        if reason:
            unusable.append({"path": p, "reason": reason, "kind": "denied"})
            continue

            unusable.append({"path": p, "reason": "不是目录或不存在", "kind": "missing"})
            continue
        _role, _memo = _normalize_ws_meta(r["role"] if "role" in r.keys() else None,
                                          r["memo"] if "memo" in r.keys() else None)
        _is_def = bool(r["is_default"]) if "is_default" in r.keys() else False

```python
def reconcile_session_workspaces(conn, session_id: str) -> list[tuple[str, str, Optional[str], bool]]:
    """进入会话·建立一条规则（唯一真源）：默认工作区始终创建 → 逐条裁决 →
    禁区行清库 / 不存在则建目录 / 可用则留 → 返回有效条目集。

    2026-10-28 小欧 - 文档[54] B.7 / [55] 方案D：默认工作区创建从"仅 rows 空才建"升级为
    "始终创建 + is_default 标志 + 项目根感知 + 删除重建"（need_new_default 判定）：
      默认工作区始终存在（先添加目录也创建）；删除后下次重建；项目根改变后在新根重建。
    返回 [(path, role, memo, is_default)] 四元组。

    ⚠ 只删数据库行，**绝不删除磁盘目录**。"""
    rows = get_session_workspaces(conn, session_id)   # 现含 role/memo/is_default 列
    current_root = get_config().get_project_root()     # 当前配置的项目根

    # ── 判断是否需要创建/重建默认工作区（[55]方案D）──
    # 需要创建的条件（任一）：
    #   a) 会话无任何 is_default=1 的行（首次，或用户删除了默认目录）
    #   b) 默认目录不在当前项目根下（项目根改变了）
    need_new_default = True
    for r in rows:
        if r.get("is_default") and Path(r["path"]).parent == Path(current_root):
            need_new_default = False          # 默认工作区存在且在正确位置
            break

    if need_new_default:
        d = _build_default_workspace_dir(session_id)   # 读当前根，天然建在新根下
        if d:
            try:
                # 旧默认目录降为普通目录（保留历史产物，用户可自行处置）
                conn.execute(
                    "UPDATE chat_session_workspaces SET is_default=0 "
                    "WHERE session_id = ? AND is_default = 1", (session_id,))
                # 新默认工作区登记（role=读写工作区，memo=本会话事务空间默认读写区域，is_default=1）
                conn.execute(
                    "INSERT OR IGNORE INTO chat_session_workspaces(session_id, path, role, memo, is_default) "
                    "VALUES (?, ?, ?, ?, 1)",
                    (session_id, _normalize_ws_path(d), DEFAULT_ROLE, DEFAULT_MEMO))
            except Exception as _e:
                logger.warning(f"[chat] 默认目录登记失败（降级走项目根）: {_e}")
        rows = get_session_workspaces(conn, session_id)

    _effective, unusable = classify_workspace_rows(rows)
    for u in unusable:
        if u["kind"] != "denied":
            continue                             # 脏行/缺目录：本轮跳过，下次再看
        try:                                     # 禁区行：从表里清掉（只删库行）
            conn.execute(
                "DELETE FROM chat_session_workspaces WHERE session_id = ? AND path = ?",
                (session_id, u["path"]))
        except Exception as _de:                 # 订正：失败就只报失败，
            logger.warning(f"[chat] 禁区目录清理失败(本轮仍不放行): {u['path']} - {_de}")
            continue                             #   不再无条件打"已清理"
        logger.warning(f"[chat] 会话目录已落入禁区, 已从列表清理: {u['path']}")

    for u in unusable:                           # 缺目录：建出来（禁区/脏行不建）
        if u["kind"] != "missing":
            continue
        try:
            Path(u["path"]).mkdir(parents=True, exist_ok=True)
            logger.info(f"[chat] 会话目录不存在, 已自动建立: {u['path']}")
        except Exception as _e:
            logger.warning(f"[chat] 会话目录建立失败(本轮不生效, 下次再试): {u['path']} - {_e}")

    return _load_workspaces_conn(conn, session_id)   # 重读重判：刚建好的目录本轮即生效
```

 * SessionWorkspacePanel - 会话使用的目录面板
 *
 * 编辑历史: 2026-10-10 小欧 - 新建（四条功能需求 + UI 视觉规范）
 * 编辑历史: 2026-10-10 小欧 - 修4错 / UI优化7项
 * 编辑历史: 2026-10-28 - 小欧 - [54]：新增目录 role(读写分区) + memo(备注) 双字段 +
 *   行内编辑(增/删/改三态完整)。输入区两行（路径+分区 / 备注+添加）；
 *   列表行展示态(path + role Tag + memo + 编辑✏️ + 删除🗑)，编辑态(path Input
 *   + role AutoComplete + memo Input + 保存/取消)。role 预设：读取工作区/
 *   读写工作区/写工作区。自定义 role 通过 localStorage 跨会话共享。
 *   role/memo 纯引导标注，不改变可写性判定。
 */
import { useMemo, useState } from 'react';
import {
  Modal,
  List,
  Input,
  Button,
  Typography,
  Space,
  Empty,
  Tooltip,
  Tag,
  AutoComplete,
} from 'antd';
import {
  DeleteOutlined,
  PlusOutlined,
  EditOutlined,
  FolderOutlined,
  LockOutlined,
} from '@ant-design/icons';
import { settingsModalWidth } from '@/theme/settingsTokens';
import { Spacing, FontSize } from '@/utils/stepStyles';
import { chatTokens } from '@/theme/tokens';
import { sessionApi } from '@/services/api/session.api';
import { showMessage, handleError, ErrorType } from '@/services/error/handler';
import type { UnusableEntry, WorkspaceEntry } from '@/types/chat';

/** role 三档预设 */
const WS_ROLE_PRESETS = ['读取工作区', '读写工作区', '写工作区'] as const;
/** 自定义 role localStorage 管理（新增和编辑共用） */
const CUSTOM_ROLES_KEY = 'ws_custom_roles';
const MAX_CUSTOM_ROLES = 16;
/** role Tag 颜色：预设三档 + 自定义灰 */
const ROLE_COLORS: Record<string, string> = {
  '读取工作区': 'green',
  '读写工作区': 'blue',
  '写工作区': 'orange',
};

/** 读自定义 role 列表（localStorage，失败降级空数组） */
function loadCustomRoles(): string[] {
  try {
    const raw = localStorage.getItem(CUSTOM_ROLES_KEY);
    return raw ? JSON.parse(raw) : [];
  } catch {
    return [];
  }
}

/** 存自定义 role（预设不存、已有不存、FIFO 淘汰、失败静默） */
function saveCustomRole(role: string): void {
  if ((WS_ROLE_PRESETS as readonly string[]).includes(role)) return;
  const list = loadCustomRoles();
  if (list.includes(role)) return;
  list.push(role);
  if (list.length > MAX_CUSTOM_ROLES) list.shift();
  try {
    localStorage.setItem(CUSTOM_ROLES_KEY, JSON.stringify(list));
  } catch {
    /* 隐私模式/配额满：静默降级，不影响主流程 */
  }
}

/** 只做绝对路径格式校验；存在性与禁区交后端判（决策74，避免前端造禁区表） */
const isAbsolute = (p: string) => /^[A-Za-z]:[\\/]/.test(p) || /^\\\\/.test(p);

/** 面板内部草稿：path + role + memo 三字段 */
type WsDraft = { path: string; role: string; memo: string };

interface Props {
  sessionId: string;
  open: boolean;
  onClose: () => void;
  /** 2026-10-28 小欧 - [54]：签名升级，携带 role/memo */
  onSaved: (list: WorkspaceEntry[]) => void;
}

export default function SessionWorkspacePanel({
  sessionId,
  open,
  onClose,
  onSaved,
}: Props) {
  const [entries, setEntries] = useState<WsDraft[]>([]);
  const [unusable, setUnusable] = useState<UnusableEntry[]>([]);
  const [projectRoot, setProjectRoot] = useState('');
  const [allowedDirs, setAllowedDirs] = useState<string[]>([]);
  // 新增区 state
  const [input, setInput] = useState('');
  const [roleInput, setRoleInput] = useState('读写工作区');
  const [memoInput, setMemoInput] = useState('');
  const [inputErr, setInputErr] = useState('');
  // 编辑区 state（行内编辑）
  const [editingIndex, setEditingIndex] = useState<number | null>(null);
  const [editPath, setEditPath] = useState('');
  const [editRole, setEditRole] = useState('读写工作区');
  const [editMemo, setEditMemo] = useState('');
  const [editErr, setEditErr] = useState('');
  // 被拒条目留痕
  const [rejected, setRejected] = useState<{ path: string; reason: string }[]>([]);
  const [saving, setSaving] = useState(false);

  /** AutoComplete options = 预设 + localStorage 自定义（去重），新增区和编辑区共享 */
  const roleOptions = useMemo(() => {
    const customs = loadCustomRoles();
    return [...WS_ROLE_PRESETS, ...customs]
      .filter((v, i, arr) => arr.indexOf(v) === i)
      .map((v) => ({ value: String(v) }));
  }, []);

  /** 打开即重拉（无暂存：关闭即丢） */
  const load = async () => {
    try {
      const r = await sessionApi.getWorkspaces(sessionId);
      setEntries(
        r.workspaces.map((w) => ({
          path: w.path,
          role: w.role || '读写工作区',
          memo: w.memo || '',
        }))
      );
      setUnusable(r.unusable);
      setProjectRoot(r.project_root);
      setAllowedDirs(r.allowed_dirs);
      setInput('');
      setRoleInput('读写工作区');
      setMemoInput('');
      setInputErr('');
      setEditingIndex(null);
      setRejected([]);
    } catch {
      setEntries([]);
      setUnusable([]);
      setProjectRoot('');
      setAllowedDirs([]);
      handleError(new Error('读取会话目录失败'));
    }
  };

  /** 新增（或覆盖已存在同路径条目） */
  const addEntry = () => {
    const v = input.trim();
    if (!v || !isAbsolute(v)) {
      setInputErr('请输入绝对路径');
      return;
    }
    const r = roleInput.trim() || '读写工作区';
    const m = memoInput.trim();
    setInputErr('');
    saveCustomRole(r);
    setEntries((es) =>
      es.some((e) => e.path.toLowerCase() === v.toLowerCase())
        ? es.map((e) =>
            e.path.toLowerCase() === v.toLowerCase()
              ? { path: e.path, role: r, memo: m }
              : e
          )
        : [...es, { path: v, role: r, memo: m }]
    );
    setInput('');
    setRoleInput('读写工作区');
    setMemoInput('');
  };

  /** 进入编辑态：把当前行数据灌入编辑 state */
  const startEdit = (index: number) => {
    setEditingIndex(index);
    setEditPath(entries[index].path);
    setEditRole(entries[index].role);
    setEditMemo(entries[index].memo);
    setEditErr('');
  };

  /** 保存编辑：校验 path → 持久化自定义 role → 回写 entries */
  const saveEdit = () => {
    if (editingIndex === null) return;
    const v = editPath.trim();
    if (!v || !isAbsolute(v)) {
      setEditErr('请输入绝对路径');
      return;
    }
    const r = editRole.trim() || '读写工作区';
    const m = editMemo.trim();
    saveCustomRole(r);
    setEntries((es) =>
      es.map((e, i) => (i === editingIndex ? { path: v, role: r, memo: m } : e))
    );
    setEditingIndex(null);
  };

  /** 取消编辑：丢弃修改回到展示态 */
  const cancelEdit = () => setEditingIndex(null);

  /** 删除条目（删空二次确认） */
  const removeEntry = (index: number) => {
    const willEmpty = entries.length === 1;
    if (willEmpty) {
      Modal.confirm({
        title: '清空目录列表？',
        content:
          '清空后本会话不再有使用目录，产物将退回项目根。磁盘目录不会被删除。',
        okText: '清空',
        cancelText: '取消',
        onOk: () => {
          setEntries([]);
          setEditingIndex(null);
        },
      });
      return;
    }
    setEntries((es) => es.filter((_, j) => j !== index));
    if (editingIndex === index) setEditingIndex(null);
  };

  /** 确定 → PATCH；422 被拒条目自动摘除 + 逐条提示 */
  const confirm = async () => {
    setSaving(true);
    try {
      await sessionApi.patchWorkspaces(
        sessionId,
        entries.map((e) => ({
          path: e.path,
          role: e.role || '读写工作区',
          memo: e.memo.trim() || undefined,
        }))
      );
      onSaved(
        entries.map((e) => ({
          path: e.path,
          role: e.role || '读写工作区',
          memo: e.memo.trim() || null,
        }))
      );
      onClose();
    } catch (e: unknown) {
      const rejected =
        (
          e as {
            response?: { data?: { error?: { workspace_rejected?: unknown } } };
          }
        )?.response?.data?.error?.workspace_rejected ?? [];
      const items = rejected as { path: string; reason: string }[];
      if (items.length) {
        const bad = new Set(items.map((x) => x.path));
        setEntries((es) => es.filter((x) => !bad.has(x.path)));
        setRejected(items);
        items.forEach((x) =>
          showMessage(ErrorType.WORKSPACE_REJECTED, `${x.path}：${x.reason}`)
        );
      } else {
        throw e;
      }
    } finally {
      setSaving(false);
    }
  };

  return (
    <Modal
      open={open}
      width={settingsModalWidth.display}
      destroyOnHidden
      maskClosable
      confirmLoading={saving}
      title="会话事务空间"
      onOk={confirm}
      onCancel={onClose}
      okText="确定"
      cancelText="取消"
      afterOpenChange={(visible) => {
        if (visible) void load();
      }}
    >
      {/* ① 只读区：项目根 + 授权目录（[读写工作区] 标注，非"只读"——
          这两目录在安全矩阵中同样支持读写，无需特别授权） */}
      <div
        style={{
          background: chatTokens.colorPrimaryBg,
          borderRadius: 6,
          padding: Spacing.MD,
          display: 'flex',
          flexDirection: 'column',
          gap: Spacing.XS,
        }}
      >
        <div style={{ display: 'flex', alignItems: 'center', gap: Spacing.XS }}>
          <FolderOutlined style={{ color: chatTokens.colorTextSecondary }} />
          <Typography.Text
            style={{
              fontSize: FontSize.SECONDARY,
              color: chatTokens.colorTextSecondary,
              flexShrink: 0,
            }}
          >
            项目根
          </Typography.Text>
          <Typography.Text
            ellipsis={{ tooltip: projectRoot || '-' }}
            copyable={{ text: projectRoot }}
            style={{ fontSize: FontSize.SECONDARY, flex: 1 }}
          >
            {projectRoot || '-'}
          </Typography.Text>
          <Tag color="blue" style={{ marginRight: 0 }}>
            读写工作区
          </Tag>
        </div>
        <div style={{ display: 'flex', alignItems: 'center', gap: Spacing.XS }}>
          <LockOutlined style={{ color: chatTokens.colorTextSecondary }} />
          <Typography.Text
            style={{
              fontSize: FontSize.SECONDARY,
              color: chatTokens.colorTextSecondary,
              flexShrink: 0,
            }}
          >
            授权目录
          </Typography.Text>
          <Typography.Text
            ellipsis={{ tooltip: allowedDirs.join('；') || '（未配置）' }}
            copyable={
              allowedDirs.length ? { text: allowedDirs.join('\n') } : false
            }
            style={{ fontSize: FontSize.SECONDARY, flex: 1 }}
          >
            {allowedDirs.length ? allowedDirs.join('；') : '（未配置）'}
          </Typography.Text>
          <Tag color="blue" style={{ marginRight: 0 }}>
            读写工作区
          </Tag>
        </div>
      </div>

      {/* ②③ 可用列表 + 不可用置灰列表（展示态/编辑态分支） */}
      <List
        style={{ marginTop: Spacing.MD }}
        locale={{
          emptyText: (
            <Empty
              image={Empty.PRESENTED_IMAGE_SIMPLE}
              description="尚未添加目录，进入会话后将自动创建默认目录"
            />
          ),
        }}
        dataSource={[
          ...entries.map((e, i) => ({
            key: `${i}_${e.path}`,
            kind: 'ok' as const,
            path: e.path,
            role: e.role,
            memo: e.memo,
            reason: '',
            index: i,
          })),
          ...unusable.map((u) => ({
            key: `u_${u.path}`,
            kind: 'bad' as const,
            path: u.path,
            role: '',
            memo: '',
            reason: u.reason,
            index: -1,
          })),
        ]}
        renderItem={(it) => {
          const isUnusable = it.kind === 'bad';
          return (
            <List.Item
              actions={
                isUnusable
                  ? undefined
                  : [
                      <Tooltip key="edit" title="编辑该目录">
                        <Button
                          type="text"
                          size="small"
                          icon={<EditOutlined />}
                          onClick={() => startEdit(it.index)}
                        />
                      </Tooltip>,
                      <Tooltip key="del" title="移除该目录">
                        <Button
                          type="text"
                          size="small"
                          danger
                          icon={<DeleteOutlined />}
                          onClick={() => removeEntry(it.index)}
                        />
                      </Tooltip>,
                    ]
              }
            >
              {editingIndex === it.index && !isUnusable ? (
                /* ── 编辑态：path + role + memo 三字段全可改 ── */
                <div style={{ width: '100%' }}>
                  <Input
                    style={{ width: '100%', marginBottom: 6 }}
                    value={editPath}
                    onChange={(e) => {
                      setEditPath(e.target.value);
                      setEditErr('');
                    }}
                    onPressEnter={saveEdit}
                    placeholder="目录路径"
                  />
                  {editErr && (
                    <Typography.Text
                      type="danger"
                      style={{
                        fontSize: FontSize.SECONDARY,
                        display: 'block',
                        marginBottom: 4,
                      }}
                    >
                      {editErr}
                    </Typography.Text>
                  )}
                  <Space.Compact style={{ width: '100%' }}>
                    <AutoComplete
                      style={{ width: 120 }}
                      value={editRole}
                      onChange={setEditRole}
                      options={roleOptions}
                      placeholder="分区"
                    />
                    <Input
                      style={{ flex: 1 }}
                      value={editMemo}
                      maxLength={256}
                      placeholder="备注（可选）"
                      onChange={(e) => setEditMemo(e.target.value)}
                      onPressEnter={saveEdit}
                    />
                    <Button type="primary" size="small" onClick={saveEdit}>
                      保存
                    </Button>
                    <Button size="small" onClick={cancelEdit}>
                      取消
                    </Button>
                  </Space.Compact>
                </div>
              ) : (
                /* ── 展示态：path + role Tag + memo 副行 ── */
                <List.Item.Meta
                  title={
                    <div
                      style={{ display: 'flex', alignItems: 'center', gap: 8 }}
                    >
                      <Typography.Text
                        ellipsis={{ tooltip: it.path }}
                        style={{
                          fontSize: FontSize.SECONDARY,
                          flex: 1,
                          color: isUnusable
                            ? chatTokens.colorTextSecondary
                            : chatTokens.colorText,
                        }}
                      >
                        {it.path}
                      </Typography.Text>
                      {!isUnusable && (
                        <Tag
                          color={ROLE_COLORS[it.role] || 'default'}
                          style={{ marginRight: 0 }}
                        >
                          {it.role}
                        </Tag>
                      )}
                    </div>
                  }
                  description={
                    isUnusable ? (
                      <Typography.Text
                        type="secondary"
                        style={{ fontSize: FontSize.SECONDARY }}
                      >
                        {it.reason}
                      </Typography.Text>
                    ) : it.memo ? (
                      <Typography.Text
                        type="secondary"
                        style={{ fontSize: FontSize.SECONDARY }}
                      >
                        {it.memo}
                      </Typography.Text>
                    ) : null
                  }
                />
              )}
            </List.Item>
          );
        }}
      />

      {/* ④ 新增输入区（两行：路径+分区 / 备注+添加） */}
      <Space.Compact style={{ width: '100%', marginTop: Spacing.SM }}>
        <Input
          style={{ flex: 1 }}
          placeholder="目录路径（绝对路径）"
          status={inputErr ? 'error' : undefined}
          value={input}
          onChange={(e) => {
            setInput(e.target.value);
            setInputErr('');
          }}
          onPressEnter={addEntry}
        />
        <AutoComplete
          style={{ width: 120 }}
          value={roleInput}
          onChange={setRoleInput}
          options={roleOptions}
          placeholder="分区"
        />
      </Space.Compact>
      <Space.Compact style={{ width: '100%', marginTop: 6 }}>
        <Input
          style={{ flex: 1 }}
          placeholder="备注（可选，如：后端源码、产物输出、别碰 legacy）"
          value={memoInput}
          maxLength={256}
          onChange={(e) => setMemoInput(e.target.value)}
          onPressEnter={addEntry}
        />
        <Button
          type="primary"
          icon={<PlusOutlined />}
          onClick={addEntry}
          aria-label="添加目录"
        />
      </Space.Compact>
      {inputErr && (
        <Typography.Text
          style={{ fontSize: FontSize.SECONDARY, color: chatTokens.colorError }}
        >
          {inputErr}
        </Typography.Text>
      )}

      {/* 被拒留痕（#3）：自动清除的条目在此可回看 */}
      {rejected.length > 0 && (
        <div
          style={{
            marginTop: Spacing.SM,
            padding: Spacing.SM,
            border: `1px dashed ${chatTokens.colorBorder}`,
            borderRadius: 6,
          }}
        >
          <Typography.Text
            style={{
              fontSize: FontSize.SECONDARY,
              color: chatTokens.colorError,
            }}
          >
            以下 {rejected.length}{' '}
            项已被移除，未存入会话目录表（后端整单拒绝，其余条目也尚未保存，
            请确认后再次点击「确定」）：
          </Typography.Text>
          {rejected.map((r) => (
            <div
              key={r.path}
              style={{
                fontSize: FontSize.SECONDARY,
                color: chatTokens.colorTextSecondary,
              }}
            >
              · {r.path} —— {r.reason}
            </div>
          ))}
        </div>
      )}
    </Modal>
  );
}
```

## 四、Prompt 注入格式（改造后）

### 4.1 典型场景（三档 role + memo）

```
<会话工作目录>
本次任务会话工作目录及分区标注（引导参考，不改变可写性判定）：
  - E:\test_dir\20261025-084845-2639    [读写工作区]  主线任务产物目录  (默认工作区)
  - F:\OmniAgentAs-01\backend            [读取工作区]  后端源码，只查阅不改动
  - F:\OmniAgentAs-01\doc-10月优化       [写工作区]    文档按 [NN]主题-小欧-YYYY-MM-DD.md 命名
要求你临时/中间文件优先写入[写工作区]目录.
</会话工作目录>
```

> **`(默认工作区)` 标注**：关联 `[55]` 方案 D —— `is_default=1` 的行追加该标注，让 LLM 明确"这是本会话自动创建的隔离区，临时/中间文件优先落这里"。

### 4.1a 默认工作区场景（关联 `[55]` 方案 D：先添加目录 + 项目根改变后）

```
<会话工作目录>
本次任务会话工作目录及分区标注（引导参考，不改变可写性判定）：
  - E:\new_root\20261028-180405-abcd    [读写工作区]  本会话事务空间默认读写区域  (默认工作区)
  - E:\test_dir\20261025-084845-2639    [读写工作区]  本会话事务空间默认读写区域
  - F:\OmniAgentAs-01                   [读写工作区]
要求你临时/中间文件优先写入会话工作目录.
</会话工作目录>
```

> **效果**（关联 `[55]` 方案 D）：新任务默认落点 = 新根下的默认工作区（`is_default=1`，标 `(默认工作区)`）；旧根默认目录降为普通（保留历史产物）；用户目录照常。LLM 有清晰三层落点：默认隔离区（新根）→ 历史区（旧根）→ 用户指定区。

### 4.2 无 [写工作区]（退化文案）

```
<会话工作目录>
本次任务会话工作目录及分区标注（引导参考，不改变可写性判定）：

## 五、数据库迁移策略

**使用现有 `_ensure_column` 机制**（幂等，老库安全）：

```python
# db_initializer.py 迁移区追加三条（is_default 关联[55]方案D）
_ensure_column(conn, "chat_session_workspaces", "role", "TEXT DEFAULT '读写工作区'")
_ensure_column(conn, "chat_session_workspaces", "memo", "TEXT DEFAULT NULL")
_ensure_column(conn, "chat_session_workspaces", "is_default", "INTEGER DEFAULT 0")   # 关联[55]方案D
```

| 场景 | 结果 |
|---|---|
| **老库** | role 列自动填 `'读写工作区'`，memo 列 `NULL`，is_default 列 `0` → 旧行行为与现状完全一致 |
| **新库** | 建表语句直接含三列，默认值同上 |
| **UNIQUE** | `UNIQUE(session_id, path)` 不变，role/memo/is_default 允许任意重复 |
| **回滚** | 三列均有默认值/NULL，删列不丢业务数据（只丢标注） |
| **性能** | 每行多三列短文本，64 行上限下可忽略 |

## 七、风险与注意事项

| # | 风险 | 处置 |
|---|---|---|
| 1 | **旧前端 + 新后端** | `set_session_workspaces` 兼容 `list[str]`（自动补 `role='读写工作区', memo=None`）→ 不炸 |
| 2 | **新前端 + 旧后端** | 前端多传 role/memo，旧后端 Pydantic `list[str]` 对 dict 元素校验失败 → **必须先后端后前端上线**（同一版本内一起发） |
| 3 | **role 被误当权限** | prompt 首行明示"引导参考，不改变可写性判定"；文档与代码注释双处说明；安全矩阵零改动 |
| 4 | **role/memo 污染安全判定** | `all_paths` 只由 `e.path` 构成；`_ws_deny_reason` 等判据不接收 role/memo → 结构上不可能污染 |
| 5 | **memo 换行破坏 prompt 行结构** | `_normalize_ws_meta` 统一把 `\r\n` 转空格；前端 Input 本身单行 |
| 6 | **超长 memo 撑爆 prompt** | 后端截断 256 + 前端 `maxLength={256}` 双保险 |
| 7 | **role 自由输入乱填** | 不校验不拒单（拒单代价 > 收益），非预设值走灰色 badge，LLM 按字面理解 |
| 8 | **自定义 role localStorage 丢失** | 浏览器清缓存/换机器会丢失自定义 role 列表。**但库里的 role 值不丢**（存在 DB），只是 AutoComplete 下拉不再提示 → 用户重新输入即可 |
| 9 | **`_drop_nested` 丢子目录标注** | 父目录在快照里时子目录被去嵌套 → 子目录 role/memo 不进 prompt。**面板读库直显不受影响**（面板不走快照），仅 prompt 展示不全；如需保留可在 build 前按 role 分组，但属过度设计（YAGNI），先按现状 |
| 10 | **UNIQUE 约束** | 仍 `UNIQUE(session_id, path)`，role/memo 不参与 → 同路径只有一行，改 role/memo 走覆盖写 |
| 11 | **classify 返回值类型变更** | `effective` 从 `list[str]` → `list[tuple[str, str, Optional[str], bool]]`（四元组，含 is_default），调用方仅 `_load_workspaces_conn` 与 `reconcile` 两处，已同步改造；`set_session_workspaces` 内 `_ws_precheck` 调用处仍为三元组 `[p for p, _r, _m in entries]`（该函数只处理 path/role/memo，is_default 由 reconcile 单独维护） |
| 12 | **classify 中 `r["role"]` 安全取值** | `_ensure_column` 补列后 Row 自动含新列；但 classify 可能被其他来源 rows 调用，故用 `r.keys()` 检查列存在性，缺失时走 `DEFAULT_ROLE` |
| 13 | **编辑 path 后与已有条目重复** | `saveEdit` 不做前端去重（与 addEntry 不同），因为后端 `set_session_workspaces` 的 casefold 去重会自动合并。但用户可能不感知合并 → 可选：`saveEdit` 前检查重复并提示。先按后端兜底（KISS），有反馈再加前端提示 |
| 14 | **编辑中途切换到另一行编辑** | `editingIndex` 单值，点新行 `startEdit` 自动覆盖旧值 → 旧行编辑内容丢失。设计如此（同时只编辑一行），与"取消 = 丢弃"语义一致 |
| 15 | **编辑 path 改成非法路径** | `saveEdit` 做 `isAbsolute` 校验，失败时 `setEditErr` 提示，不退出编辑态 → 用户可修正后重试 |
| 16 | **is_default 与 role/memo 一致性**（关联[55]方案D） | `is_default=1` 的行 role/memo 由系统设定（`DEFAULT_ROLE`/`DEFAULT_MEMO`），用户编辑不改 is_default（PATCH 全量覆盖时 is_default 由 reconcile 维护）→ 结构上不可能冲突 |
| 17 | **is_default 不参与安全判定**（关联[55]方案D） | `all_paths` 只由 `e.path` 构成；is_default 不传给 `_ws_deny_reason` 等判据 → 结构上不可能污染安全判定 |

>
> - 弹框顶部展示的是**系统级固定目录**（项目根 + 授权目录），它们**不是**"只读"目录——在安全矩阵中这两个目录**同样支持读写**：

>   - **授权目录**（如 `G:\xuan-agent`、`F:\agenttool`）：用户显式授权的目录，读写均支持，无需额外授权

## 十、三堂会审自检（设计阶段）

### 10.1 合规检查（10 大规范）

| 规范 | 自检 |
|---|---|
| **SRP** | `_normalize_ws_meta` 只管 role/memo 归一化；`_ws_deny_reason` 只管准入判据；`loadCustomRoles`/`saveCustomRole` 只管 localStorage；`startEdit`/`saveEdit`/`cancelEdit` 只管编辑态切换；职责不混 |
| **DRY** | role/memo 归一化抽 `_normalize_ws_meta` 单一真源；localStorage 工具函数单一出口；`roleOptions` 新增区和编辑区共享；`saveCustomRole` 在 addEntry 和 saveEdit 两处复用 |
| **KISS-DIRECT** | 不做 role 枚举类、不做 registry、不做 validator 链；编辑态直接切分支渲染，不抽 EditableRow 组件（YAGNI——只有一个使用点）；localStorage 直接 JSON.stringify |
| **SLAP** | service 层不碰 prompt 拼接；orchestrator 不碰 DB 写库；localStorage 逻辑在组件内不外泄；编辑态逻辑在组件内不外泄 |
| **YAGNI** | 不做 role 国际化、不做 memo 富文本、不做跨机器同步、不做自定义 role 管理 UI、不抽 EditableRow 组件 |
| **禁止 backward** | ❗例外说明：`list[str]` 兼容是**跨版本接口兼容**（前端可能滞后部署），不是代码内部新旧逻辑并存 —— 属必要兼容层，非 backward 违规 |
| **OCP** | role 为 TEXT 而非 ENUM，新增自定义值零代码改动；localStorage 自定义列表动态扩展不改预设常量；编辑能力复用 PATCH 全量覆盖，不改后端接口 |
| **LSP** | `WorkspaceEntry` 新增字段有默认值，不破坏既有构造点 |
| **ISP** | `WorkspaceItem`（API）与 `WorkspaceEntry`（快照）职责分离，未合并 |
| **复用优先** | 复用既有 `_normalize_ws_path` / `_ws_precheck` / `classify_workspace_rows` / PATCH 全量覆盖，未重造；`roleOptions` / `saveCustomRole` 新增和编辑共用 |

### 10.2 合理检查

- **数据流单向**：DB → service → snapshot → prompt，无回环
- **编辑数据流单向**：`startEdit`（灌入 state）→ 用户改 → `saveEdit`（回写 entries）→ confirm → PATCH → DB，无回环
- **localStorage 数据流单向**：`addEntry`/`saveEdit` → `saveCustomRole` → localStorage → 下次渲染 `loadCustomRoles` → options，无回环
- **无透传层**：`_normalize_ws_meta` 有实质逻辑（trim + 默认 + 截断 + 换行处理），非纯透传
- **异常边界集中**：`_ws_deny_reason` 的 fail-closed 保持不动；role/memo 归一化不抛异常（截断兜底）；localStorage 全 try-catch（隐私模式/配额满不炸）；编辑 path 校验失败不退出编辑态（用户可修正）

### 10.3 关联检查（功能退化风险）

| 链路 | 是否退化 | 说明 |
|---|---|---|
| 安全判定（写/删/读三线） | ❌ 不退化 | `all_paths` 构造逻辑未动 |
| 禁区清理（reconcile） | ❌ 不退化 | 仍按 `u["path"]` 操作 |
