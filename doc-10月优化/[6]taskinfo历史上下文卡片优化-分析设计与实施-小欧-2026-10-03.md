## 一、现状与问题定案（v1.1 已复核）

### 1.1 数据链路（实读代码）

```
后端每轮 LLM 响应后（受门控）
  react_step.py:473-484  build_context_overview() → MetaStep(type="context_overview")
    帧字段真源 = agent_telemetry.py:301-309 的 return dict（7 键）
    文本真源 = MetaStep.content（steps/base.py:80-88：content 为唯一权威文本字段，
              其余 kw 经 _extra_fields 透传）
    基线快照 = start_step.py:237-246 set_injected_context（只置 injected_* 两项）
前端
  sseParser.ts:516-528  → contextOverview（只取 5 键）
    → useTaskInfo.ts:389 overview（**历史任务走 :169 硬置 ''**）
      → infoMaps.tsx:77-88 mapStatus 四态
        → TaskInfoBar.tsx:374-452 MetricItem + FloatingEntry
```

### 1.2 发射门控（`react_step.py:475` 代码）

```python
if _llm_n == 1 or getattr(agent.message_builder, "_trimmed_this_round", False) or _llm_n % 5 == 0:
```

首轮 + 裁剪轮 + 每 5 轮。3 轮任务只发 1 帧；12 轮任务发 1/5/10 三帧。456 行注释称“每次 LLM 响应必发”指的是遥测落库与 stats 帧，本帧被 475 行 gate 住——注释与代码口径不一致（本次仅正名注释，不动逻辑）。

## 二、设计目标（v1.1 收敛为 4 行）

```
历史上下文
装入历史对话 24 条 · 估算Token约 9.2K
最近: xxxxx…（单行省略，悬停见全文；北京老陈 2026-10-04：展开按钮不好看，不做折叠）
```

删除项及原因：**注入占比**（恒 1.0 失真，用户无行动含义）；**第 N 轮快照**（与既有 `轮:N` 重复，且快照只在 1/5/裁剪轮发，与实时轮数并排会互相矛盾）；**剩余额度**（与“已用”线性冗余，且未扣缓冲不可信）；**链组短号/续聊开关**（口径不可对齐、语义误导，见 1.3 第 8 条）。token 一律冠“约”（估算器不动）。
