## Bug清单

### Bug #1: 空字符串被openpyxl转为None

**测试用例**: `test_empty_string`

**问题描述**:
- 输入: `{"列": ""}`
- 预期: 单元格值为空字符串 `""`
- 实际: openpyxl将空字符串转为 `None`

**代码位置**: `write_xlsx.py:138`

**根本原因**: openpyxl库的默认行为，空字符串自动转为None

**影响**: 
- 数据丢失
- 无法区分"空字符串"和"None值"

**建议修复**:
```python
# 在写入单元格时检查空字符串
if cell_data == "":
    ws.cell(row=row_idx, column=col_idx, value="")  # 强制写入空字符串
else:
    ws.cell(row=row_idx, column=col_idx, value=cell_data)
```

**优先级**: P2（中）

### Bug #2: 列宽自适应逻辑错误

**测试用例**: `test_column_width_adaptation`

**问题描述**:
- 输入: `[{"短": "A", "中等长度": "BBB", "这是一个非常长的列名": "CCCCCCCCCCCC"}]`
- 预期: 第三列宽度 > 第二列宽度 > 第一列宽度
- 实际: 列宽顺序不符合预期

**代码位置**: `write_xlsx.py:58-69`

**根本原因**: 
- 列宽计算逻辑可能有问题
- 需要验证 `_adjust_xlsx_column_width` 函数

**影响**:
- 列宽不自适应
- 用户体验差

**建议修复**:
```python
# 检查列宽计算逻辑
def _adjust_xlsx_column_width(ws):
    for col_idx in range(1, ws.max_column + 1):
        max_len = 0
        col_letter = get_column_letter(col_idx)
        for row_idx in range(1, ws.max_row + 1):
            cell = ws.cell(row=row_idx, column=col_idx)
            if cell.value:
                max_len = max(max_len, len(str(cell.value)))
        ws.column_dimensions[col_letter].width = max(max_len + 2, 8)
```

**优先级**: P1（高）

### Bug #3: 特殊字符工作表名未验证

**测试用例**: `test_special_chars_sheet_name`

**问题描述**:
- 输入: `sheet_name="数据/表"`
- 预期: 应该报错或自动替换特殊字符
- 实际: 直接使用，导致Excel打开失败

**代码位置**: `write_xlsx.py:127`

**根本原因**: 
- 未对工作表名进行验证
- Excel不允许工作表名包含: `\ / ? * [ ]`

**影响**:
- 生成的Excel文件可能无法打开
- 用户困惑

**建议修复**:
```python
# 验证工作表名
invalid_chars = ['\\', '/', '?', '*', '[', ']']
for char in invalid_chars:
    if char in sheet_name:
        sheet_name = sheet_name.replace(char, '_')  # 替换为下划线
```

**优先级**: P1（高）

### Bug #5: 空字典处理错误

**测试用例**: `test_empty_dict`

**问题描述**:
- 输入: `[{}]`
- 预期: 0列（因为没有数据）
- 实际: 1列

**代码位置**: `write_xlsx.py:119-123`

**根本原因**: 
- 空字典时，`headers` 为空列表
- 但 `ws.max_column` 仍然返回1（openpyxl默认行为）

**影响**:
- 生成多余的空列
- 数据不准确

**建议修复**:
```python
# 空字典特殊处理
if len(data) > 0 and all(len(row) == 0 for row in data):
    # 所有行都是空字典，不写任何数据
    pass
```

**优先级**: P2（中）
