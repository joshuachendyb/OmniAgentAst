## 四、修复总原则（落地10大规范）

1. **SRP**：单函数只做一件事；回滚/校验/解析各司其职。
2. **DRY**：相同逻辑只写一次；复用 `json_utils`/`time_utils` 等已有公用函数（先查 `FUNCTIONS.md`）。
3. **KISS-DIRECT**：直线逻辑、最小改动；不引入新抽象、不七绕八绕。
4. **SLAP**：调用链同抽象层；不在底层函数里混编排。
5. **YAGNI**：不加用不上的接口/模式。
6. **禁止 backward**：所有改动坚决不保留向后兼容分支。
7. **复用优先**：新函数先查库，能复用必复用。
8. **零退化**：功能只能正确/增强/优化，杜绝退化（三思三省、复查10遍）。
9. 每条 diff 标注 `文件:行号` 与「改后代码」，改前逻辑已在第二章核实，不再回贴。
10. 拆分/合并代码遵循「先复制后改」，不重写业务逻辑。

### 5.1 #1 edit_text/copy/compress 操作不可回滚（属实）

- **病症**：`rollback_operation` 对 edit_text/copy/compress 返回 False，文件改动无法恢复，回滚静默失败。

- **修复 diff（核实3遍：①确认缺分支 ②按 op_type 直线分派，符合 SRP/KISS ③回滚=反向操作，零退化）**：

`app/services/safety/operation_rollback.py` 的 `rollback_operation`，在 `CREATE` 分支后追加：

```python
            elif op_type == OperationType.MODIFY.value:
                # 编辑类：用执行时备份的源文件恢复（backup 由 operation_executor 生成）
                if backup and Path(backup).exists():
                    backup_path = Path(backup)
                    source_path = Path(src)
                    source_path.parent.mkdir(parents=True, exist_ok=True)
                    if backup_path.is_dir():
                        shutil.copytree(backup_path, source_path, dirs_exist_ok=True)
                    else:
                        shutil.copy2(backup_path, source_path)
                    success = True
                    logger.info(f"Restored edited file from backup: {backup} -> {source_path}")
                else:
                    logger.warning(f"No backup for MODIFY rollback: {operation_id}")
            elif op_type in (OperationType.COPY.value, OperationType.COMPRESS.value):
                # 复制/压缩：回滚=删除生成的目标文件（与 CREATE 同语义）
                dest_path = Path(dst) if dst else Path(src)
                if dest_path.exists():
                    if dest_path.is_dir():
                        shutil.rmtree(dest_path)
                    else:
                        dest_path.unlink()
                    success = True
                    logger.info(f"Removed copied/compressed target: {dest_path}")
```

`app/services/safety/operation_executor.py:93-95` 的备份生成扩展为 MODIFY：

                    and source_path and source_path.exists():

### 5.2 #2 move 回滚无备份，source 被占则回滚失败（属实，非灾难性丢数据）

- **病症**：move 回滚直接用 `dest_path.rename(source_path)`，若原 source 位置已被新文件占用，Windows 下 `rename` 抛 `FileExistsError` → 回滚失败（文件停在 dest，未丢但回滚失效），与 DELETE 有备份的机制不一致。
- **病根**：`operation_rollback.py:53-59` MOVE 分支无备份、无占用保护。
- **核实证据**：`operation_rollback.py:53-59`；`operation_executor.py:93-95` MOVE 不生成 `backup_path`。
- **修复 diff（核实3遍：①确认无占用保护 ②回滚前先保全当前 source 再 rename，符合 SRP/KISS ③不丢数据，零退化）**：

`app/services/safety/operation_rollback.py` 的 MOVE 分支改为：

```python
            elif op_type == OperationType.MOVE.value:
                dest_path = Path(dst)
                source_path = Path(src)
                if dest_path.exists():
                    # 先保全当前 source（若被新文件占用）再移回，杜绝覆盖丢失
                    if source_path.exists():
                        _bak = source_path.with_name(source_path.name + ".rollback_bak")
                        try:
                            source_path.rename(_bak)
                        except Exception as _e:
                            logger.error(f"MOVE rollback: backup occupied source failed: {_e}")
                            return False
                    dest_path.rename(source_path)
                    success = True
                    logger.info(f"Moved back: {dest_path} -> {source_path}")
```

```python
import threading
_pending_confirmations: Dict[str, _PendingConfirmation] = {}
_pending_lock = threading.Lock()

def _cleanup_stale_confirmations() -> None:
    with _pending_lock:
        stale = [k for k, v in _pending_confirmations.items()
                 if time.monotonic() - v.created_at > _STALE_SECONDS]
        for k in stale:
            _pending_confirmations.pop(k, None)

def resolve_confirmation(confirm_id, confirmed, ...) -> bool:
    with _pending_lock:
        entry = _pending_confirmations.get(confirm_id)
        if entry is None or entry.future.done():
            return False
        entry.future.set_result({...})
        _pending_confirmations.pop(confirm_id, None)
    return True
```
