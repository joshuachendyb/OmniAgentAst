## 一、概述

OmniAgentAs-desk 是全栈（React+FastAPI）AI Agent 桌面应用。核心模式是 **用户输入 → 意图检测 → Agent工厂 → ReAct循环 → SSE流式返回**。

本文深度梳理系统中 12 个关键流程，从入口到出口追踪完整数据流，并为每个流程定义测试要点和测试方法。

### 流程1：HTTP请求入口与SSE流式初始化

**文件链**: `chat_openai.py:42` → `chat_stream()` → `run_sse_stream()`

**当前状态**: `chat_router.py` 已合并入 `chat_openai.py`（2026-06-23 北京老陈）

```
Frontend fetch POST /api/v1/chat/stream
  │
  ▼
chat_stream_endpoint(request: ChatRequest)          ← chat_openai.py:42
  │
  ▼
chat_stream(request)                                 ← chat_openai.py:86
  ├── 1. user_input = request.messages[-1].content
  ├── 2. session_id = request.session_id or uuid4()
  ├── 3. task_id = uuid4()
  ├── 4. _current_task_id.set(task_id)               ← ContextVar设置
  ├── 5. next_step = create_step_counter()
  ├── 6. register_task(task_id, ai_service)           ← task_registry.py:41
  ├── 7. task_interrupt_check(task_id)                ← 中断检查
  ├── 8. step_start()                                ← 发出start SSE事件
  ├── 9. run_sse_stream(...)                         ← Agent执行核心
  │       │
  │       ├── _cancel_poller()                       ← asyncio.create_task
  │       │     └── 每秒检查check_cancelled()
  │       │
  │       └── async for sse_chunk in sse_stream:
  │             ├── task_pause_check_and_yield()     ← 暂停检查
  │             └── task_cancel_check_and_yield()    ← 取消检查
  │
  └── finally: task_cleanup(task_id, llm_call_count)
```

**关键设计**:
- task 生命周期在 `chat_stream` 的 `generate()` 内管理，finally 保证 cleanup
- `_cancel_poller` 是独立 asyncio task，每秒轮询取消状态
- cancel 检测到后调用 `sse_stream.aclose()` 关闭生成器

```
  │     └── return ChunkBuffer(MAX_CONSECUTIVE_CHUNKS)
  │
  ├── agent.status = AgentStatus.EXECUTING
  │
  ├── while agent.llm_call_count < max_steps:
  │     │
  │     └── async for event in _process_single_step(agent, chunk_buffer):
  │           │
  │           ├── call_llm(agent)                           ← llm_caller.py:17
  │           │     ├── agent.llm_call_count += 1

  │           │     └── async for chunk in request_stream(...):
```

### 流程6：SSE事件流（后端→前端）

**文件链**: `run_sse_stream.py:38` → `format_agent_sse()` → 前端

**当前状态**: 直接 `to_dict()` 不经 SSE 字符串往返（2026-06-08 P1修复）

```
  │
  ├── agent = UniversalAgent(llm_client, task_id)
  ├── llm_client.set_stop_check(_stop_check)          ← 注入停止回调
  ├── context["previous_messages"] = _load_previous_messages(session_id)
  │
  └── async for event in agent.run_react_cycle(task, context, task_id):
        │
        ├── event_dict = event.to_dict()              ← 直接转dict
        │
        ├── current_execution_steps.append(event_dict) ← 累积步骤
        │
        ├── event_type == "final" → stream_state.current_content = content
        ├── event_type == "chunk" → stream_state.current_content += chunk
        │
        └── sse_data = format_agent_sse(event_dict)   ← 格式化SSE
              yield sse_data
```

**异常路径**:

```
CancelledError:
  ├── yield MetaStep(type="interrupted")
  ├── yield FinalStep(response="任务已被中断")
  └── agent.status = COMPLETED

Exception:
  ├── yield ErrorStep(error_type="agent_operation_error")
  ├── yield FinalStep(response="执行异常: ...")
  └── agent.status = FAILED

finally:
  └── save_execution_steps_to_db(session_id, steps, content)
```

**8种 SSE type**:

| Type | 含义 | Step类 |

| `chunk` | AI流式回复片段 | ChunkStep |
| `action_tool` | 工具调用 | ActionStep |
| `observation` | 工具执行结果 | ObservationStep |
| `final` | 最终回答 | FinalStep |
| `error` | 错误信息 | ErrorStep |
| `interrupted` | 中断 | MetaStep(type="interrupted") |
