## 一、三步部署运行

1. **放 CLI**：`setup_cli.bat <opencode-cli.exe完整路径>`（或者自放，文件名必须 `opencode-cli.exe`）
2. **配 token**：复制 `config.example.json` → `config.json`，token 换成随机 64 位 hex（默认端口/池参数不动）
3. **起停**：
   - 启动：`start.bat`（自动设 NO_PROXY，回环不走代理）
   - 停止：`stop.bat`（只杀 8199 端口进程）
   - 判活：`/healthz` 返回 `status=ok`，`cli=idle` 是正常（按需启动），对话后转 `up`

要求：Python 3.11+ 装 `fastapi uvicorn httpx`；硬约束——**先起网关，再拉模型**，反序会报错。

## 二、宿主接入（零代码）

`config\config.yaml` 的 `ai:` 下去新增：

```yaml
  opencli:
    label: opencli本地网关
    api_base: http://127.0.0.1:8199/v1
    api_key: <与网关 token 同值>
    timeout: 900
    max_retries: 2
    models: []
```

要点：
- `api_base` **必须带 `/v1`**（唯一契约锚点，两边一致）
- 环境变量 `setx NO_PROXY "127.0.0.1,localhost"` 后**重启后端**
- UI 四步：建 provider → 拉模型（免费层 9–10 个，个数波动正常）→ 勾选 → 保存对话
- 鉴权两层不用管：宿主 token 部署时已写入；下游密码网关自动捕获，不暴露

## 三、测试

```
python gateways\tests\run_cases.py            # 快速套件（约 1 分钟）12 过/0 败/3 跳
python gateways\tests\run_cases.py --full     # 加重型 C4/F1/F2/F3/D7（约 5 分钟）
```

- `--only A3,D1` 点选复跑；FAIL 退出码 1，可挂 CI
- **C4（并发 40）可能触发免费层 429 → 网关冷却约 1 小时**，空闲窗口再单独跑；F3→D7→F1→F2 已实测全过
- SKIP 项（断网/停服/思考模型类）须手工，60 项归账见执行记录 `doc-11月优化\[11]网关验收测试自动化执行记录-小欧-2026-11-05.md`

## 四、打包部署

- **默认不进包**：`OmniAgentBackend.spec` 不收 `gateways/`，打包版不含 opencli（推荐 A，境内免费层多直连 429，预置无用）
- **按需插件（方案 C）**：单独编译 `gateway.exe`，放到 `dist\OmniAgentBackend\gateways\`（与源码同形）；随后手动启动
- **注意**：.py 塞进 `_internal` 跑不起来（包内无解释器）；体积代价 ≈ 260 MB

## 五、常见问题

| 现象 | 处置 |
|------|------|
| 401 | 宿主 api_key ≠ 网关 token，两处对齐 |
| 连接拒绝 | 网关没起 / 端口不对，`start.bat` 后核对 |
| 大量 429 free-limit | 等冷却（最长约 1 h）或换出口，不改配置 |
| 未知模型 404 | UI 重拉模型再勾选保存 |
| 流式偶发断流 | 重试即过；持续断流按执行记录 §三 手工排查 |
